# Installing Postgres Enterprise Manager server on Linux AArch64 (ARM64)

Operating system-specific install instructions are described in the corresponding documentation:

### Red Hat Enterprise Linux (RHEL) and derivatives

- [RHEL 10](https://www.enterprisedb.com/docs/pem/latest/installing/linux_arm64/pem_rhel_10/)

- [RHEL 9](https://www.enterprisedb.com/docs/pem/latest/installing/linux_arm64/pem_rhel_9/)

- [Oracle Linux (OL) 10](https://www.enterprisedb.com/docs/pem/latest/installing/linux_arm64/pem_rhel_10/)

- [Oracle Linux (OL) 9](https://www.enterprisedb.com/docs/pem/latest/installing/linux_arm64/pem_rhel_9/)

### Debian and derivatives

- [Debian 13](https://www.enterprisedb.com/docs/pem/latest/installing/linux_arm64/pem_debian_13/)

- [Debian 12](https://www.enterprisedb.com/docs/pem/latest/installing/linux_arm64/pem_debian_12/)

* [RHEL 10 or OL 10](https://www.enterprisedb.com/docs/pem/latest/installing/linux_arm64/pem_rhel_10/): You can install PEM on a single server, or you can install the web application server and the backend database on two separate servers. You must prepare your servers for PEM installation.
* [RHEL 9 or OL 9](https://www.enterprisedb.com/docs/pem/latest/installing/linux_arm64/pem_rhel_9/): You can install PEM on a single server, or you can install the web application server and the backend database on two separate servers. You must prepare your servers for PEM installation.
* [Debian 13](https://www.enterprisedb.com/docs/pem/latest/installing/linux_arm64/pem_debian_13/): You can install PEM on a single server, or you can install the web application server and the backend database on two separate servers. You must prepare your servers for PEM installation.
* [Debian 12](https://www.enterprisedb.com/docs/pem/latest/installing/linux_arm64/pem_debian_12/): You can install PEM on a single server, or you can install the web application server and the backend database on two separate servers. You must prepare your servers for PEM installation.
