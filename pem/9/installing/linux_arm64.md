# Installing Postgres Enterprise Manager server on Linux AArch64 (ARM64)

Operating system-specific install instructions are described in the corresponding documentation:

### Red Hat Enterprise Linux (RHEL) and derivatives

- [RHEL 9](https://www.enterprisedb.com/docs/pem/9/installing/linux_arm64/pem_rhel_9/)

- [Oracle Linux (OL) 9](https://www.enterprisedb.com/docs/pem/9/installing/linux_arm64/pem_rhel_9/)

### Debian and derivatives

- [Debian 12](https://www.enterprisedb.com/docs/pem/9/installing/linux_arm64/pem_debian_12/)

* [RHEL 9 or OL 9](https://www.enterprisedb.com/docs/pem/9/installing/linux_arm64/pem_rhel_9/): You can install PEM on a single server, or you can install the web application server and the backend database on two separate servers. You must prepare your servers for PEM installation.
* [Debian 12](https://www.enterprisedb.com/docs/pem/9/installing/linux_arm64/pem_debian_12/): You can install PEM on a single server, or you can install the web application server and the backend database on two separate servers. You must prepare your servers for PEM installation.
