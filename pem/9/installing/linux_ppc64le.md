# Installing Postgres Enterprise Manager server on Linux IBM Power (ppc64le)

Operating system-specific install instructions are described in the corresponding documentation:

### Red Hat Enterprise Linux (RHEL)

- [RHEL 9](https://www.enterprisedb.com/docs/pem/9/installing/linux_ppc64le/pem_rhel_9/)

- [RHEL 8](https://www.enterprisedb.com/docs/pem/9/installing/linux_ppc64le/pem_rhel_8/)

### SUSE Linux Enterprise (SLES)

- [SLES 15](https://www.enterprisedb.com/docs/pem/9/installing/linux_ppc64le/pem_sles_15/)

* [RHEL 9](https://www.enterprisedb.com/docs/pem/9/installing/linux_ppc64le/pem_rhel_9/): You can install PEM on a single server, or you can install the web application server and the backend database on two separate servers. You must prepare your servers for PEM installation.
* [RHEL 8](https://www.enterprisedb.com/docs/pem/9/installing/linux_ppc64le/pem_rhel_8/): You can install PEM on a single server, or you can install the web application server and the backend database on two separate servers. You must prepare your servers for PEM installation.
* [SLES 15](https://www.enterprisedb.com/docs/pem/9/installing/linux_ppc64le/pem_sles_15/): Postgres Enterprise Manager 8.3 and later is supported on SLES.
