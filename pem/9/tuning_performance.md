# Tuning performance

The following features help in tuning the performance:

- [Tuning Wizard](https://www.enterprisedb.com/docs/pem/9/tuning_performance/tuning_wizard/)
- [Postgres Expert](https://www.enterprisedb.com/docs/pem/9/tuning_performance/postgres_expert/)
- [Performance Diagnostics](https://www.enterprisedb.com/docs/pem/9/tuning_performance/performance_diagnostic/)

* [Tuning Wizard](https://www.enterprisedb.com/docs/pem/9/tuning_performance/tuning_wizard/): The Tuning Wizard reviews your PostgreSQL or EDB Postgres Advanced Server installation, recommending a set of configuration options tuned to the installation's anticipated workload. Benchmarking systems or systems with a high work load might require also require manual tuning to reach optimum performance.
* [Postgres Expert](https://www.enterprisedb.com/docs/pem/9/tuning_performance/postgres_expert/): The Postgres Expert utility provides expert advice on how to best configure your Postgres servers for optimal performance, security, and more. Postgres Expert serves as a PostgreSQL DBA-in-a-box by evaluating your servers for deviations in best practices. Postgres Expert contains three specialized experts:
* [Performance Diagnostic](https://www.enterprisedb.com/docs/pem/9/tuning_performance/performance_diagnostic/): The Performance Diagnostic dashboard analyzes the database performance for Postgres instances by monitoring the wait events. To display the diagnostic graphs, PEM uses the data collected by the EDB wait states module. For more information on EDB wait states, see EDB wait states.
