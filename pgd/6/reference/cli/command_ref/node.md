# pgd node

The `pgd node` commands are used to manage the nodes in the EDB Postgres Distributed cluster.

## Subcommands

- [show](https://www.enterprisedb.com/docs/pgd/6/reference/cli/command_ref/node/show/): Show node-level information.
- [set-option](https://www.enterprisedb.com/docs/pgd/6/reference/cli/command_ref/node/set-option/): Set node-level options.
- [get-option](https://www.enterprisedb.com/docs/pgd/6/reference/cli/command_ref/node/get-option/): Get node-level options.
- [upgrade](https://www.enterprisedb.com/docs/pgd/6/reference/cli/command_ref/node/upgrade/): Perform a major version upgrade of a PGD Postgres node.
