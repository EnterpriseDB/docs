# Installing and configuring EDB Postgres Distributed

Choose a [deployment pattern](https://www.enterprisedb.com/docs/pgd/latest/planning/deployment-patterns/) and a deployment method to deploy EDB Postgres Distributed. The pattern determines which nodes and groups you deploy, and the method determines how you deploy them.

Choose one of the following methods to deploy PGD:

- [Manual deployment and administration](https://www.enterprisedb.com/docs/pgd/latest/deploying/deploy-manual/) describes how to manually deploy and configure EDB Postgres Distributed on a set of servers.

- [Trusted Postgres Architect (TPA)](https://www.enterprisedb.com/docs/pgd/latest/deploying/deploy-tpa/) describes how to use TPA to deploy and configure EDB Postgres Distributed to a Docker environment, Linux hosts, or AWS.

- [EDB Postgres Distributed for Kubernetes](https://www.enterprisedb.com/docs/pgd/latest/deploying/deploy-kubernetes/) describes how to deploy and configure EDB Postgres Distributed to a Kubernetes environment.

- [Hybrid Manager](https://www.enterprisedb.com/docs/pgd/latest/deploying/deploy-hm/) describes how to deploy and configure EDB Postgres Distributed to Hybrid Manager.

* [Manually](https://www.enterprisedb.com/docs/pgd/latest/deploying/deploy-manual/): How to manually deploy and configure EDB Postgres Distributed.
* [Using TPA](https://www.enterprisedb.com/docs/pgd/latest/deploying/deploy-tpa/): How to deploy and configure EDB Postgres Distributed using Trusted Postgres Architect (TPA).
* [On Kubernetes](https://www.enterprisedb.com/docs/pgd/latest/deploying/deploy-kubernetes/): How to deploy and configure EDB Postgres Distributed using EDB CloudNativePG Global Cluster operator.
* [On Hybrid Manager](https://www.enterprisedb.com/docs/pgd/latest/deploying/deploy-hm/): How to deploy and configure Distributed High-Availability clusters powered by PGD using Hybrid Manager.
