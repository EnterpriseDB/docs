# Quickstart guide

This guide will guide your through installing a basic PGD cluster, connect to the it, load data, and perform basic SQL operations.

- [Creating a cluster](https://www.enterprisedb.com/docs/pgd/latest/quickstart/first-cluster/).
- [Working with SQL and the PGD Cluster](https://www.enterprisedb.com/docs/pgd/latest/quickstart/working-with-sql/).
- [Loading Data into your PGD Cluster](https://www.enterprisedb.com/docs/pgd/latest/quickstart/loading-data/).
- [Using the PGD CLI](https://www.enterprisedb.com/docs/pgd/latest/quickstart/using-cli/).

* [Creating a cluster](https://www.enterprisedb.com/docs/pgd/latest/quickstart/first-cluster/): Creating your first cluster with EDB Postgres Distributed.
* [Working with SQL](https://www.enterprisedb.com/docs/pgd/latest/quickstart/working-with-sql/): Working with SQL and the PGD cluster
* [Loading data](https://www.enterprisedb.com/docs/pgd/latest/quickstart/loading-data/): PGD is, at its core, a Postgres database, so you can use the same tools and methods to load data into your PGD cluster as you would with any PostgreSQL database. To get you started, this guide will walk you through the process of loading data into your PGD cluster.
* [Using PGD CLI](https://www.enterprisedb.com/docs/pgd/latest/quickstart/using-cli/): PGD CLI is a command-line interface for managing and monitoring your EDB Postgres Distributed (PGD) clusters. It provides a set of commands to perform various operations on the cluster, such as creating nodes, joining nodes, and managing replication.
