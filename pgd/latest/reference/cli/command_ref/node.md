# pgd node

The `pgd node` commands are used to manage the nodes in the EDB Postgres Distributed cluster.

## Subcommands

- [setup](https://www.enterprisedb.com/docs/pgd/latest/reference/cli/command_ref/node/setup/): Configure PGD data nodes in a cluster.
- [show](https://www.enterprisedb.com/docs/pgd/latest/reference/cli/command_ref/node/show/): Show node-level information.
- [part](https://www.enterprisedb.com/docs/pgd/latest/reference/cli/command_ref/node/part/): Part a PGD node from an active cluster.
- [set-option](https://www.enterprisedb.com/docs/pgd/latest/reference/cli/command_ref/node/set-option/): Set node-level options.
- [get-option](https://www.enterprisedb.com/docs/pgd/latest/reference/cli/command_ref/node/get-option/): Get node-level options.
- [set-config](https://www.enterprisedb.com/docs/pgd/latest/reference/cli/command_ref/node/set-config/): Set node-level configuration.
- [get-config](https://www.enterprisedb.com/docs/pgd/latest/reference/cli/command_ref/node/get-config/): Get node-level configuration.
- [upgrade](https://www.enterprisedb.com/docs/pgd/latest/reference/cli/command_ref/node/upgrade/): Perform a major version upgrade of a PGD Postgres node.
- [start](https://www.enterprisedb.com/docs/pgd/latest/reference/cli/command_ref/node/start/): Start the Postgres instance on a node.
- [stop](https://www.enterprisedb.com/docs/pgd/latest/reference/cli/command_ref/node/stop/): Stop the Postgres instance on a node.
- [restart](https://www.enterprisedb.com/docs/pgd/latest/reference/cli/command_ref/node/restart/): Restart the Postgres instance on a node.
