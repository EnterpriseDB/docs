# First steps with your Quickstart PGD Cluster

Now that you have created your first PGD cluster, you can start working with it. This guide will help you connect to the cluster, load data, and perform basic SQL operations.

- [Working with SQL and the PGD Cluster](https://www.enterprisedb.com/docs/pgd/6.1/get-started/first-steps/working-with-sql/)
- [Loading Data into your PGD Cluster](https://www.enterprisedb.com/docs/pgd/6.1/get-started/first-steps/loading-data/)
- [Using the PGD CLI](https://www.enterprisedb.com/docs/pgd/6.1/get-started/first-steps/using-cli/)

* [Working with SQL](https://www.enterprisedb.com/docs/pgd/6.1/get-started/first-steps/working-with-sql/): Working with SQL and the PGD Cluster
* [Loading Data](https://www.enterprisedb.com/docs/pgd/6.1/get-started/first-steps/loading-data/): PGD is, at its core, a Postgres database, so you can use the same tools and methods to load data into your PGD cluster as you would with any PostgreSQL database. To get you started, this guide will walk you through the process of loading data into your PGD cluster.
* [Using PGD CLI](https://www.enterprisedb.com/docs/pgd/6.1/get-started/first-steps/using-cli/): PGD CLI is a command-line interface for managing and monitoring your EDB Postgres Distributed (PGD) clusters. It provides a set of commands to perform various operations on the cluster, such as creating nodes, joining nodes, and managing replication.
