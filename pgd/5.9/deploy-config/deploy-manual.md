# Manual deployment and configuration of PGD

This section covers how to manually deploy and configure EDB Postgres Distributed.

- [Deploying manually](https://www.enterprisedb.com/docs/pgd/5.9/deploy-config/deploy-manual/deploying/) works through the steps needed to:
  - Provision hosts
  - Install Postgres
  - Configure repositories
  - Install the PGD software
  - Create a cluster
  - Check a cluster
  - Configure PGD proxies
  - Install and use PGD CLI

* [Deploying](https://www.enterprisedb.com/docs/pgd/5.9/deploy-config/deploy-manual/deploying/): EDB offers automated PGD deployment using Trusted Postgres Architect (TPA) because it's generally more reliable than manual processes.
