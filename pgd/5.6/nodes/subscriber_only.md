# Subscriber-only nodes and groups

Subscriber-only nodes and groups offer a powerful way to build read scaling into your PGD cluster.

- The [Overview](https://www.enterprisedb.com/docs/pgd/5.6/nodes/subscriber_only/overview/) introduces how subscriber-only nodes and groups work in PGD.

- [Creating a subscriber-only group](https://www.enterprisedb.com/docs/pgd/5.6/nodes/subscriber_only/creating-so/) explains how to create a subscriber-only group and node.

- [Joining a node to a subscriber-only group](https://www.enterprisedb.com/docs/pgd/5.6/nodes/subscriber_only/joining-so/) explains how to join a node to an existing subscriber-only group which has members.

- [Optimizing subscriber-only groups](https://www.enterprisedb.com/docs/pgd/5.6/nodes/subscriber_only/optimizing-so/) provides details on how to configure the PGD 5.6 subscriber-only optimized topology feature which uses a group leader for more efficient replication.
