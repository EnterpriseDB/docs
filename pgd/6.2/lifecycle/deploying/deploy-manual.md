# Manually

This section covers how to manually deploy and configure EDB Postgres Distributed (PGD).

If you want to install a learning/test environment, we recommend using the [Quickstart guide](https://www.enterprisedb.com/docs/pgd/latest/quickstart/).

Manually deploying a PGD cluster consists of the following steps:

1. Meet the [prerequisites](https://www.enterprisedb.com/docs/pgd/6.2/lifecycle/deploying/deploy-manual/01-prerequisites/).
2. [Configure the EDB repositories](https://www.enterprisedb.com/docs/pgd/6.2/lifecycle/deploying/deploy-manual/02-configure-repositories/).
3. [Install the database and PGD software](https://www.enterprisedb.com/docs/pgd/6.2/lifecycle/deploying/deploy-manual/03-installing-database-and-pgd/).
4. [Configure the cluster](https://www.enterprisedb.com/docs/pgd/6.2/lifecycle/deploying/deploy-manual/04-configuring-cluster/).
5. [Check the cluster](https://www.enterprisedb.com/docs/pgd/6.2/lifecycle/deploying/deploy-manual/05-check-cluster/).
6. Learn how to [connect to your cluster](https://www.enterprisedb.com/docs/pgd/6.2/lifecycle/deploying/deploy-manual/connections/).

- [Prerequisites](https://www.enterprisedb.com/docs/pgd/6.2/lifecycle/deploying/deploy-manual/01-prerequisites/): Learn what the prerequisites are before you install EDB Postgres Distributed.
- [Configuring PGD repositories](https://www.enterprisedb.com/docs/pgd/6.2/lifecycle/deploying/deploy-manual/02-configure-repositories/): Configuring the necessary repositories for the database and PGD software on each host.
- [Installing](https://www.enterprisedb.com/docs/pgd/6.2/lifecycle/deploying/deploy-manual/03-installing-database-and-pgd/): Installing the database and pgd software on each host.
- [Configuring](https://www.enterprisedb.com/docs/pgd/6.2/lifecycle/deploying/deploy-manual/04-configuring-cluster/): Perform the necessary configuration changes to your newly installed PGD cluster.
- [Checking the cluster](https://www.enterprisedb.com/docs/pgd/6.2/lifecycle/deploying/deploy-manual/05-check-cluster/): Verify that your PGD cluster is correctly installed and configured.
- [Connecting to your cluster](https://www.enterprisedb.com/docs/pgd/6.2/lifecycle/deploying/deploy-manual/connections/): How to connect to your PGD cluster.
