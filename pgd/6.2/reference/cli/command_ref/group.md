# pgd group

The `pgd group` commands are used to manage the groups in the EDB Postgres Distributed cluster.

## Subcommands

- [show](https://www.enterprisedb.com/docs/pgd/6.2/reference/cli/command_ref/group/show/): Show group-level information.
- [set-option](https://www.enterprisedb.com/docs/pgd/6.2/reference/cli/command_ref/group/set-option/): Set group-level options.
- [get-option](https://www.enterprisedb.com/docs/pgd/6.2/reference/cli/command_ref/group/get-option/): Get group-level options.
- [set-leader](https://www.enterprisedb.com/docs/pgd/6.2/reference/cli/command_ref/group/set-leader/): Set the write leader of a group (perform a switchover).
