# Oracle compatibility reference

This reference information applies to organizations migrating their Oracle applications to use EDB Postgres Advanced Server.

- [dblink\_ora functions and procedures](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/01_dblink_ora_functions_and_procedures/): Describes the functions and procedures supported by dblink\_ora
- [Partitioning commands compatible with Oracle Databases](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/04_partitioning_commands_compatible_with_oracle_databases/): Listing of table partitioning syntaxes that are compatible with Oracle databases
- [Built-in packages](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_bip_guide/): Listing of the built-in package support provided by EDB Postgres Advanced Server
- [Catalog Views](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_cat_views/): Listing of the catalog views support provided by EDB Postgres Advanced Server
- [Oracle-compatible SQL commands](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/epas_compat_sql/): Listing of SQL commands compatible with Oracle databases
- [List of Oracle compatible configuration parameters](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/summary_oracle_config_parameters/): Descriptions of the configuration parameters used to control system behaviors to act more like PostgreSQL or more like Oracle
- [SYS schema](https://www.enterprisedb.com/docs/epas/latest/reference/oracle_compatibility_reference/sys_schema/): Information about the SYS schema in EDB Postgres Advanced Server
