# Language element reference

<div id="reference" class="registered_link"></div>

ECPGPlus has these language elements.

- [C-preprocessor directives](https://www.enterprisedb.com/docs/epas/latest/reference/application_programmer_reference/07_reference/c_preprocessor_directives/): The ECPGPlus C-preprocessor enforces two behaviors that depend on the mode in which you invoke ECPGPlus:
- [Language element reference](https://www.enterprisedb.com/docs/epas/latest/reference/application_programmer_reference/07_reference/ecpgplus_statements/): Description of the ECPGPlus language elements
- [The SQLDA structure](https://www.enterprisedb.com/docs/epas/latest/reference/application_programmer_reference/07_reference/sqlda_structure/): Oracle Dynamic SQL method 4 uses the SQLDA data structure to hold the data and metadata for a dynamic SQL statement. A SQLDA structure can describe a set of input parameters corresponding to the parameter markers found in the text of a dynamic statement or the result set of a dynamic statement.
- [Supported C data types](https://www.enterprisedb.com/docs/epas/latest/reference/application_programmer_reference/07_reference/supported_c_data_types/): An ECPGPlus application must deal with two sets of data types: SQL data types (such as SMALLINT, DOUBLE PRECISION, and CHARACTER VARYING) and C data types (like short, double, and varchar\[n]). When an application fetches data from the server, ECPGPlus maps each SQL data type to the type of the C variable into which the data is returned.
- [Type codes](https://www.enterprisedb.com/docs/epas/latest/reference/application_programmer_reference/07_reference/type_codes/): Type codes for external data types
