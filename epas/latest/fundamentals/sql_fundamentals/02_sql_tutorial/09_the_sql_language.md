# The SQL language

<div id="the_sql_language" class="registered_link"></div>

EDB Postgres Advanced Server supports SQL language that's compatible with Oracle syntax as well as syntax and commands for extended functionality. Extended functionality doesn't provide database compatibility for Oracle or support Oracle-styled applications.

[SQL reference](https://www.enterprisedb.com/docs/epas/latest/reference/sql_reference/) provides detailed information about:

- [Compatible SQL syntax and language elements](https://www.enterprisedb.com/docs/epas/latest/reference/sql_reference/01_sql_syntax/)
- [Data types](https://www.enterprisedb.com/docs/epas/latest/reference/sql_reference/02_data_types/)
- [Functions and operators for the built-in data types](https://www.enterprisedb.com/docs/epas/latest/reference/sql_reference/03_functions_and_operators/)
