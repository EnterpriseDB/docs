# Supported platforms

EDB Postgres Advanced Server supports installations on Linux and Windows platforms.

To learn about the platform support for EDB Postgres Advanced Server, you can refer either to the platform support for EDB Postgres Advanced Server on the [Platform Compatibility page](https://www.enterprisedb.com/platform-compatibility#epas) on the EDB website or [Installing EDB Postgres Advanced Server](https://www.enterprisedb.com/docs/epas/latest/installing/).
