# Enterprise Postgres (Oracle Compatible)

EDB is the only worldwide company to deliver innovative and low-cost, open-source-derived database solutions. These solutions offer commercial quality, ease of use, compatibility, scalability, and performance for small or large-scale enterprises. Enterprise Postgres (Oracle Compatible), also known as EDB Postgres Advanced Server (EPAS), adds extended functionality to open-source PostgreSQL, including:

- [Database administration](https://www.enterprisedb.com/docs/epas/17/database_administration/)
- [Enhanced SQL capabilities](https://www.enterprisedb.com/docs/epas/17/application_programming/15_enhanced_sql_and_other_misc_features/)
- [Database and application security](https://www.enterprisedb.com/docs/epas/17/epas_security_guide/)
- [Performance monitoring and analysis](https://www.enterprisedb.com/docs/epas/17/managing_performance/)
- [Application development utilities](https://www.enterprisedb.com/docs/epas/17/application_programming/)
- [Advanced replication (version 14 and higher)](https://www.enterprisedb.com/docs/pgd/latest/).

All of these features are available in Postgres mode and [Oracle compatibility mode](https://www.enterprisedb.com/docs/epas/17/working_with_oracle_data/). When you launch EDB Postgres Advanced Server in Oracle compatibility mode, you get additional features that help with Oracle-to-Postgres migrations.

- [Oracle-compatible custom data types](https://www.enterprisedb.com/docs/epas/17/reference/sql_reference/02_data_types/)
- [Oracle keywords](https://www.enterprisedb.com/docs/epas/17/reference/sql_reference/01_sql_syntax/)
- [Oracle functions](https://www.enterprisedb.com/docs/epas/17/reference/sql_reference/03_functions_and_operators/)
- [Oracle-style catalog views](https://www.enterprisedb.com/docs/epas/17/reference/oracle_compatibility_reference/epas_compat_cat_views/)
- [Additional compatibility with Oracle MERGE](https://www.enterprisedb.com/docs/epas/17/reference/oracle_compatibility_reference/epas_compat_sql/65a_merge/).

EDB also makes available a [full suite of tools and utilities](https://www.enterprisedb.com/docs/epas/17/tools_utilities_and_components/) that helps you monitor and manage your EDB Postgres Advanced Server deployment.

To see how EDB Postgres Advanced Server compares to other databases, see [Choosing your Postgres distribution](https://www.enterprisedb.com/docs/edb-postgres-ai/databases/postgres_distributions/).
