# Enterprise Postgres (Oracle Compatible)

Enterprise Postgres (Oracle Compatible), also known as EDB Postgres Advanced Server, continues to lead as the only worldwide company to deliver innovative and low-cost, open-source-derived database solutions with commercial quality, ease of use, compatibility, scalability, and performance for small or large-scale enterprises.

- [Release notes](https://www.enterprisedb.com/docs/epas/14/epas_rel_notes/): EDB Postgres Advanced Server 14 is built on open-source PostgreSQL 14, which introduces myriad enhancements that enable databases to scale up and scale out in more efficient ways. PostgreSQL 14 has significant performance improvements, which includes an improved indexing and lookup system, a level up on query planning when using extended statistics, improved performance for queries that use aggregates or partitioned tables, and providing more ways to monitor activity within a PostgreSQL database. And along with highly requested features like parallelized vacuuming, incremental sorting, PostgreSQL 14 has a multitude of other new features and capabilities.
