# Oracle catalog views

Oracle catalog views provide information about database objects in a manner compatible with Oracle data dictionary views.

- [ALL\_ALL\_TABLES](https://www.enterprisedb.com/docs/epas/14/epas_compat_cat_views/oracle_compatible_views/02_all_all_tables/): The ALLALLTABLES view provides information about the tables the current user can access.
- [ALL\_CONS\_COLUMNS](https://www.enterprisedb.com/docs/epas/14/epas_compat_cat_views/oracle_compatible_views/03_all_cons_columns/): The ALLCONSCOLUMNS view provides information about the columns specified in constraints placed on tables accessible by the current user.
- [ALL\_CONSTRAINTS](https://www.enterprisedb.com/docs/epas/14/epas_compat_cat_views/oracle_compatible_views/04_all_constraints/): The ALL\_CONSTRAINTS view provides information about the constraints placed on tables accessible by the current user.
- [ALL\_COL\_PRIVS](https://www.enterprisedb.com/docs/epas/14/epas_compat_cat_views/oracle_compatible_views/05_all_col_privs/): The ALLCOLPRIVS view provides the following types of privileges:
- [ALL\_DB\_LINKS](https://www.enterprisedb.com/docs/epas/14/epas_compat_cat_views/oracle_compatible_views/06_all_db_links/): The ALLDBLINKS view provides information about the database links accessible by the current user.
- [ALL\_DEPENDENCIES](https://www.enterprisedb.com/docs/epas/14/epas_compat_cat_views/oracle_compatible_views/07_all_dependencies/): The ALL\_DEPENDENCIES view provides information about the dependencies between database objects that the current user can access, except for synonyms.
- [ALL\_DIRECTORIES](https://www.enterprisedb.com/docs/epas/14/epas_compat_cat_views/oracle_compatible_views/08_all_directories/): The ALL\_DIRECTORIES view provides information about all directories created with the CREATE DIRECTORY command.
- [ALL\_IND\_COLUMNS](https://www.enterprisedb.com/docs/epas/14/epas_compat_cat_views/oracle_compatible_views/09_all_ind_columns/): The ALLINDCOLUMNS view provides information about columns included in indexes on the tables accessible by the current user.
- [ALL\_INDEXES](https://www.enterprisedb.com/docs/epas/14/epas_compat_cat_views/oracle_compatible_views/10_all_indexes/): The ALL\_INDEXES view provides information about the indexes on tables that the current user can access.
- [ALL\_JOBS](https://www.enterprisedb.com/docs/epas/14/epas_compat_cat_views/oracle_compatible_views/11_all_jobs/): The ALL\_JOBS view provides information about the jobs that the current user can access.
- [ALL\_OBJECTS](https://www.enterprisedb.com/docs/epas/14/epas_compat_cat_views/oracle_compatible_views/12_all_objects/): The ALL\_OBJECTS view provides information about all objects that reside in the database.
- [ALL\_PART\_KEY\_COLUMNS](https://www.enterprisedb.com/docs/epas/14/epas_compat_cat_views/oracle_compatible_views/13_all_part_key_columns/): The ALLPARTKEY\_COLUMNS view provides information about the key columns of the partitioned tables that reside in the database.
- [ALL\_PART\_TABLES](https://www.enterprisedb.com/docs/epas/14/epas_compat_cat_views/oracle_compatible_views/14_all_part_tables/): The ALLPARTTABLES view provides information about all of the partitioned tables that reside in the database.
- [ALL\_POLICIES](https://www.enterprisedb.com/docs/epas/14/epas_compat_cat_views/oracle_compatible_views/15_all_policies/): The ALL\_POLICIES view provides information on all policies in the database. This view is accessible only to superusers.
- [ALL\_QUEUES](https://www.enterprisedb.com/docs/epas/14/epas_compat_cat_views/oracle_compatible_views/16_all_queues/): The ALL\_QUEUES view provides information about any currently defined queues.
- [ALL\_QUEUE\_TABLES](https://www.enterprisedb.com/docs/epas/14/epas_compat_cat_views/oracle_compatible_views/17_all_queue_tables/): The ALLQUEUETABLES view provides information about all of the queue tables in the database.
- [ALL\_SEQUENCES](https://www.enterprisedb.com/docs/epas/14/epas_compat_cat_views/oracle_compatible_views/18_all_sequences/): The ALL\_SEQUENCES view provides information about all user-defined sequences on which the user has SELECT or UPDATE privileges.
- [ALL\_SOURCE](https://www.enterprisedb.com/docs/epas/14/epas_compat_cat_views/oracle_compatible_views/19_all_source/): The ALL\_SOURCE view provides a source code listing of the following program types: functions, procedures, triggers, package specifications, and package bodies.
- [ALL\_SUBPART\_KEY\_COLUMNS](https://www.enterprisedb.com/docs/epas/14/epas_compat_cat_views/oracle_compatible_views/20_all_subpart_key_columns/): The ALLSUBPARTKEY\_COLUMNS view provides information about the key columns of those partitioned tables that are subpartitioned that reside in the database.
- [ALL\_SYNONYMS](https://www.enterprisedb.com/docs/epas/14/epas_compat_cat_views/oracle_compatible_views/21_all_synonyms/): The ALL\_SYNONYMS view provides information on all synonyms that the current user can reference.
