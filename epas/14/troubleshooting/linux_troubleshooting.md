* [Enabling core dumps](https://www.enterprisedb.com/docs/epas/14/troubleshooting/linux_troubleshooting/enabling_core_dump/): You can use core dumps to diagnose or debug errors. A core dump is a file containing a process's address space (memory) when the process terminates unexpectedly. Core dumps may be produced on-demand (such as by a debugger) or automatically upon termination.
