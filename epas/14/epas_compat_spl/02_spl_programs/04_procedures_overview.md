# Procedures overview

<div id="procedures_overview" class="registered_link"></div>

Procedures are standalone SPL programs that you invoke or call as an individual SPL program statement. When called, procedures can optionally receive values from the caller in the form of input parameters. They can optionally return values to the caller in the form of output parameters.

- [Creating a procedure](https://www.enterprisedb.com/docs/epas/14/epas_compat_spl/02_spl_programs/04_procedures_overview/01_creating_a_procedure/): The CREATE PROCEDURE command defines and names a standalone procedure that's stored in the database.
- [Calling a procedure](https://www.enterprisedb.com/docs/epas/14/epas_compat_spl/02_spl_programs/04_procedures_overview/02_calling_a_procedure/): You can invoke a procedure from another SPL program by specifying the procedure name followed by any parameters and a semicolon:
- [Deleting a procedure](https://www.enterprisedb.com/docs/epas/14/epas_compat_spl/02_spl_programs/04_procedures_overview/03_deleting_a_procedure/): You can delete a procedure from the database using the DROP PROCEDURE command.
