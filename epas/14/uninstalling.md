# Uninstalling EDB Postgres Advanced Server

This section provides detailed information about uninstalling the EDB Postgres Advanced server on specific platforms.

- [On Linux](https://www.enterprisedb.com/docs/epas/14/uninstalling/linux_uninstall/): Note that after uninstalling EDB Postgres Advanced Server, the cluster data files remain intact and the service user persists. You may manually remove the cluster data and service user from the system.
- [On Windows](https://www.enterprisedb.com/docs/epas/14/uninstalling/windows_uninstall/): Note that after uninstalling EDB Postgres Advanced Server, the cluster data files remain intact and the service user persists. You may manually remove the cluster data and service user from the system.
