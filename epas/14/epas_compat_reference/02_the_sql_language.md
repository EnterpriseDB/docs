# The SQL language

<div id="the_sql_language" class="registered_link"></div>

A subset of the EDB Postgres Advanced Server SQL language is compatible with Oracle databases. These SQL syntaxes, data types, and functions work in both EDB Postgres Advanced Server and Oracle.

The EDB Postgres Advanced Server includes syntax and commands for extended functionality (functionality that doesn't provide database compatibility for Oracle or support Oracle-styled applications) that aren't included here.

- [SQL syntax](https://www.enterprisedb.com/docs/epas/14/epas_compat_reference/02_the_sql_language/01_sql_syntax/): Understanding the general syntax of SQL forms the foundation for understanding how to apply the SQL commands to define and modify data.
- [Data types](https://www.enterprisedb.com/docs/epas/14/epas_compat_reference/02_the_sql_language/02_data_types/): The following table shows the built-in general-purpose data types.
- [Functions and operators](https://www.enterprisedb.com/docs/epas/14/epas_compat_reference/02_the_sql_language/03_functions_and_operators/): EDB Postgres Advanced Server provides functions and operators for the built-in data types.
