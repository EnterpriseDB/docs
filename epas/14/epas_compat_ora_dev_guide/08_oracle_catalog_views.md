# Oracle catalog views

<div id="oracle_catalog_views" class="registered_link"></div>

The Oracle catalog views provide information about database objects in a manner compatible with the Oracle data dictionary views. Information about the supported views is available in Database Compatibility for Oracle Developers [Catalog Views](https://www.enterprisedb.com/docs/epas/14/epas_compat_cat_views/oracle_compatible_views/).
