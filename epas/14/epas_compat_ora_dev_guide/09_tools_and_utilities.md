# Tools and utilities

<div id="tools_and_utilities" class="registered_link"></div>

Compatible tools and utility programs allow you to work with EDB Postgres Advanced Server in a familiar environment. The tools supported by EDB Postgres Advanced Server include:

- EDB\*Plus
- EDB\*Loader
- EDB\*Wrap
- The Dynamic Runtime Instrumentation Tools Architecture (DRITA)

For detailed information about the functionality supported by EDB Postgres Advanced Server, see [Tools, utilities, and components](https://www.enterprisedb.com/docs/epas/14/epas_compat_tools_guide/).
