# Invoking EDB\*Loader

<div id="invoking_edb_loader" class="registered_link"></div>

You can run EDB\*Loader as superuser or as a normal user.

- [Running EDB\*Loader](https://www.enterprisedb.com/docs/epas/16/database_administration/02_edb_loader/invoking_edb_loader/running_edb_loader/): Describes how to run EDB\*Loader from the command line
- [Conventional path load](https://www.enterprisedb.com/docs/epas/16/database_administration/02_edb_loader/invoking_edb_loader/conventional_path_load/): Describes how to use EDB\*Loader with a conventional path load to update the rows in a table
- [Direct path load](https://www.enterprisedb.com/docs/epas/16/database_administration/02_edb_loader/invoking_edb_loader/direct_path_load/): Describes how to use EDB\*Loader to write data directly to the database pages
- [Parallel direct path load](https://www.enterprisedb.com/docs/epas/16/database_administration/02_edb_loader/invoking_edb_loader/parallel_direct_path_load/): Describes how to run a parallel direct path load to distribute the loading process over two or more sessions
- [Remote loading](https://www.enterprisedb.com/docs/epas/16/database_administration/02_edb_loader/invoking_edb_loader/performing_remote_loading/): Describes how to load a database running on a database server using data piped from a different source
