# Object type components

<div id="object_type_components" class="registered_link"></div>

Object types are created and stored in the database by using the following two constructs of the SPL language:

- The _object type specification_. This construct is the public interface specifying the attributes and method signatures of the object type.
- The _object type body_. This construct contains the implementation of the methods specified in the object type specification.
