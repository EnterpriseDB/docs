# EDB Postgres Advanced Server security features

EDB Postgres Advanced Server extends Postgres security with features designed to limit unauthorized access.

- [Transparent Data Encryption overview](https://www.enterprisedb.com/docs/epas/17/epas_security_guide/tde_feature/): Provides an overview of the benefits of the Transparent Data Encryption feature
- [EDB audit logging](https://www.enterprisedb.com/docs/epas/17/epas_security_guide/05_edb_audit_logging/): Enables database and security administrators, auditors, and operators to track and analyze database activities
- [Protecting against SQL injection attacks](https://www.enterprisedb.com/docs/epas/17/epas_security_guide/02_protecting_against_sql_injection_attacks/): With the SQL/Protect feature, EDB Postgres Advanced Server offers protection against SQL injection attacks by examining incoming queries for common SQL injection profiles.
- [Generating SSL certificates](https://www.enterprisedb.com/docs/epas/17/epas_security_guide/04_sslutils/): The sslutils Postgres extension provides SSL certificate generation functions to EDB Postgres Advanced Server for use by the EDB Postgres Enterprise Manager server
- [Protecting proprietary source code](https://www.enterprisedb.com/docs/epas/17/epas_security_guide/03_edb_wrap/): Describes how to use the EDB\*Wrap utility to obfuscate proprietary source code and programs
- [Managing user profiles](https://www.enterprisedb.com/docs/epas/17/epas_security_guide/04_profile_management/): How to create and manage profiles that specify database access for users
- [Redacting data](https://www.enterprisedb.com/docs/epas/17/epas_security_guide/05_data_redaction/): Use the EDB Postgres Advanced Server data redaction feature to limit exposure to sensitive data by dynamically changing the data as it is displayed for certain users
- [Controlling data access](https://www.enterprisedb.com/docs/epas/17/epas_security_guide/03_virtual_private_database/): Virtual Private Database offers fine-grained access control to data down to specific rows, as defined by the security policy
