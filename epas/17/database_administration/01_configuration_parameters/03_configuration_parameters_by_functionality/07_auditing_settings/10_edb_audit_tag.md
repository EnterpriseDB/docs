# edb\_audit\_tag

<div id="edb_audit_tag" class="registered_link"></div>

**Parameter type:** String

**Default value:** none

**Minimum scope of effect:** Session

**When value changes take effect:** Immediate

**Required authorization to activate:** User

Specifies a string value to include in the audit log when the `edb_audit` parameter is set to `csv`, `xml`, or `json`.
