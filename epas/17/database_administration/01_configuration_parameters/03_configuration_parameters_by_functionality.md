# Configuration parameters by functionality

<div id="configuration_parameters_by_functionality" class="registered_link"></div>

Configuration parameters can be grouped by function. See [Description of parameter attributes](https://www.enterprisedb.com/docs/epas/17/database_administration/01_configuration_parameters/03_configuration_parameters_by_functionality/attribute_descriptions/) for the list of attributes included in each configuration parameter description.

- [Top performance-related parameters](https://www.enterprisedb.com/docs/epas/17/database_administration/01_configuration_parameters/03_configuration_parameters_by_functionality/01_top_performance_related_parameters/): These configuration parameters have the most immediate impact on performance.
- [Resource usage/memory](https://www.enterprisedb.com/docs/epas/17/database_administration/01_configuration_parameters/03_configuration_parameters_by_functionality/02_resource_usage_memory/): These configuration parameters control resource use pertaining to memory.
- [Resource usage/EDB Resource Manager](https://www.enterprisedb.com/docs/epas/17/database_administration/01_configuration_parameters/03_configuration_parameters_by_functionality/03_resource_usage_edb_resource_manager/): These configuration parameters control resource use through EDB Resource Manager.
- [Query tuning](https://www.enterprisedb.com/docs/epas/17/database_administration/01_configuration_parameters/03_configuration_parameters_by_functionality/04_query_tuning/): These configuration parameters are used for optimizer hints.
- [Query tuning/planner method configuration](https://www.enterprisedb.com/docs/epas/17/database_administration/01_configuration_parameters/03_configuration_parameters_by_functionality/05_query_tuning_planner_method_configuration/): These configuration parameters are used for planner method configuration.
- [Reporting and logging/what to log](https://www.enterprisedb.com/docs/epas/17/database_administration/01_configuration_parameters/03_configuration_parameters_by_functionality/06_reporting_and_logging_what_to_log/): These configuration parameters control reporting and logging.
- [Auditing settings](https://www.enterprisedb.com/docs/epas/17/database_administration/01_configuration_parameters/03_configuration_parameters_by_functionality/07_auditing_settings/): These configuration parameters are for use with the EDB Postgres Advanced Server database auditing feature.
- [Client connection defaults/locale and formatting](https://www.enterprisedb.com/docs/epas/17/database_administration/01_configuration_parameters/03_configuration_parameters_by_functionality/08_ccd_locale_and_formatting/): These configuration parameters affect locale and formatting.
- [Client connection defaults/statement behavior](https://www.enterprisedb.com/docs/epas/17/database_administration/01_configuration_parameters/03_configuration_parameters_by_functionality/09_ccd_statement_behaviour/): These configuration parameters affect statement behavior.
- [Client connection defaults/other defaults](https://www.enterprisedb.com/docs/epas/17/database_administration/01_configuration_parameters/03_configuration_parameters_by_functionality/10_ccd_other_defaults/): These parameters set miscellaneous client connection defaults.
- [Compatibility options](https://www.enterprisedb.com/docs/epas/17/database_administration/01_configuration_parameters/03_configuration_parameters_by_functionality/11_compatibility_options/): These configuration parameters control various database compatibility features.
- [Customized options](https://www.enterprisedb.com/docs/epas/17/database_administration/01_configuration_parameters/03_configuration_parameters_by_functionality/12_customized_options/): customvariableclasses
- [Ungrouped configuration parameters](https://www.enterprisedb.com/docs/epas/17/database_administration/01_configuration_parameters/03_configuration_parameters_by_functionality/13_ungrouped/): These configuration parameters apply only to EDB Postgres Advanced Server and are for a specific, limited purpose.
- [Audit archiving parameters](https://www.enterprisedb.com/docs/epas/17/database_administration/01_configuration_parameters/03_configuration_parameters_by_functionality/14_audit_archiver/): These configuration parameters are used by the EDB Postgres Advanced Server database audit archiving feature.
