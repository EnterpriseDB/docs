# Tools and utilities overview

<div id="tools_and_utilities" class="registered_link"></div>

Oracle-compatible tools and utility programs allow you to work with EDB Postgres Advanced Server in a familiar environment. The tools supported by EDB Postgres Advanced Server include:

- [EDB\*Plus](https://www.enterprisedb.com/docs/edb_plus/latest/)
- [EDB\*Loader](https://www.enterprisedb.com/docs/epas/17/database_administration/02_edb_loader/)
- [EDB\*Wrap](https://www.enterprisedb.com/docs/epas/17/epas_security_guide/03_edb_wrap/)
- [The Dynamic Runtime Instrumentation Tools Architecture (DRITA)](https://www.enterprisedb.com/docs/epas/17/managing_performance/04_dynamic_runtime_instrumentation_tools_architecture_DRITA/)
