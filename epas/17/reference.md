# Reference

This reference material contains descriptive content needed by application programmers and database administrators. It also includes information that applies to organizations migrating their Oracle applications to use EDB Postgres Advanced Server as well as a SQL reference.

- [SQL reference](https://www.enterprisedb.com/docs/epas/17/reference/sql_reference/): Describes the subset of the EDB Postgres Advanced Server SQL language that is compatible with Oracle databases
- [Application programmer reference](https://www.enterprisedb.com/docs/epas/17/reference/application_programmer_reference/): Contains reference information applicable to application programmer tasks, such as the layout of system catalog tables
- [Database administrator reference](https://www.enterprisedb.com/docs/epas/17/reference/database_administrator_reference/): Contains reference information applicable to database administrator tasks, such as configuration parameters
- [Oracle compatibility reference](https://www.enterprisedb.com/docs/epas/17/reference/oracle_compatibility_reference/): Contains reference information applicable to organizations migrating their Oracle applications to use EDB Postgres Advanced Server
