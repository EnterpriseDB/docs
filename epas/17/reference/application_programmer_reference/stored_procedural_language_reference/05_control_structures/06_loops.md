# Loops

<div id="loops" class="registered_link"></div>

When you use the `LOOP`, `EXIT`, `CONTINUE`, `WHILE`, and `FOR` statements, your SPL program can repeat a series of commands.

- [LOOP](https://www.enterprisedb.com/docs/epas/17/reference/application_programmer_reference/stored_procedural_language_reference/05_control_structures/06_loops/01_loop/): LOOP defines an unconditional loop that's repeated indefinitely until terminated by an EXIT or RETURN statement.
- [EXIT](https://www.enterprisedb.com/docs/epas/17/reference/application_programmer_reference/stored_procedural_language_reference/05_control_structures/06_loops/02_exit/): Syntax
- [CONTINUE](https://www.enterprisedb.com/docs/epas/17/reference/application_programmer_reference/stored_procedural_language_reference/05_control_structures/06_loops/03_continue/): The CONTINUE statement provides a way to proceed with the next iteration of a loop while skipping intervening statements.
- [WHILE](https://www.enterprisedb.com/docs/epas/17/reference/application_programmer_reference/stored_procedural_language_reference/05_control_structures/06_loops/04_while/): Syntax
- [FOR (integer variant)](https://www.enterprisedb.com/docs/epas/17/reference/application_programmer_reference/stored_procedural_language_reference/05_control_structures/06_loops/05_for_integer_variant/): Syntax
