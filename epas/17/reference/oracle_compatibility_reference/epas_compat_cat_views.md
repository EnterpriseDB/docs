# Database compatibility for Oracle developers: catalog views

Catalog views provide information about database objects. There are two categories of catalog views:

- Oracle catalog views provide information about database objects in a manner compatible with the Oracle data dictionary views.

- System catalog views are present in PostgreSQL and might have extra information when accessed in EDB Postgres Advanced Server.

These features related to the catalog views support are provided by EDB Postgres Advanced Server.

- [Oracle catalog views](https://www.enterprisedb.com/docs/epas/17/reference/oracle_compatibility_reference/epas_compat_cat_views/oracle_compatible_views/): Oracle catalog views provide information about database objects in a manner compatible with Oracle data dictionary views.
- [System catalog views](https://www.enterprisedb.com/docs/epas/17/reference/oracle_compatibility_reference/epas_compat_cat_views/pg_views/): System catalog views are present in PostgreSQL. They might have extra information when accessed in EDB Postgres Advanced Server. The PGUSER view is an example of a system catalog view that provides additional information specific to EDB Postgres Advanced Server.
