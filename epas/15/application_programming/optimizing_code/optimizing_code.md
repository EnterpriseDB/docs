# Optimizing inefficient SQL code

Inefficient SQL code is a leading cause of database performance problems. The challenge for database administrators and developers is locating and then optimizing this code in large, complex systems.

See [SQL Profiler](https://www.enterprisedb.com/docs/epas/15/managing_performance/03_sql_profiler/) to see how the utility can help you locate and optimize poorly running SQL code.
