# Setting configuration parameters

<div id="configuration_parameters" class="registered_link"></div>

The EDB Postgres Advanced Server configuration parameters control various aspects of the database server’s behavior and environment such as data file and log file locations, connection, authentication and security settings, resource allocation and consumption, archiving and replication settings, error logging and statistics gathering, optimization and performance tuning, and locale and formatting settings

Configuration parameters that apply only to EDB Postgres Advanced Server are noted in [Summary of configuration parameters](https://www.enterprisedb.com/docs/epas/latest/reference/database_administrator_reference/02_summary_of_configuration_parameters/), which lists all EDB Postgres Advanced Server configuration parameters along with a number of key attributes of the parameters.

You can find more information about configuration parameters in the [PostgreSQL core documentation](https://www.postgresql.org/docs/current/static/runtime-config.html).

- [Setting configuration parameters](https://www.enterprisedb.com/docs/epas/15/database_administration/01_configuration_parameters/01_setting_new_parameters/): Describes how to set the configuration parameters for EDB Postgres Advanced Server
- [Configuration parameters by functionality](https://www.enterprisedb.com/docs/epas/15/database_administration/01_configuration_parameters/03_configuration_parameters_by_functionality/): Provides a detailed description of the configuration parameters, grouped by function
