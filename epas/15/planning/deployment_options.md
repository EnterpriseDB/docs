# Deployment options

You can deploy and install EDB Postgres Advanced Server using:

- [EDB Postgres AI Cloud Service](https://www.enterprisedb.com/docs/edb-postgres-ai/cloud-service/), a fully managed database-as-a-service with built-in Oracle compatibility. It runs in your cloud account and is operated by the Postgres experts. Cloud Service makes it easy to set up, manage, and scale your databases. Provision PostgreSQL or EDB Postgres Advanced Server with Oracle compatibility.

- [EDB PostgreSQL for Kubernetes](https://www.enterprisedb.com/docs/postgres_for_kubernetes/latest/), an operator designed by EnterpriseDB to manage PostgreSQL workloads on any supported Kubernetes cluster running in private, public, hybrid, or multi-cloud environments. EDB PostgreSQL for Kubernetes adheres to DevOps principles and concepts such as declarative configuration and immutable infrastructure.

- [EDB Postgres Advanced Server AMI](https://www.enterprisedb.com/docs/epas/15/planning/deployment_options/aws_epas/), which is an Amazon Machine Image containing EDB Postgres Advanced Server. It's available from Amazon Marketplace.

- Native packages or installers. See [Installing EDB Postgres Advanced Server](https://www.enterprisedb.com/docs/epas/latest/installing/).

* [Deploying from an AMI](https://www.enterprisedb.com/docs/epas/15/planning/deployment_options/aws_epas/): EDB Postgres Advanced Server Amazon Machine Image (AMI) is a preconfigured template with EDB Postgres Advanced Server installed on RHEL 8. You can purchase the EDB Postgres Advanced Server AMI from Amazon Marketplace.
