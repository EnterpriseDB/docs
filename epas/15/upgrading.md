# EDB Postgres Advanced Server upgrade

Upgrading EDB Postgres Advanced Server involves:

- `pg_upgrade` to upgrade from an earlier version of EDB Postgres Advanced Server to the latest version.
- `yum` to perform a minor version upgrade on a Linux host.
- `StackBuilder Plus` to perform a minor version upgrade on a Windows host.

* [Upgrade considerations](https://www.enterprisedb.com/docs/epas/15/upgrading/03_limitations/): Outlines the requirements and limitations to review prior to upgrading
* [Upgrading an installation with pg\_upgrade](https://www.enterprisedb.com/docs/epas/15/upgrading/04_upgrading_an_installation_with_pg_upgrade/): Describes using pg\_upgrade to migrate from an earlier version of EDB Postgres Advanced Server to the newest version
* [Performing a minor version update of an RPM installation](https://www.enterprisedb.com/docs/epas/15/upgrading/05_performing_a_minor_version_update_of_an_rpm_installation/): For RPM package installs, how to perform a minor version upgrade to a more recent version
* [Using StackBuilder Plus to perform a minor version update](https://www.enterprisedb.com/docs/epas/15/upgrading/06_using_stackbuilder_plus_to_perform_a_minor_version_update/): How to use the StackBuilder Plus utility to install supporting modules&#x20;
