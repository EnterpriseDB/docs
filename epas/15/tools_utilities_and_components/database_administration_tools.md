# Database administrator tools

EDB Postgres Advanced Server includes features designed to increase database administrator productivity, such as enabling DBAs to prioritize different workloads using the Resource Manager feature.

- [Tools and utilities overview](https://www.enterprisedb.com/docs/epas/15/tools_utilities_and_components/database_administration_tools/09_tools_and_utilities/): Provides an overview of the supported Oracle compatible tools and utility programs

- [EDB\*Loader](https://www.enterprisedb.com/docs/epas/15/tools_utilities_and_components/database_administration_tools/edb_loader_overview/): Provides an overview of the EDB\*Loader high-performance bulk data loader
