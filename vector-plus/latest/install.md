# Installing Vector Plus

Vector Plus installs as a Postgres extension from an EDB package repository. Follow the steps below to get started. See [Supported versions and platforms](https://www.enterprisedb.com/docs/vector-plus/latest/overview/supported-platforms/) for which Postgres versions, variants, and operating systems are supported.

- [Installing Vector Plus](https://www.enterprisedb.com/docs/vector-plus/latest/install/installing/)
- [Configuring Vector Plus](https://www.enterprisedb.com/docs/vector-plus/latest/install/configuring/)
