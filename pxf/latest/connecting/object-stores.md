# Connecting to an object store

Configure a server for your object store, then read and write its data through external tables.

- [S3-compatible object stores](https://www.enterprisedb.com/docs/pxf/latest/connecting/object-stores/s3/): Amazon S3 and MinIO.
- [Azure](https://www.enterprisedb.com/docs/pxf/latest/connecting/object-stores/azure/): Azure Blob Storage and Azure Data Lake Storage.
- [Google Cloud Storage](https://www.enterprisedb.com/docs/pxf/latest/connecting/object-stores/gcs/).

* [Azure](https://www.enterprisedb.com/docs/pxf/latest/connecting/object-stores/azure/): Configure PXF to read and write data in Azure Blob Storage or Azure Data Lake Storage, and query it from WarehousePG.
* [Google Cloud Storage](https://www.enterprisedb.com/docs/pxf/latest/connecting/object-stores/gcs/): Configure PXF to read and write data in Google Cloud Storage, and query it from WarehousePG.
* [S3-compatible stores](https://www.enterprisedb.com/docs/pxf/latest/connecting/object-stores/s3/): Configure PXF to read and write data in Amazon S3 or MinIO, and query it from WarehousePG.
