# Deployment options

The deployment options include:

- [Installing](https://www.enterprisedb.com/docs/pge/17/installing/) on a virtual machine or physical server using native packages

- Deploying it with [EDB Postgres Distributed](https://www.enterprisedb.com/docs/pgd/latest/)

- Deploying it on [EDB Postgres AI Cloud Service](https://www.enterprisedb.com/docs/edb-postgres-ai/cloud-service/) with extreme-high-availability cluster types
