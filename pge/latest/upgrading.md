# Upgrading EDB Postgres Extended Server

You can upgrade EDB Postgres Extended Server installations to a more recent version.

- See [Upgrading a major version of EDB Postgres Extended Server](https://www.enterprisedb.com/docs/pge/latest/upgrading/major_upgrade/) for a major upgrade example.

- See [Upgrading a minor version of EDB Postgres Extended Server](https://www.enterprisedb.com/docs/pge/latest/upgrading/minor_upgrade/) for minor upgrade examples according to your package format.

- See [Migrating from PostgreSQL](https://www.enterprisedb.com/docs/pge/latest/upgrading/postgresql_migration/) if you're moving an existing community PostgreSQL cluster to EDB Postgres Extended Server. If you also want to enable [transparent data encryption](https://www.enterprisedb.com/docs/edb-postgres-ai/platforms-and-tools/security/tde/) as part of that migration, see [Migrating from PostgreSQL to Enterprise Postgres](https://www.enterprisedb.com/docs/edb-postgres-ai/platforms-and-tools/security/tde/postgres_to_extended/) instead.

  For the full set of `pg_upgrade` options relevant to encrypted clusters, see [pg\_upgrade TDE options](https://www.enterprisedb.com/docs/edb-postgres-ai/platforms-and-tools/security/tde/reference/pg_upgrade_arguments/).

* [Major upgrades](https://www.enterprisedb.com/docs/pge/latest/upgrading/major_upgrade/): Perform a major version upgrade of EDB Postgres Extended Server.
* [Minor upgrades](https://www.enterprisedb.com/docs/pge/latest/upgrading/minor_upgrade/): Minor version upgrade of EDB Postgres Extended Server
* [Migrating from PostgreSQL](https://www.enterprisedb.com/docs/pge/latest/upgrading/postgresql_migration/): Use pg\_upgrade to migrate an existing community PostgreSQL cluster to EDB Postgres Extended Server.
