# Enterprise Postgres (EDB Postgres Extended Server)

Enterprise Postgres, also known as EDB Postgres Extended Server, is a Postgres database server distribution built on open-source, community PostgreSQL. It's fully compatible with PostgreSQL. If you have applications written and tested to work with PostgreSQL, they will behave the same with Enterprise Postgres. We will support and fix any functionality or behavior differences between community PostgreSQL and Enterprise Postgres.

Enterprise Postgres's primary purpose is to extend PostgreSQL with a limited number of features that can't be implemented as extensions, such as [enhanced replication optimization](https://www.enterprisedb.com/docs/pge/16/replication/) used by [EDB Postgres Distributed](https://www.enterprisedb.com/docs/pgd/latest/) and [Transparent Data Encryption](https://www.enterprisedb.com/docs/edb-postgres-ai/platforms-and-tools/security/tde/), while maintaining parity in other respects.

Additional value-add enterprise features include:

- Security though [Transparent Data Encryption](https://www.enterprisedb.com/docs/edb-postgres-ai/platforms-and-tools/security/tde/)

- [WAL pacing delays to avoid flooding transaction logs](https://www.enterprisedb.com/docs/pge/16/operation/#avoid-flooding-transaction-logs)

- [Additional tracing and diagnostics options](https://www.enterprisedb.com/docs/pge/16/operation/#additional-tracing-and-diagnostics-options)
