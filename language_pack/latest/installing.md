# Installing Language Packs

Select a link to access the applicable installation information:

- [Linux](https://www.enterprisedb.com/docs/language_pack/latest/installing/linux/)
- [Windows](https://www.enterprisedb.com/docs/language_pack/latest/installing/windows/)
- [MacOS](https://www.enterprisedb.com/docs/language_pack/latest/installing/macos/)

* [On Linux](https://www.enterprisedb.com/docs/language_pack/latest/installing/linux/): Installing with EDB Postgres Advanced Server
* [On Windows](https://www.enterprisedb.com/docs/language_pack/latest/installing/windows/): On Windows, EDB provides a graphical interactive installer for Language Pack. Use Stack Builder (with PostgreSQL) or StackBuilder Plus (with EDB Postgres Advanced Server) to download the EDB installer package and then invoke the graphical installer for Language Pack.  See Using Stack Builder or StackBuilder Plus.
* [On MacOS](https://www.enterprisedb.com/docs/language_pack/latest/installing/macos/): On MacOS, EDB provides a graphical interactive installer for Language Pack. To access the graphical installer, install Stack Builder as part of a PostgreSQL installation, and then use Stack Builder to invoke the graphical installer.
