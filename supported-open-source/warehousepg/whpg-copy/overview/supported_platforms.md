# Supported platforms

WarehousePG Copy is compatible with the following versions of WarehousePG:

- WarehousePG (WHPG) version 6.x running on RHEL 7 or RHEL 8.
- WarehousePG version 7.x running on RHEL 8 or RHEL 9.

WarehousePG Copy packages are built for the x86\_64 architecture, and, starting with version 1.1.0, also for the ppc64le architecture on RHEL 8 and RHEL 9.

> **Important**
>
> Migration is supported between clusters of the same version or when upgrading from WarehousePG 6.x to WarehousePG 7.x. However, downward migration from version 7.x to 6.x is not supported.
