# Overview of WarehousePG Backup and Restore

WarehousePG Backup and Restore (`whpg-backup`) creates and restores WarehousePG backup sets in parallel across the coordinator and all segment hosts.

- [Architecture](https://www.enterprisedb.com/docs/supported-open-source/warehousepg/whpg-backup/overview/architecture/): Learn how `whpg-backup` coordinates backups and restores across the coordinator and segment hosts.

- [Known issues](https://www.enterprisedb.com/docs/supported-open-source/warehousepg/whpg-backup/overview/known_issues/): Review current limitations before you deploy.
