# WarehousePG Backup and Restore 1.34.0 release notes

**Release date:** August 25, 2026

WarehousePG Backup and Restore 1.34.0 includes new features, an improvement, a bug fix, and security updates.

## Features

- **Manage backup history from the command line:** `gpbackup` adds five subcommands for inspecting and maintaining the [backup history database](https://www.enterprisedb.com/docs/supported-open-source/warehousepg/whpg-backup/using/#understanding-the-backup-history-database): `list-backups`, `find-table`, `display-report`, `delete-backup`, and `delete-backups-before`. See [Managing backup history](https://www.enterprisedb.com/docs/supported-open-source/warehousepg/whpg-backup/using/#managing-backup-history) for examples, or the [gpbackup reference](https://www.enterprisedb.com/docs/supported-open-source/warehousepg/whpg-backup/reference/gpbackup/#subcommands) for the full syntax.
- **Skip extensions on restore:** `gprestore --exclude-extension` skips restoring specific extensions, useful when the target cluster doesn't have the extension's control file installed. See the [gprestore options](https://www.enterprisedb.com/docs/supported-open-source/warehousepg/whpg-backup/reference/gprestore/#options).

## Improvements

- The backup history database now records `single_backup_dir`, `command_line`, and `object_count` for each backup. Opening an existing history database automatically adds the missing columns.

## Bug fixes

- The [S3 storage plugin](https://www.enterprisedb.com/docs/supported-open-source/warehousepg/whpg-backup/s3-plugin/) now scopes `delete_directory` operations to the configured S3 folder and rejects unsafe delete targets, such as `..` traversal.

## Security

- Updated dependencies to address known CVEs, including `golang.org/x/net`.
