# Bundled extensions

Bundled extensions ship with WarehousePG, and availability varies by version.

| Extension                                                                                                                                             | Description                                                                                                                | 6.x | 7.x |
| ----------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------- | :-: | :-: |
| `amcheck`                                                                                                                                             | Provides functions for verifying the logical consistency of indexes and heap relations.                                    |  ✓  |  —  |
| [auto\_explain](https://www.enterprisedb.com/docs/supported-open-source/warehousepg/extensions/bundled/auto-explain/)                                 | Automatically logs execution plans of slow statements.                                                                     |  ✓  |  ✓  |
| [btree\_gin](https://www.enterprisedb.com/docs/supported-open-source/warehousepg/extensions/bundled/btree_gin/)                                       | Provides GIN operator classes that implement B-tree equivalent behavior for certain data types.                            |  ✓  |  ✓  |
| [citext](https://www.enterprisedb.com/docs/supported-open-source/warehousepg/extensions/bundled/citext/)                                              | Provides a case-insensitive, multibyte-aware text data type.                                                               |  ✓  |  ✓  |
| [dblink](https://www.enterprisedb.com/docs/supported-open-source/warehousepg/extensions/bundled/dblink/)                                              | Provides connections to other WarehousePG databases.                                                                       |  ✓  |  ✓  |
| `file_fdw`                                                                                                                                            | Provides a foreign-data wrapper for accessing data files in the server's file system.                                      |  —  |  ✓  |
| [fuzzystrmatch](https://www.enterprisedb.com/docs/supported-open-source/warehousepg/extensions/bundled/fuzzystrmatch/)                                | Determines similarities and differences between strings.                                                                   |  ✓  |  ✓  |
| [gp\_array\_agg](https://www.enterprisedb.com/docs/supported-open-source/warehousepg/extensions/bundled/gp_array_agg/)                                | Implements a parallel `array_agg()` aggregate function.                                                                    |  ✓  |  —  |
| [gp\_check\_functions](https://www.enterprisedb.com/docs/supported-open-source/warehousepg/extensions/bundled/gp_check_functions/)                    | Provides views to check for orphaned and missing relation files, and a function to move orphaned files.                    |  ✓  |  —  |
| `gp_debug_numsegments`                                                                                                                                | Provides functions for testing and debugging cluster segment count behavior.                                               |  —  |  ✓  |
| `gp_distribution_policy`                                                                                                                              | Provides access to a table's distribution policy information.                                                              |  ✓  |  ✓  |
| [gp\_exttable\_fdw](https://www.enterprisedb.com/docs/supported-open-source/warehousepg/extensions/bundled/gp_exttable_fdw/)                          | Built-in foreign-data wrapper that converts an external table to a foreign table.                                          |  —  |  ✓  |
| `gp_inject_fault`                                                                                                                                     | Provides fault injection points for testing cluster fault tolerance and recovery.                                          |  —  |  ✓  |
| `gp_internal_tools`                                                                                                                                   | Provides internal diagnostic functions for WarehousePG support and engineering use.                                        |  ✓  |  ✓  |
| [gp\_legacy\_string\_agg](https://www.enterprisedb.com/docs/supported-open-source/warehousepg/extensions/bundled/gp_legacy_string_agg/)               | Implements the legacy, single-argument `string_agg()` aggregate function from WarehousePG 5.                               |  ✓  |  ✓  |
| [gp\_parallel\_retrieve\_cursor](https://www.enterprisedb.com/docs/supported-open-source/warehousepg/extensions/bundled/gp_parallel_retrieve_cursor/) | Provides extended cursor functionality to retrieve data, in parallel, directly from segments.                              |  ✓  |  —  |
| [gp\_percentile\_agg](https://www.enterprisedb.com/docs/supported-open-source/warehousepg/extensions/bundled/gp_percentile_agg/)                      | Improves GPORCA performance for ordered-set aggregate functions.                                                           |  ✓  |  —  |
| [gp\_pitr](https://www.enterprisedb.com/docs/supported-open-source/warehousepg/extensions/bundled/gp_pitr/)                                           | Supports point-in-time recovery for WarehousePG 6.                                                                         |  ✓  |  —  |
| `gp_replica_check`                                                                                                                                    | Provides functions for verifying consistency between primary and mirror segments.                                          |  —  |  ✓  |
| [gp\_sparse\_vector](https://www.enterprisedb.com/docs/supported-open-source/warehousepg/extensions/bundled/gp_sparse_vector/)                        | Implements a data type that uses compressed storage of zeros to make vector computations on floating point numbers faster. |  ✓  |  ✓  |
| [gp\_subtransaction\_overflow](https://www.enterprisedb.com/docs/supported-open-source/warehousepg/extensions/bundled/gp_subtransaction_overflow/)    | Provides a view and function for querying suboverflowed backends.                                                          |  ✓  |  —  |
| `gp_toolkit`                                                                                                                                          | Provides administrative views and functions for monitoring database status, such as skew, locks, and disk usage.           |  —  |  ✓  |
| [greenplum\_fdw](https://www.enterprisedb.com/docs/supported-open-source/warehousepg/extensions/bundled/greenplum_fdw/)                               | Foreign-data wrapper for running queries between WarehousePG clusters.                                                     |  ✓  |  —  |
| [hstore](https://www.enterprisedb.com/docs/supported-open-source/warehousepg/extensions/bundled/hstore/)                                              | Provides a data type for storing sets of key/value pairs within a single value.                                            |  ✓  |  ✓  |
| `intarray`                                                                                                                                            | Provides additional functions, operators, and index support for arrays of integers with no null elements.                  |  —  |  ✓  |
| [ip4r](https://www.enterprisedb.com/docs/supported-open-source/warehousepg/extensions/bundled/ip4r/)                                                  | Provides IPv4 and IPv6 data types, range index types, and related functions and operators.                                 |  ✓  |  —  |
| [isn](https://www.enterprisedb.com/docs/supported-open-source/warehousepg/extensions/bundled/isn/)                                                    | Provides data types for international product numbering standards (EAN13, UPC, ISBN, ISMN, ISSN).                          |  ✓  |  ✓  |
| [ltree](https://www.enterprisedb.com/docs/supported-open-source/warehousepg/extensions/bundled/ltree/)                                                | Provides data types for representing labels of data stored in a hierarchical tree-like structure.                          |  ✓  |  ✓  |
| [orafce](https://www.enterprisedb.com/docs/supported-open-source/warehousepg/extensions/bundled/orafce_ref/)                                          | Provides Oracle SQL compatibility functions.                                                                               |  ✓  |  ✓  |
| [pageinspect](https://www.enterprisedb.com/docs/supported-open-source/warehousepg/extensions/bundled/pageinspect/)                                    | Provides functions for low-level inspection of the contents of database pages. Available to superusers only.               |  ✓  |  ✓  |
| [pg\_buffercache](https://www.enterprisedb.com/docs/supported-open-source/warehousepg/extensions/bundled/pg_buffercache/)                             | Provides access to views for obtaining cluster-wide shared buffer metrics.                                                 |  —  |  ✓  |
| [pg\_cron](https://www.enterprisedb.com/docs/supported-open-source/warehousepg/extensions/bundled/pg_cron/)                                           | Cron-based job scheduler that runs inside the database.                                                                    |  ✓  |  —  |
| [pg\_hint\_plan](https://www.enterprisedb.com/docs/supported-open-source/warehousepg/extensions/bundled/pg_hint_plan/)                                | Controls the execution plan the planner chooses for a query, using hints placed in SQL comments.                           |  —  |  ✓  |
| [pg\_stat\_statements](https://www.enterprisedb.com/docs/supported-open-source/warehousepg/extensions/bundled/pg_stat_statements/)                    | Tracks execution statistics of all SQL statements. Requires `shared_preload_libraries`.                                    |  —  |  ✓  |
| [pg\_trgm](https://www.enterprisedb.com/docs/supported-open-source/warehousepg/extensions/bundled/pg_trgm/)                                           | Provides functions and operators for determining the similarity of alphanumeric text based on trigram matching.            |  ✓  |  ✓  |
| [pgcrypto](https://www.enterprisedb.com/docs/supported-open-source/warehousepg/extensions/bundled/pgcrypto/)                                          | Provides cryptographic functions.                                                                                          |  ✓  |  ✓  |
| PL/Perl                                                                                                                                               | Enables writing functions and triggers in Perl.                                                                            |  ✓  |  ✓  |
| PL/pgSQL                                                                                                                                              | Enables writing functions, triggers, and procedural code in a SQL-like language.                                           |  ✓  |  ✓  |
| PL/Python                                                                                                                                             | Enables writing functions in Python.                                                                                       |  ✓  |  ✓  |
| [postgres\_fdw](https://www.enterprisedb.com/docs/supported-open-source/warehousepg/extensions/bundled/postgres_fdw/)                                 | Provides a foreign-data wrapper for accessing data stored in a remote PostgreSQL or WarehousePG database.                  |  ✓  |  ✓  |
| [sslinfo](https://www.enterprisedb.com/docs/supported-open-source/warehousepg/extensions/bundled/sslinfo/)                                            | Provides information about the SSL certificate of the current client connection.                                           |  ✓  |  ✓  |
| [tablefunc](https://www.enterprisedb.com/docs/supported-open-source/warehousepg/extensions/bundled/tablefunc/)                                        | Provides various functions that return tables (multiple rows).                                                             |  ✓  |  ✓  |
| [timestamp9](https://www.enterprisedb.com/docs/supported-open-source/warehousepg/extensions/bundled/timestamp9/)                                      | Provides an efficient, nanosecond-precision timestamp data type and related functions.                                     |  ✓  |  —  |
| [tsm\_system\_rows](https://www.enterprisedb.com/docs/supported-open-source/warehousepg/extensions/bundled/tsm_system_rows/)                          | Implements the `SYSTEM_ROWS` table sampling method for `TABLESAMPLE`.                                                      |  —  |  ✓  |
| [tsm\_system\_time](https://www.enterprisedb.com/docs/supported-open-source/warehousepg/extensions/bundled/tsm_system_time/)                          | Implements the `SYSTEM_TIME` table sampling method for `TABLESAMPLE`.                                                      |  —  |  ✓  |
| `unaccent`                                                                                                                                            | Provides a text search dictionary that removes accents from lexemes.                                                       |  —  |  ✓  |
| [uuid-ossp](https://www.enterprisedb.com/docs/supported-open-source/warehousepg/extensions/bundled/uuid-ossp/)                                        | Provides functions to generate universally unique identifiers (UUIDs).                                                     |  ✓  |  ✓  |
