# whpg\_live\_query\_plan

The `whpg_live_query_plan` extension shows the execution plan of a running query from another session, with per-node, per-segment progress. WarehousePG Enterprise Manager (WEM) 1.6 and later use the extension to show live query plans.

For the changes in each release, see the [release notes](https://www.enterprisedb.com/docs/supported-open-source/warehousepg/extensions/additional/whpg-live-query-plan/release_notes/).
