# whpg-madlib

Use whpg-madlib to run data-parallel implementations of mathematical, statistical, graph, machine learning, and deep learning methods on structured and unstructured data without moving the data out of the database. It runs inside WarehousePG itself, so you don't need to install or maintain any additional services alongside your cluster.

whpg-madlib is a fork of [Apache MADlib](http://madlib.apache.org/documentation.html), an open source library for scalable in-database analytics, with changes specific to WarehousePG. The source is in the [whpg-madlib repository](https://github.com/warehouse-pg/whpg-madlib).

To get started with whpg-madlib, see:

- [Release notes](https://www.enterprisedb.com/docs/supported-open-source/warehousepg/extensions/additional/madlib/release_notes/)
- [Installing whpg-madlib](https://www.enterprisedb.com/docs/supported-open-source/warehousepg/extensions/additional/madlib/installing/)
- [Using whpg-madlib](https://www.enterprisedb.com/docs/supported-open-source/warehousepg/extensions/additional/madlib/using/)

See [Machine learning and deep learning using MADlib](https://www.enterprisedb.com/docs/warehousepg/latest/admin_guide/analytics/madlib/) in the WarehousePG 7 analytics guide, or the [WarehousePG 6 version](https://www.enterprisedb.com/docs/warehousepg/6/admin_guide/analytics/madlib/), for an overview of the machine learning and deep learning capabilities. See the [Apache MADlib documentation](http://madlib.apache.org/documentation.html) for the full function reference.

- [Release notes](https://www.enterprisedb.com/docs/supported-open-source/warehousepg/extensions/additional/madlib/release_notes/): Release notes for the whpg-madlib extension for WarehousePG.
- [Installing whpg-madlib](https://www.enterprisedb.com/docs/supported-open-source/warehousepg/extensions/additional/madlib/installing/): Install the whpg-madlib extension for WarehousePG, add the MADlib functions to a database, and upgrade or uninstall them.
- [Using](https://www.enterprisedb.com/docs/supported-open-source/warehousepg/extensions/additional/madlib/using/): Call MADlib functions from SQL in WarehousePG, and run linear regression, association rules, and Naive Bayes classification examples.
