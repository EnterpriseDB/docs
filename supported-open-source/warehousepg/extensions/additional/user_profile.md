# user\_profile

Use the user\_profile extension to enforce password policies and protect accounts in WarehousePG (WHPG). Group roles under a profile to set password complexity, expiration, and reuse rules, lock accounts after repeated failed logins, and give users a grace period to renew an expired password. A database superuser creates and manages the profiles, and WarehousePG applies the rules to the roles associated with each profile. Failed-login locking and password expiration apply only to password logins, as described in [Limitations](https://www.enterprisedb.com/docs/supported-open-source/warehousepg/extensions/additional/user_profile/using/#limitations).
