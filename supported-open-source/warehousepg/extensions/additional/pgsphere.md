# whpg-pgsphere

> **Note: Version availability**
>
> whpg-pgsphere is available starting with WarehousePG 7.3.0.

The whpg-pgsphere extension adds spherical data types, operators, and functions to WarehousePG (WHPG). Use it to represent and query geometric objects on a sphere, including points, circles, lines, ellipses, paths, and polygons, and to compute distances, areas, and containment between them. Common use cases include astronomical positioning, such as star positions on the celestial sphere, and geographic coordinate systems, such as sites on Earth.

The WarehousePG whpg-pgsphere extension is based on the [pgSphere extension](https://github.com/postgrespro/pgsphere) for PostgreSQL. The [release notes](https://www.enterprisedb.com/docs/supported-open-source/warehousepg/extensions/additional/pgsphere/release_notes/) list the pgSphere version each release is based on. The source is in the [whpg-pgsphere repository](https://github.com/warehouse-pg/whpg-pgsphere). No WarehousePG or massively parallel processing (MPP)-specific considerations apply to the extension.
