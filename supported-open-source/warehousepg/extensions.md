# Extensions

WarehousePG ships with a set of bundled extensions that don't require a separate install, and provides additional extensions you install separately on each host before enabling them.

## Bundled extensions

Extensions that ship with WarehousePG. See the [bundled extensions](https://www.enterprisedb.com/docs/supported-open-source/warehousepg/extensions/bundled/) page for the full list, including a compatibility matrix.

## Additional extensions

Extensions you install separately on each host before enabling them. See [Additional extensions](https://www.enterprisedb.com/docs/supported-open-source/warehousepg/extensions/additional/).

- [Bundled extensions](https://www.enterprisedb.com/docs/supported-open-source/warehousepg/extensions/bundled/): Extensions that ship with WarehousePG and don't require a separate package install, with WHPG 6.x/7.x availability.
- [Additional extensions](https://www.enterprisedb.com/docs/supported-open-source/warehousepg/extensions/additional/): Open source extensions for WarehousePG that require a separate package install on each host.
