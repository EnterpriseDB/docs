# Managing queries

Find the queries that slow down your WarehousePG cluster, follow them while they run, and test the changes that fix them.

- [Monitoring and evaluating queries:](https://www.enterprisedb.com/docs/supported-open-source/warehousepg/wem/queries/query-monitor/) Track real-time SQL execution to identify bottlenecks and use the editor to test query logic or performance improvements.

- [Viewing query plans:](https://www.enterprisedb.com/docs/supported-open-source/warehousepg/wem/queries/live-query-plan/) Follow the execution plan, processes, and disk I/O of a running query to find skew and stuck processes while the query runs.

* [Monitoring and evaluating queries](https://www.enterprisedb.com/docs/supported-open-source/warehousepg/wem/queries/query-monitor/): Monitor active workloads, execute SQL, and leverage AI-driven optimization tools.
* [Viewing query plans](https://www.enterprisedb.com/docs/supported-open-source/warehousepg/wem/queries/live-query-plan/): Watch the execution plan, processes, and disk I/O of a running query in WarehousePG Enterprise Manager, and find skew and stuck processes while the query runs.
