# Optimizing system performance

Tune the workload and infrastructure to ensure consistent, high-speed execution and system continuity.

- [Managing system resources:](https://www.enterprisedb.com/docs/supported-open-source/warehousepg/wem/performance/managing-resources/) Control CPU and memory boundaries via resource groups and resource queues to prevent contention.

- [Analyzing data distribution:](https://www.enterprisedb.com/docs/supported-open-source/warehousepg/wem/performance/data-analysis/) Investigate table statistics, data skew, and bloat to improve query execution plans.

- [Planning storage capacity:](https://www.enterprisedb.com/docs/supported-open-source/warehousepg/wem/performance/storage/) Monitor disk utilization and historical growth trends across all hosts to prevent "disk full" events.

* [Managing system resources](https://www.enterprisedb.com/docs/supported-open-source/warehousepg/wem/performance/managing-resources/): Configure and monitor CPU, memory, and concurrency limits to optimize workload performance for resource groups and resource queues.
* [Analyzing data distribution](https://www.enterprisedb.com/docs/supported-open-source/warehousepg/wem/performance/data-analysis/): Explore database structures, monitor storage health, and optimize performance metrics.
* [Planning storage capacity](https://www.enterprisedb.com/docs/supported-open-source/warehousepg/wem/performance/storage/): Monitor disk capacity, usage distribution, and historical growth across the WarehousePG cluster.
