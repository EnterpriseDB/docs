# CVE-2026-62155 - mongo\_fdw connection URI injection through unencoded option values

First Published: 2026/11/25

Last Updated: 2026/11/25

## Summary

mongo\_fdw builds the mongodb:// connection URI by inserting option values without percent-encoding them, so URI metacharacters (@ : / ? # & =) in a value are parsed as part of the URI structure. A role that is not a superuser but has USAGE on a foreign server can set the username and password options in its own user mapping. An @ or other metacharacter in those values can point the connection at a host the attacker controls, allowing connection redirection, credential capture and man-in-the-middle attacks. Server-level options such as the address, database and replica set can be injected the same way.

## Affected products and versions

- Affected Product: MongoDB Foreign Data Wrapper (mongo\_fdw)
- Affected Versions: mongo\_fdw 5.5.3 and earlier, on all supported PostgreSQL and EDB Postgres Advanced Server versions

## Remediation/fixes

Impacted users must upgrade to mongo\_fdw 5.6.0 or later. From mongo\_fdw 5.6.0, mongo\_fdw builds the URI with the libmongoc URI API, which encodes credentials, and rejects URI metacharacters in the other option values.

| Product    | VRMF              | Remediation/First Fix               |
| ---------- | ----------------- | ----------------------------------- |
| mongo\_fdw | 5.5.3 and earlier | Update to mongo\_fdw 5.6.0 or later |

## Mitigation

Until you can upgrade, reduce exposure as follows:

- Revoke USAGE on mongo\_fdw foreign servers from roles that are not trusted.
- Review user mappings for usernames or passwords that contain @, :, /, ?, # or & characters.
