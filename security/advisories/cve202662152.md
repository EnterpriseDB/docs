# CVE-2026-62152 - mysql\_fdw allows non-superusers to set connection options that run SQL and read server files

First Published: 2026/11/25

Last Updated: 2026/11/25

## Summary

mysql\_fdw accepts several security-sensitive connection options from roles that are not superusers. A role with USAGE on the mysql\_fdw foreign data wrapper can set init\_command, which runs arbitrary SQL on the remote MySQL server at every connection, including connections made with other users' mappings on a shared foreign server. The same role can set mysql\_default\_file, ssl\_key, ssl\_cert, ssl\_ca and ssl\_capath, which name files read from the PostgreSQL server host, allowing server-side file reads and connection redirection.

## Vulnerability details

CVE-ID: [CVE-2026-62152](https://nvd.nist.gov/vuln/detail/CVE-2026-62152)

CVSS Base Score: 5.8 Medium

CVSS Temporal Score: Undefined

CVSS Environmental Score: Undefined

CVSS Vector: CVSS:4.0/AV:N/AC:L/AT:P/PR:L/UI:N/VC:L/VI:N/VA:N/SC:H/SI:H/SA:H

## Affected products and versions

- Affected Product: MySQL Foreign Data Wrapper (mysql\_fdw)
- Affected Versions: mysql\_fdw 2.9.3 and earlier, on all supported PostgreSQL and EDB Postgres Advanced Server versions

## Remediation/fixes

Impacted users must upgrade to mysql\_fdw 2.10.0 or later. From mysql\_fdw 2.10.0, only superusers can set init\_command, mysql\_default\_file, ssl\_key, ssl\_cert, ssl\_ca and ssl\_capath.

| Product    | VRMF              | Remediation/First Fix                |
| ---------- | ----------------- | ------------------------------------ |
| mysql\_fdw | 2.9.3 and earlier | Update to mysql\_fdw 2.10.0 or later |

## Mitigation

Until you can upgrade, reduce exposure as follows:

- Revoke USAGE on the mysql\_fdw foreign data wrapper from roles that are not trusted.
- Review existing foreign servers for these options set by roles that are not superusers.
