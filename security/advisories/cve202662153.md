# CVE-2026-62153 - mysql\_fdw SQL injection through ANALYZE, IMPORT FOREIGN SCHEMA and the sql\_mode option

First Published: 2026/11/25

Last Updated: 2026/11/25

## Summary

mysql\_fdw inserts several values into statements sent to the remote MySQL server without escaping them: the dbname and table\_name options in ANALYZE, the remote schema name and the LIMIT TO and EXCEPT table names in IMPORT FOREIGN SCHEMA, and the sql\_mode option in the SET sql\_mode command. A user who can create or alter foreign tables or foreign servers, or run IMPORT FOREIGN SCHEMA, can break out of the string literal and run arbitrary SQL on the remote MySQL server with the credentials of the user mapping.

CVSS Temporal Score: Undefined

CVSS Vector: CVSS:4.0/AV:N/AC:L/AT:N/PR:H/UI:N/VC:N/VI:N/VA:N/SC:H/SI:H/SA:H

## Affected products and versions

- Affected Product: MySQL Foreign Data Wrapper (mysql\_fdw)
- Affected Versions: mysql\_fdw 2.9.3 and earlier, on all supported PostgreSQL and EDB Postgres Advanced Server versions

## Remediation/fixes

Impacted users must upgrade to mysql\_fdw 2.10.0 or later. From mysql\_fdw 2.10.0, mysql\_fdw escapes these names and accepts only letters, digits, underscores and commas in sql\_mode.

| Product    | VRMF              | Remediation/First Fix                |
| ---------- | ----------------- | ------------------------------------ |
| mysql\_fdw | 2.9.3 and earlier | Update to mysql\_fdw 2.10.0 or later |

## Mitigation

Until you can upgrade, reduce exposure as follows:

- Limit who can create or alter mysql\_fdw foreign tables and foreign servers.
- Grant the MySQL account used in user mappings only the privileges the foreign tables need.
