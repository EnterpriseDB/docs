# CVE-2026-132662 - PEM SQL Profiler path traversal

First Published: 2026/11/19

Last Updated: 2026/11/19

## Summary

The SQL Profiler save and load functions in the PEM web application do not keep the client-supplied file name inside the user's storage directory. A user with the SQL Profiler role (pem\_comp\_sqlprofiler) can read JSON files, and overwrite files that the PEM web server account can write, outside their own storage directory. Overwriting the PEM web application's configuration database stops the web console for all users.

## Vulnerability details

CVE-ID: [CVE-2026-132662](https://nvd.nist.gov/vuln/detail/CVE-2026-132662)

CVSS Base Score: 7.2 High

CVSS Temporal Score: Undefined

CVSS Environmental Score: Undefined

CVSS Vector: CVSS:4.0/AV:N/AC:L/AT:N/PR:L/UI:N/VC:L/VI:L/VA:H/SC:N/SI:N/SA:N

## Affected products and versions

- Affected Product: Postgres Enterprise Manager (PEM)
- Affected Versions: PEM 7.0.0 and later versions prior to PEM 10.6.1

## Remediation/fixes

Impacted users must upgrade to PEM 10.6.1 or later. From PEM 10.6.1, the SQL Profiler only reads and writes files inside the user's storage directory.

| Product | VRMF                                             | Remediation/First Fix         |
| ------- | ------------------------------------------------ | ----------------------------- |
| PEM     | PEM 7.0.0 and later versions prior to PEM 10.6.1 | Update to PEM 10.6.1 or later |

PEM 9.8 is end of life and will not receive a fix. PEM 9.x users must upgrade to PEM 10.6.1 or later.

## Mitigation

Until you can upgrade, reduce exposure as follows:

- Grant the pem\_comp\_sqlprofiler role only to trusted users.
