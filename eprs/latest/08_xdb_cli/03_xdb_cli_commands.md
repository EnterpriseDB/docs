# Replication Server CLI commands

<div id="xdb_cli_commands" class="registered_link"></div>

The CLI commands are listed here in the order in which they are typically used, following the order of Replication Server console operations.

The examples assume that the Replication Server CLI commands are executed after you make `XDB_HOME/bin` your current working directory. This configuration means you don't have to specify the full path of `XDB_HOME/bin` for each execution of the `edb-repcli.jar` file. For example, assuming Replication Server is installed in the default installation directory, you issued the following command in Linux:

`cd /usr/edb/xdb/bin`

In Windows, the equivalent is the following:

`cd C:\Program Files\edb\EnterpriseDB-xDBReplicationServer\bin`

Whenever the `repsvrfile` parameter appears in the examples, the file `~/pubsvrfile` contains the publication server login information and is located in the user’s home directory while `~/subsvrfile` contains the subscription server login information. For Windows, the equivalent usage is `%HOMEPATH%\pubsvrfile and %HOMEPATH%\subsvrfile.`

The examples are shown on a Linux system. They use the Linux continuation character, which is a backslash (`\`) to show how a Replication Server CLI command can continue onto the next line if you don't want to wrap the text in your terminal window. For Windows, use the Windows continuation character, which is a caret (`^`).

- [Getting help (help)](https://www.enterprisedb.com/docs/eprs/latest/08_xdb_cli/03_xdb_cli_commands/01_get_help/): The help command provides a syntax summary of all Replication Server CLI commands.
- [Printing the version number (version)](https://www.enterprisedb.com/docs/eprs/latest/08_xdb_cli/03_xdb_cli_commands/02_print_version/): The version command displays the Replication Server CLI version number.
- [Printing the Replication Server version number (repversion)](https://www.enterprisedb.com/docs/eprs/latest/08_xdb_cli/03_xdb_cli_commands/03_print_xdb_server_version/): The repversion command displays the Replication Server version number.
- [Encrypting passwords (encrypt)](https://www.enterprisedb.com/docs/eprs/latest/08_xdb_cli/03_xdb_cli_commands/04_encrypt_password/): The encrypt command encrypts the text supplied in an input file and writes the encrypted result to a specified output file. Use the encrypt command to generate an encrypted password to copy into a text file. This text file is referenced by a Replication Server CLI command that requires a user name and the user’s password.
- [Printing the length of time the server has been running (uptime)](https://www.enterprisedb.com/docs/eprs/latest/08_xdb_cli/03_xdb_cli_commands/05_printing_server_uptime/): The uptime command displays the time interval since the publication server was up and running.
- [Adding a publication database (addpubdb)](https://www.enterprisedb.com/docs/eprs/latest/08_xdb_cli/03_xdb_cli_commands/06_add_pub_database/): The addpubdb command adds a publication database definition.
- [Printing publication database IDs (printpubdbids)](https://www.enterprisedb.com/docs/eprs/latest/08_xdb_cli/03_xdb_cli_commands/07_printing_pub_db_id/): The printpubdbids command displays the publication database IDs of the publication database definitions.
- [Printing publication database details (printpubdbidsdetails)](https://www.enterprisedb.com/docs/eprs/latest/08_xdb_cli/03_xdb_cli_commands/08_printing_pub_db_details/): The printpubdbidsdetails command displays the connection information for each publication database definition.
- [Printing the controller database ID (printcontrollerdbid)](https://www.enterprisedb.com/docs/eprs/latest/08_xdb_cli/03_xdb_cli_commands/09_printing_controller_db_id/): The printcontrollerdbid command displays the publication database ID of the controller database.
- [Printing the primary definition node database ID (printpdndbid)](https://www.enterprisedb.com/docs/eprs/latest/08_xdb_cli/03_xdb_cli_commands/10_printing_pdn_node_db_id/): For MMR only: The printmdndbid command prints the publication database ID of the primary definition node.
- [Updating a publication database (updatepubdb)](https://www.enterprisedb.com/docs/eprs/latest/08_xdb_cli/03_xdb_cli_commands/11_updating_publication_database/): The updatepubdb command lets you change the connection information for an existing publication database definition identified by its publication database ID.
- [Removing a publication database (removepubdb)](https://www.enterprisedb.com/docs/eprs/latest/08_xdb_cli/03_xdb_cli_commands/12_removing_publication_database/): The removepubdb command removes a publication database definition.
- [Get tables for a new publication (gettablesfornewpub)](https://www.enterprisedb.com/docs/eprs/latest/08_xdb_cli/03_xdb_cli_commands/13_get_tables_for_new_publication/): The gettablesfornewpub command lists the tables and views available for including in a new publication from a given publication database definition.
- [Creating a publication (createpub)](https://www.enterprisedb.com/docs/eprs/latest/08_xdb_cli/03_xdb_cli_commands/14_creating_publication_cli/): The createpub command creates a publication.
- [Printing a list of publications (printpublist)](https://www.enterprisedb.com/docs/eprs/latest/08_xdb_cli/03_xdb_cli_commands/15_print_publications_list/): The printpublist command displays a list of publication names.
- [Printing a list of tables in a publication (printpublishedtables)](https://www.enterprisedb.com/docs/eprs/latest/08_xdb_cli/03_xdb_cli_commands/16_print_publications_tables_list/): The printpublishedtables command displays a list of tables and views that belong to the given publication.
- [Printing a list of filters in a publication (printpubfilterslist)](https://www.enterprisedb.com/docs/eprs/latest/08_xdb_cli/03_xdb_cli_commands/17_print_publications_filters_list/): The printpubfilterslist command displays a list of table filters defined in the given publication.
- [Adding tables to a publication (addtablesintopub)](https://www.enterprisedb.com/docs/eprs/latest/08_xdb_cli/03_xdb_cli_commands/18_adding_tables_to_publication/): The addtablesintopub command adds tables or views into an existing publication.
- [Removing tables from a publication (removetablesfrompub)](https://www.enterprisedb.com/docs/eprs/latest/08_xdb_cli/03_xdb_cli_commands/19_removing_tables_from_publication/): The removetablesfrompub command removes tables from a publication.
- [Adding table filters to a publication (addfilter)](https://www.enterprisedb.com/docs/eprs/latest/08_xdb_cli/03_xdb_cli_commands/20_adding_tablefilters_to_publication/): The addfilter command adds the definition of table filter rules to the specified publication. This addition makes the filter rules available to enable later on target subscriptions or non-MDN nodes.
- [Updating table filters in a publication (updatefilter)](https://www.enterprisedb.com/docs/eprs/latest/08_xdb_cli/03_xdb_cli_commands/21_updating_tablefilters_to_publication/): The updatefilter command changes the filter clauses of the specified tables or views.
- [Removing a table filter from a publication (removefilter)](https://www.enterprisedb.com/docs/eprs/latest/08_xdb_cli/03_xdb_cli_commands/22_removing_tablefilters_to_publication/): The removefilter command removes the table filter from the specified publication.
- [Printing the conflict resolution strategy (printconfresolutionstrategy)](https://www.enterprisedb.com/docs/eprs/latest/08_xdb_cli/03_xdb_cli_commands/23_print_conflict_resolution_strategy/): For MMR only: The printconfresolutionstrategy command displays the conflict resolution strategy and the standby conflict resolution strategy of the specified table.
- [Updating the conflict resolution strategy (updateconfresolutionstrategy)](https://www.enterprisedb.com/docs/eprs/latest/08_xdb_cli/03_xdb_cli_commands/24_updating_conflict_resolution_strategy/): For MMR only: The updateconfresolutionstrategy command changes the conflict resolution strategy or standby conflict resolution strategy of the specified table.
- [Setting the master definition node (setasmdn)](https://www.enterprisedb.com/docs/eprs/latest/08_xdb_cli/03_xdb_cli_commands/25_set_pdn_node/): For MMR only: The setasmdn command sets a primary node to the role of master definition node.
- [Setting the controller (setascontroller)](https://www.enterprisedb.com/docs/eprs/latest/08_xdb_cli/03_xdb_cli_commands/26_set_controller/): The setascontroller command designates a publication database as the controller database. The publication database can be the primary database of a single-master replication system or a primary node of a multi-master replication system.
- [Validating a publication (validatepub)](https://www.enterprisedb.com/docs/eprs/latest/08_xdb_cli/03_xdb_cli_commands/27_validate_a_publication/): The validatepub command checks whether any of the definitions of the tables in the given publication changed since the publication was created.
- [Validating all publications (validatepubs)](https://www.enterprisedb.com/docs/eprs/latest/08_xdb_cli/03_xdb_cli_commands/28_validate_all_publications/): The validatepubs command checks whether any of the definitions of the tables subordinate to the given publication database definition changed since the publication was created.
- [Removing a publication (removepub)](https://www.enterprisedb.com/docs/eprs/latest/08_xdb_cli/03_xdb_cli_commands/29_removing_a_publication/): The removepub command removes one or more publications.
- [Replicating DDL changes (replicateddl)](https://www.enterprisedb.com/docs/eprs/latest/08_xdb_cli/03_xdb_cli_commands/30_replicating_ddl_changes_cli/): The replicateddl command applies an ALTER TABLE statement to a publication table in all databases of a replication system. It also updates the Replication Server insert/update/delete triggers and shadow table associated with that publication table.
- [Adding a subscription database (addsubdb)](https://www.enterprisedb.com/docs/eprs/latest/08_xdb_cli/03_xdb_cli_commands/31_adding_subscription_db/): For SMR only: The addsubdb command adds a subscription database definition.
- [Printing subscription database IDs (printsubdbids)](https://www.enterprisedb.com/docs/eprs/latest/08_xdb_cli/03_xdb_cli_commands/32_printing_subscription_db_id/): For SMR only: The printsubdbids command displays the subscription database IDs of the subscription database definitions.
- [Printing Subscription Database Details (printsubdbidsdetails)](https://www.enterprisedb.com/docs/eprs/latest/08_xdb_cli/03_xdb_cli_commands/33_printing_subscription_db_details/): For SMR only: The printsubdbidsdetails command prints the connection information for each subscription database definition.
- [Updating a subscription database (updatesubdb)](https://www.enterprisedb.com/docs/eprs/latest/08_xdb_cli/03_xdb_cli_commands/34_updating_subscription_database_cli/): For SMR only: The updatesubdb command lets you change the connection information for an existing subscription database definition identified by its subscription database ID.
- [Removing a subscription database (removesubdb)](https://www.enterprisedb.com/docs/eprs/latest/08_xdb_cli/03_xdb_cli_commands/35_removing_subscription_database_cli/): For SMR only: The removesubdb command removes a subscription database definition.
- [Creating a subscription (createsub)](https://www.enterprisedb.com/docs/eprs/latest/08_xdb_cli/03_xdb_cli_commands/36_creating_subscription_cli/): For SMR only: The createsub command creates a new subscription.
- [Printing a subscription list (printsublist)](https://www.enterprisedb.com/docs/eprs/latest/08_xdb_cli/03_xdb_cli_commands/37_print_subscription_list/): For SMR only: The printsublist command displays a list of subscription names.
- [Printing the column mappings added to a publication (printusercolmapping)](https://www.enterprisedb.com/docs/eprs/latest/08_xdb_cli/03_xdb_cli_commands/37a_print_column_mappings_publication/): For SMR only: The printusercolmapping command prints column data type mapping between the publication and subscription database.
- [Enabling filters on a subscription or non-MDN node (enablefilter)](https://www.enterprisedb.com/docs/eprs/latest/08_xdb_cli/03_xdb_cli_commands/38_enable_filters_on_subscription_or_non_pdn_node/): The enablefilter command enables one or more filter rules on a single-master replication system subscription or on a multi-master replication system primary node other than the primary definition node.
- [Disabling filters on a subscription or non-MDN node (disablefilter)](https://www.enterprisedb.com/docs/eprs/latest/08_xdb_cli/03_xdb_cli_commands/39_disable_filters_on_subscription_or_non_pdn_node/): The disablefilter command disables one or more filter rules on a single-master replication system subscription or on a multi-master replication system primary node other than the primary definition node.
- [Taking a single-master snapshot (dosnapshot)](https://www.enterprisedb.com/docs/eprs/latest/08_xdb_cli/03_xdb_cli_commands/40_taking_smr_snapshot/): For SMR only: The dosnapshot command performs snapshot synchronization on the specified subscription in a single-master replication system.
- [Take a multi-master snapshot (dommrsnapshot)](https://www.enterprisedb.com/docs/eprs/latest/08_xdb_cli/03_xdb_cli_commands/41_taking_mmr_snapshot/): For MMR only: The dommrsnapshot command performs snapshot synchronization on the specified primary node in a multi-master replication system.
- [Performing a synchronization (dosynchronize)](https://www.enterprisedb.com/docs/eprs/latest/08_xdb_cli/03_xdb_cli_commands/42_perform_synchronization/): The dosynchronize command performs synchronization replication on the specified subscription for a single-master replication system or for an entire multi-master replication system.
- [Configuring a single-master schedule (confschedule)](https://www.enterprisedb.com/docs/eprs/latest/08_xdb_cli/03_xdb_cli_commands/43_configure_smr_schedule/): For SMR only: The confschedule command creates a schedule for when to start recurring replications for a single-master replication system.
- [Configuring a multi-master schedule (confschedulemmr)](https://www.enterprisedb.com/docs/eprs/latest/08_xdb_cli/03_xdb_cli_commands/44_configure_mmr_schedule/): For MMR only: The confschedulemmr command creates a schedule for when to start recurring replications for a multi-master replication system.
- [Print schedule (printschedule)](https://www.enterprisedb.com/docs/eprs/latest/08_xdb_cli/03_xdb_cli_commands/45_print_schedule/): The printschedule command displays a recurring replication schedule.
- [Updating a subscription (updatesub)](https://www.enterprisedb.com/docs/eprs/latest/08_xdb_cli/03_xdb_cli_commands/46_updating_subscription_cli/): For SMR only: The updatesub command updates certain metadata of a given subscription. This metadata allows the subscription server to find the host running the publication server that manages the publication associated with the subscription.
- [Removing a subscription (removesub)](https://www.enterprisedb.com/docs/eprs/latest/08_xdb_cli/03_xdb_cli_commands/47_removing_subscription_cli/): For SMR only: The removesub command removes a subscription.

- [Cleaning up shadow table history (cleanshadowhistforpub)](https://www.enterprisedb.com/docs/eprs/latest/08_xdb_cli/03_xdb_cli_commands/49_clean_shadow_table_history/): The cleanshadowhistforpub command deletes the shadow table history for the specified publication.
- [Cleaning up replication history (cleanrephistoryforpub)](https://www.enterprisedb.com/docs/eprs/latest/08_xdb_cli/03_xdb_cli_commands/50_clean_replication_history/): The cleanrephistoryforpub command deletes the replication history for the specified publication.
- [Cleaning up all replication history (cleanrephistory)](https://www.enterprisedb.com/docs/eprs/latest/08_xdb_cli/03_xdb_cli_commands/51_clean_all_replication_history/): The cleanrephistory command deletes the replication history for all publications in the specified publication server.
- [Reloading the publication or subscription server configuration file (reloadconf)](https://www.enterprisedb.com/docs/eprs/latest/08_xdb_cli/03_xdb_cli_commands/52_reload_conf_file/): The reloadconf command applies any changes in the publication or subscription server configuration file (XDBHOME/etc/xdbpubserver.conf or XDBHOME/etc/xdbsubserver.conf) without restarting the server.
