# Printing the version number (version)

<div id="print_version" class="registered_link"></div>

The `version` command displays the Replication Server CLI version number.

## Synopsis:

`-version`

## Examples

```shell
$ java -jar edb-repcli.jar -version
Version: 7.0.0                      .
```
