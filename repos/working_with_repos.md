# Working with repositories

Common tasks that you may need to perform when working with EDB repositories include:

- [Directly browsing and downloading from repositories](https://www.enterprisedb.com/docs/repos/working_with_repos/directly/) so you can see what is available and, when necessary, download packages directly without installing a repository.
- [Building local mirrors](https://www.enterprisedb.com/docs/repos/working_with_repos/building_local_mirrors/) to speed up installations and reduce dependency on the EDB repositories.
- [Installing in an air-gapped environment](https://www.enterprisedb.com/docs/repos/working_with_repos/installing_airgapped/) such as a secure location at a site where the systems running EDB packages can't access the internet.
- [Integrating with configuration management tools](https://www.enterprisedb.com/docs/repos/working_with_repos/integrating/), including:
  - JFrog
  - Satellite
  - Artifactory
  - Nexus
