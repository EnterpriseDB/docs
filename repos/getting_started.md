# Getting started with repositories

You can get started with your repository using any of these approaches:

- [Use the web page](https://www.enterprisedb.com/docs/repos/getting_started/with_web/) if you have an Enterprise subscription to EDB software and want to use the web interface to guide you through downloading and installing packages.

- [Use the CLI](https://www.enterprisedb.com/docs/repos/getting_started/with_cli/) for any subscription if you want to use the CLI to install packages from EDB repositories. The CLI works for all EDB repositories and is the most flexible way to install packages.

- [Use container orchestration](https://www.enterprisedb.com/docs/repos/getting_started/with_k8s/) with EDB-provided Postgres operators and operand images, or deploy a complete EDB Postgres AI Hybrid Manager system.

> **Note**
>
> If you have a Standard or Community360 subscription or want to install packages for Postgres Distributed without using TPA, you must use the CLI. See [Getting started using repositories with the CLI](https://www.enterprisedb.com/docs/repos/getting_started/with_cli/).

- [Get your token](https://www.enterprisedb.com/docs/repos/getting_started/get_your_token/): How to get the token you need to download EDB software.
- [With the web page](https://www.enterprisedb.com/docs/repos/getting_started/with_web/): How to download and install the EDB package you need using the Repos page on the web.
- [With the CLI](https://www.enterprisedb.com/docs/repos/getting_started/with_cli/): How to download and install the EDB package you need using the CLI
- [With Kubernetes](https://www.enterprisedb.com/docs/repos/getting_started/with_k8s/): Configure your container orchestration system to pull from one of EDB's container registries.
- [Troubleshooting](https://www.enterprisedb.com/docs/repos/getting_started/troubleshooting/): How to troubleshoot your repositories and downloads when they don't work
