# Getting started using repositories with the CLI

This getting started describes how to use the CLI to download and install the EDB package you need. Using the CLI, you can install packages from any EDB repository, including `community360`, `standard`, `enterprise`, and `postgres_distributed`. The repository you can access depends on your subscription.

For a list of repositories and the subscriptions that can access them, see [Repositories by name](https://www.enterprisedb.com/docs/repos/reference/repositories_by_name/). If you don't know what your subscription is, contact your EDB account manager or support representative.

To install packages from EDB repositories using the CLI, you need to:

1. [Get your token](https://www.enterprisedb.com/docs/repos/getting_started/get_your_token/).
2. [Add your repository](https://www.enterprisedb.com/docs/repos/getting_started/with_cli/adding_edb_repositories/).
3. [Install the package you need](https://www.enterprisedb.com/docs/repos/getting_started/with_cli/install_named_package/).

Once you've mastered package installation, you can move on to [working with repositories](https://www.enterprisedb.com/docs/repos/working_with_repos/). Learn how to directly browse repositories and download packages, create local mirrors, handle air-gapped installations, and integrate with configuration management tools.

- [Add EDB repositories](https://www.enterprisedb.com/docs/repos/getting_started/with_cli/adding_edb_repositories/): How to add EDB repositories to your system using the command line
- [Installing a named package](https://www.enterprisedb.com/docs/repos/getting_started/with_cli/install_named_package/): How to install a named package from the EDB repository
