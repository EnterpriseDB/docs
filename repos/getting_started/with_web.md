# Getting started using repositories on the web

To get started, you need to have an Enterprise subscription to EDB software. The web-based version of the repository system currently supports only Enterprise subscriptions.

> **Note**
>
> If you want to install software from other EDB repositories, such as `community360` or `postgres_distributed`, you need to use the command line interface. See [Getting started using repositories with the CLI](https://www.enterprisedb.com/docs/repos/getting_started/with_cli/).

To install packages from EDB repositories using the web-based interface, you need to:

1. [Get your token](https://www.enterprisedb.com/docs/repos/getting_started/get_your_token/).
2. [Add your repository](https://www.enterprisedb.com/docs/repos/getting_started/with_web/add_your_repository/).
3. [Install the package you need](https://www.enterprisedb.com/docs/repos/getting_started/with_web/install_package/).

Once you've mastered package installation, you can move on to [working with repositories](https://www.enterprisedb.com/docs/repos/working_with_repos/). Learn how to directly browse repositories and download packages, create local mirrors, handle air-gapped installations, and integrate with configuration management tools.

- [Add your repository](https://www.enterprisedb.com/docs/repos/getting_started/with_web/add_your_repository/): How to add the EDB repository to your system
- [Installing packages](https://www.enterprisedb.com/docs/repos/getting_started/with_web/install_package/): How to install the EDB package you need
