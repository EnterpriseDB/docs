# Hybrid Manager operator release notes

The Hybrid Manager (HM) operator is released independently of Hybrid Manager itself. These release notes describe what changed in each operator release.

A single `2.x` operator supports a range of HM versions. To find the operator version that goes with the HM release you're running or upgrading to, see the [compatibility matrix](https://www.enterprisedb.com/docs/hm-operator/latest/compatibility_matrix/).

| Version                                                                                              | Release date |
| ---------------------------------------------------------------------------------------------------- | ------------ |
| [2.3.0](https://www.enterprisedb.com/docs/hm-operator/latest/rel_notes/hm-operator_2.3.0_rel_notes/) | 10 Nov 2026  |
| [2.2.0](https://www.enterprisedb.com/docs/hm-operator/latest/rel_notes/hm-operator_2.2.0_rel_notes/) | 01 Sep 2026  |
| [2.1.0](https://www.enterprisedb.com/docs/hm-operator/latest/rel_notes/hm-operator_2.1.0_rel_notes/) | 31 Jul 2026  |
| [2.0.0](https://www.enterprisedb.com/docs/hm-operator/latest/rel_notes/hm-operator_2.0.0_rel_notes/) | 04 Jun 2026  |

> **Note: Releases before 2.0.0**
>
> Before 2.0.0 the operator was versioned and released together with Hybrid Manager. Changes to those earlier versions are described in the [Hybrid Manager release notes](https://www.enterprisedb.com/docs/edb-postgres-ai/latest/hybrid-manager/release_notes/).
