title: "Migration Portal 5.1.0 release notes"
navTitle: Version 5.1.0
---

Released: 25 Aug 2026

New features, enhancements, bug fixes, and other changes in Migration Portal 5.1.0 include the following:

| Type                 | Description                                                                                                                                                                                    |
|----------------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Enhancement          | Migration Portal now flags a multi-value index as an incompatible feature.                                                                                                                    |
| Enhancement          | Added detection for Oracle `SQL_MACRO` functions (notice GN0273).                                                                                                                              |
| Enhancement          | Added support for parsing Oracle 21c window functions, including `SUM`, `OTHERS`, and quoted object names.                                                                                    |
| Enhancement          | Added Oracle 21c support for additional functions, the `DBMS_MLE` package, the `EXCEPT` set operator, and `JSON_TRANSFORM` handling.                                                          |
| Enhancement          | Migration Portal now reports `spl_check` findings on Oracle PL/SQL objects (functions, procedures, package bodies, type bodies, and triggers) as warnings instead of errors, so affected objects can still pass assessment. We still recommend that you review and fix them, since they can cause runtime errors in the migrated database. |
| Bug&nbsp;fix         | Fixed an issue in which the DDL extractor and parser didn't detect standalone DML statements that followed a failed `CREATE TABLE` statement.                                                 |
| Bug&nbsp;fix         | Fixed an issue in which the DDL extractor didn't reject chained-table syntax.                                                                                                                  |
| Bug&nbsp;fix         | Fixed several DDL extractor issues affecting Oracle 10g, including incorrect owner information reported for `SYS` built-in object-type columns.                                               |
| Bug&nbsp;fix         | Fixed an issue in which the ERH-2051 repair handler was applied to versions of EDB Postgres Advanced Server that no longer need it.                                                           |
| Bug&nbsp;fix         | Fixed an issue in which generating an assessment report for a schema with a large number of dependencies could time out or run out of memory, causing the report download to fail with an error in the Migration Portal UI. |
| Bug&nbsp;fix         | Fixed an issue in which a project could get stuck in the 'DDL file is being uploaded' state when an in-memory project failed to be created in the database, leaving the project in limbo with no way to delete it. Projects stuck in this state can now be deleted. |
| Bug&nbsp;fix         | Fixed an issue in which `spl_check` warnings were incorrectly displayed in the migration report's common failures section.                                                                     |
| Bug&nbsp;fix         | Fixed an issue in which Migration Portal didn't rewrite unconditional multi-table `INSERT ALL` statements (ERH-3017/GN0278).                                                                  |
| Bug&nbsp;fix         | Fixed an issue in which the DDL extractor didn't extract constraints on dependent tables and didn't generate names for unnamed `NOT NULL` constraints.                                        |
| Bug&nbsp;fix         | Fixed an issue in which `spl_check` reported incorrect line numbers. Line numbers are now anchored to the member-body opener.                                                                 |
| Security&nbsp;fix    | Updated the PostgreSQL driver and the `spring-boot-starter-parent` library to address CVEs.                                                                                                    |
| Security&nbsp;fix    | Updated the Netty library to resolve CVEs.                                                                                                                                                     |
| Security&nbsp;fix    | Updated the Spring Framework library to address CVEs.                                                                                                                                          |
| Security&nbsp;fix    | Updated the Spring Security library to version 6.5.11 to address CVEs.                                                                                                                         |
| Security&nbsp;fix    | Fixed several other critical CVEs.                                                                                                                                                             |
