Fix This DDL (also called AI DDL Repair) is an AI Copilot capability that automatically suggests a fix for a DDL object that fails schema assessment. It's separate from the [AI Copilot chat window](../mp_ai_copilot/) — instead of asking a question and copying an answer into your DDL yourself, you review, and then accept, edit, regenerate, or reject, a fix that AI Copilot suggests directly on the incompatible object.

!!! Note
    Fix This DDL uses a third-party AI service. Your DDL statements and the associated error messages are sent to that service to generate a suggestion. Always review a suggested fix before accepting it.
!!!

## Enable Fix This DDL

You opt in to Fix This DDL separately from the general AI Copilot chat terms and conditions.

1.  During [schema assessment](/migration_portal/latest/04_mp_migrating_database/mp_schema_assessment/), open the detail view for an incompatible object.

1.  Select **Generate AI Suggested Fix**.

1.  In the **Would you like to use AI DDL Repair?** dialog box, read the terms of use, then select the **I have read and agree to the terms of use for AI DDL Repair** checkbox.

1.  Select **Close**.

Fix This DDL is now enabled for your account. Migration Portal generates a suggestion for the object you had open. It can also generate and apply fixes automatically for other objects that already failed assessment — see [Automatically generated fixes](#automatically-generated-fixes).

## Review a suggested fix

While Migration Portal generates a suggestion, the object detail view shows **Generating AI suggested fix for this DDL…**. When the suggestion is ready, review the suggested DDL — labeled **AI Suggestion**, with the disclaimer **AI-generated — review before accepting** — then choose one of the following:

-   **Accept & Reassess**: Applies the suggested DDL to the object and reassesses it immediately. You don't need to select **Reassess** separately afterward.
-   **Edit**: Lets you modify the suggested DDL yourself before accepting it.
-   **Regenerate**: Discards the current suggestion and asks AI Copilot to try again. Optionally, describe what you'd like fixed differently, then select **Submit**.
-   **Reject**: Dismisses the suggestion without applying it. Optionally, enter a reason, then select **Submit**.

!!! Important
    Test all AI-suggested fixes to confirm the converted object behaves as expected, the same way you would for any other schema-assessment repair.
!!!

## Automatically generated fixes

After you opt in, Migration Portal can also generate and apply fixes for objects that already failed assessment, without you having to open each object individually. You'll see progress indicators in the workspace object tree while these fixes are generated.

Migration Portal only applies a fix automatically when it's confident the fix resolves the incompatibility. An object fixed this way shows a **fixed by AI** icon in the object tree. If Migration Portal isn't confident in a candidate fix, it leaves the object for you to review manually instead of applying an unverified fix — open the object and select **Generate AI Suggested Fix** to review a suggestion yourself.

## If Fix This DDL can't resolve an object

If AI Copilot can't produce a fix you're satisfied with after regenerating, or the object needs a change outside what DDL repair can suggest, resolve the object manually, or use [AI Copilot chat](../mp_ai_copilot/) or **Quick Help** instead, as described in [Performing a schema assessment](/migration_portal/latest/04_mp_migrating_database/mp_schema_assessment/).
