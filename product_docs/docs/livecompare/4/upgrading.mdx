Before you upgrade from LiveCompare 3.x to LiveCompare 4.0, review the following steps. For the complete list of changes, see the [release notes](rel_notes/livecompare_4.0.0_rel_notes).

## Before you upgrade

1.  **Finish sessions that use `ignore_nullable`.** LiveCompare 4.0 removes the `ignore_nullable` setting. LiveCompare saves settings in the output database, so you can't resume or recheck a session that was started with `ignore_nullable` after you upgrade. Finish and recheck any in-progress sessions that used the setting first.
2.  **Remove `ignore_nullable` from your configuration files.** A configuration file that still sets `ignore_nullable` exits with `EX_CONFIG`. If you relied on `ignore_nullable = off`, list the nullable columns in a [`[Comparison Key]`](settings/filters/#comparison-key) section instead.
3.  **Update your Oracle 11g settings.** For Oracle 11g, set `comparison_algorithm = full_row` and `oracle_thick_mode = on`. For more information, see [Oracle support](oracle_support/#thick-mode-oracle-instant-client).
4.  **Check your platform.** LiveCompare 4.0 supports only SLES 15 SP7 and no longer supports SLES 15 SP6. For more information, see [Requirements](requirements/#platform-requirements).
5.  **Back up the output schema if you might need to go back to 3.x.** See [Output schema upgrade](#output-schema-upgrade).

## Upgrade LiveCompare

Upgrade LiveCompare with the same method you used to install it. For details about repositories and package downloads, see [Installation](installation).

The LiveCompare 4.0 package replaces the installed 3.x package, and the `livecompare` command stays at the same path (`/usr/bin/livecompare`). You don't need to uninstall 3.x or update your `PATH`.

### Upgrade from EDB repositories

Make sure the EDB repository is configured, then upgrade the package.

RHEL, or other RPM-based distributions:

```bash
sudo dnf upgrade edb-livecompare
```

Debian, Ubuntu, or other Debian-based distributions:

```bash
sudo apt-get install --only-upgrade edb-livecompare
```

SLES 15 SP7:

```bash
sudo zypper update edb-livecompare
```

### Upgrade with a manual download

Download the LiveCompare 4.0 package from the [EnterpriseDB website](https://www.enterprisedb.com/software-downloads), then install it with your package manager, which also installs any missing dependencies, such as `edb-python312`.

RHEL, or other RPM-based distributions:

```bash
sudo dnf install ./edb-livecompare-<version>.rpm
```

Debian, Ubuntu, or other Debian-based distributions:

```bash
sudo apt-get install ./edb-livecompare-<version>.deb
```

SLES 15 SP7:

```bash
sudo zypper install edb-livecompare-<version>.rpm
```

### Verify the upgrade

Check the installed version:

```bash
livecompare --version
```

The output is `EnterpriseDB LiveCompare 4.0.0`.

## After you upgrade

1.  **Rerun earlier comparisons that might have produced incorrect results.** Rerun comparisons that used `server_side_block_hash`, Oracle `block_hash` or `row_hash` on tables larger than `buffer_size`, or a nullable comparison key. Don't apply fix DML that an earlier version generated for these comparisons.
2.  **Expect new differences on the first run.** LiveCompare 4.0 evaluates differences more consistently across comparison algorithms, so the first comparison can report differences that earlier versions didn't. Review them before you apply any fix DML. For details, see the [release notes](rel_notes/livecompare_4.0.0_rel_notes).

## Output schema upgrade

LiveCompare upgrades the output schema automatically the first time 4.0 connects to it, and the upgrade can't be undone. Afterward, LiveCompare 3.x refuses to use that schema, including to resume or recheck sessions it started itself. If you might need to go back to 3.x, back up the output schema first, or point LiveCompare 4.0 at a new [`output_schema`](settings/general/#output_schema).
