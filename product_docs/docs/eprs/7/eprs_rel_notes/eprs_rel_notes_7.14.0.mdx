navTitle: Version 7.14.0
---

Released: 25 Nov 2026

!!! Note Installer removal
Installers for Ubuntu 22 and RHEL 8 are no longer provided.
!!!

New features, enhancements, bug fixes, and other changes in Replication Server 7.14.0 include the following:

| Type         | Description                                                                                                                                                                                                                                                                                                                              | Ticket |
|--------------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|--------|
| Enhancement  | Added support for PostgreSQL 19 as a publication and subscription database in trigger-based and WAL-based replication clusters.                                                                                                                                                                                                          |        |
| Enhancement  | Added support for custom column type mappings on Oracle `CLOB`, `NCLOB`, and `BLOB` columns during incremental replication. Supported target types are `JSON`, `JSONB`, `XML`, `CHAR`, `VARCHAR`, `TEXT`, and `NAME`.                                                                                                                    |        |
| Enhancement  | Enhanced shadow table cleanup for EDB Postgres Advanced Server and SQL Server to delete entries in batches, so cleanup completes in cases where a single delete previously failed.                                                                                                                                                       | #51886 |
| Enhancement  | Enhanced Replication Server to emit periodic keepalive acknowledgements during long runs of WAL changes for non-published tables, so the replication slot's `restart_lsn` can advance.                                                                                                                                                   | #60402 |
| Enhancement  | Enhanced the data validator to compare tables by unique constraint when a table has no primary key.                                                                                                                                                                                                                                      |        |
| Enhancement  | Turned on `upsertMode` by default for single-master replication (SMR) when the target is PostgreSQL or EDB Postgres Advanced Server. Multi-master replication (MMR), and a single-master subscription attached to an MMR publication, continue to default to off. A value set explicitly in the configuration file applies in all modes. |        |
| Enhancement  | Added the `pubDBTableLockTimeout` publication server option, which sets how long Replication Server waits for a table lock when creating or enabling shadow table triggers. You can change the value with `reloadconf`.                                                                                                                  |        |
| Enhancement  | Improved sync performance on SQL Server publication databases with multiple SMR publications. New publications now use a dedicated transaction sequence, so other publications' changes are no longer tracked as pending transactions in `rrep_tx_monitor`.                                                                              | #66648 |
| Security Fix | Upgraded Apache Log4j from 2.17.1 to 2.25.5 to address [CVE-2026-34480](https://nvd.nist.gov/vuln/detail/CVE-2026-34480).                                                                                                                                                                                                                |        |
| Bug&nbsp;fix | Fixed an issue where the cleanup of shadow tables on EDB Postgres Advanced Server, PostgreSQL, and SQL Server failed because of `rrep_tx_monitor` entries.                                                                                                                                                                               | #57784 |
| Bug&nbsp;fix | Made trigger upgrades idempotent, so rerunning a trigger upgrade no longer fails.                                                                                                                                                                                                                                                        |        |
| Bug&nbsp;fix | Fixed an issue where a deadlock between the snapshot lock and the sync lock occurred when a snapshot and a synchronization ran concurrently.                                                                                                                                                                                             | #59202 |
| Bug&nbsp;fix | Fixed an issue where the `PreparedStatement` cache wasn't invalidated correctly in MMR clusters with more than two nodes, preventing efficient multi-target replication.                                                                                                                                                                 | #55820 |
| Bug&nbsp;fix | Fixed an issue on SQL Server where a multi-row DML statement failed with a unique constraint violation because the same `rrep_sync_id` was used for multiple rows.                                                                                                                                                                       |        |
| Bug&nbsp;fix | Fixed an issue where the console didn't list all publications if an error occurred while loading one of them. Replication Server now logs the error and returns the remaining publications.                                                                                                                                              | #58232 |
| Bug&nbsp;fix | Fixed an issue where WAL entries already included in a snapshot were replayed after a publication server restart, causing duplicate key violations.                                                                                                                                                                                      | #59202 |
| Bug&nbsp;fix | Fixed an issue where upsert mode didn't resolve conflicts on unique indexes when the table also had a primary key, and for tables with multiple or partial unique indexes. This fix also applies to Oracle partitioned tables.                                                                                                           | #64251 |
| Bug&nbsp;fix | Fixed an issue in WAL replication where the log sequence number (LSN) boundary check during a snapshot could skip a change that sits exactly on the snapshot boundary.                                                                                                                                                                   |        |
| Bug&nbsp;fix | Fixed an issue where partition DDL conflicts stopped replication. The `ddlConflictResolution` option now applies correctly when you set it to `skip`.                                                                                                                                                                                    |        |
| Bug&nbsp;fix | Fixed an issue where DML replication on Oracle source tables that contain `XMLType` columns failed.                                                                                                                                                                                                                                      |        |
| Bug&nbsp;fix | Fixed an issue where changes to `upsertMode`, `enableBUSForOra`, `syncLOBBatchSize`, and `txMonitorPendingThresholdTime` weren't applied by `reloadconf` and required a server restart. `reloadconf` now also applies `txSetMaxSize` and `multiTxSetSplitThreshold` changes without a restart.                                           |        |
| Bug&nbsp;fix | Fixed an issue where the `_stopPubServer.sh` script failed to stop the publication server on Java 9 and later.                                                                                                                                                                                                                           |        |
| Bug&nbsp;fix | Fixed an issue where adding a table to a publication, or other cluster changes, left the control database out of sync across nodes and caused foreign key constraint violations.                                                                                                                                                         |        |
| Bug&nbsp;fix | Fixed an issue where `addpubdb` didn't roll back the publication database entry when a later step failed, leaving orphan entries after each retry.                                                                                                                                                                                       |        |
| Bug&nbsp;fix | Fixed an issue where adding a publication table with `replicateTableSchema` set to `false` updated the control tables on the MDN only and not on the other nodes.                                                                                                                                                                        |        |
| Bug&nbsp;fix | Fixed an issue where the WAL parser re-created overlapping transaction sets after a publication server restart in MMR clusters, causing duplicate `start_rrep_sync_id` values.                                                                                                                                                           | #60693 |
| Bug&nbsp;fix | Fixed an issue where logical replication failed for tables with `GENERATED ALWAYS AS IDENTITY` columns because the replicated `INSERT` statements didn't include `OVERRIDING SYSTEM VALUE`.                                                                                                                                              |        |
| Bug&nbsp;fix | Fixed an issue where replication failed when a target node was down and the server ran on Java 17 or later.                                                                                                                                                                                                                              | #62070 |
| Bug&nbsp;fix | Fixed an issue where an MMR publication server failed to start when one of its member databases was down.                                                                                                                                                                                                                                | #62070 |
| Bug&nbsp;fix | Fixed an issue where enabling `upsertMode` overrode an explicit `defaultBatchUpdateMode=BUP` setting.                                                                                                                                                                                                                                    |        |
| Bug&nbsp;fix | Fixed an issue where synchronization failed with an ORA-00936 error on Oracle source tables whose first column is a `BLOB`, `CLOB`, or `NCLOB` column.                                                                                                                                                                                   | #64251 |
| Bug&nbsp;fix | Fixed an issue where synchronization failed with an ORA-00904 error on Oracle source tables with case-sensitive column names.                                                                                                                                                                                                            | #64568 |
| Bug&nbsp;fix | Fixed an issue where controller sync events could be replayed out of order, causing a foreign key constraint violation on a standby control database when a publication was removed, and blocking further event replication to that database.                                                                                            | #64522 |
| Bug&nbsp;fix | Fixed an issue where event IDs were issued out of order on PostgreSQL and EDB Postgres Advanced Server control databases.                                                                                                                                                                                                                | #64522 |
| Bug&nbsp;fix | Fixed an issue where replaying pending off-heap transaction sets injected one target's backlog rows into the batches of other targets.                                                                                                                                                                                                   |        |
| Bug&nbsp;fix | Fixed an issue where the systemd units didn't wait for the Replication Server stop scripts to finish when stopping a service.                                                                                                                                                                                                            |        |
| Bug&nbsp;fix | Fixed an issue where partition DDL replication failed with pgjdbc 42.7.13.                                                                                                                                                                                                                                                               |        |
| Bug&nbsp;fix | Fixed an issue on SQL Server publication databases where the list of uncommitted transaction sync IDs was truncated to 30 characters, causing an incorrect syntax error.                                                                                                                                                                 | #66648 |
| Bug&nbsp;fix | Fixed an issue in MMR WAL replication where a child partition added after its parent was published wasn't registered on all nodes.                                                                                                                                                                                                       | #65821 |
| Bug&nbsp;fix | Fixed an issue where an unusual log sequence number was repeatedly logged for different row changes in a bulk transaction on non-published tables.                                                                                                                                                                                       | #55607 |
| Bug&nbsp;fix | Fixed an issue where replication failed with a `NullPointerException` when Replication Server created a transaction query with no associated table. Replication Server now logs a warning and skips that transaction.                                                                                                                    | #55293 |
| Bug&nbsp;fix | Fixed an issue where a failed snapshot of a table added to an existing WAL-based SMR publication stopped replication of the publication's existing tables, forcing a full subscription snapshot to recover.                                                                                                                              | #67518 |
| Bug&nbsp;fix | Fixed an issue on PostgreSQL 19 where `REPACK (CONCURRENTLY)` slots were counted as used replication slots. This could cause adding a WAL-mode publication database to fail with "A replication slot is not available" even though a free slot existed, when the number of running `REPACK` operations made the count reach the limit.   |        |
| Bug&nbsp;fix | Fixed an issue where WAL-mode replication failed with `cannot TRUNCATE ... pending trigger events` when the target table also had deferred capture triggers from a trigger-mode publication.                                                                                                                                             | #64927 |
| Bug&nbsp;fix | Fixed an issue where embedded NULL bytes (`0x00`) in `CLOB` and `NCLOB` columns weren't removed by `replaceNullChar`, causing synchronization to fail with an invalid byte sequence error.                                                                                                                                               |        |
| Bug&nbsp;fix | Fixed a `NullPointerException` that could occur when replaying off-heap transaction sets after a target node recovered in an MMR cluster, caused by a partition's table ID changing during partition DDL activity on a sibling partition while the node was down.                                                                        |        |
