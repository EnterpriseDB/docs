Released: 12 Nov 2026

!!! note "Windows OpenSSL bundling"

- On Windows, EPAS 15.20.0 is bundled with OpenSSL 3.5.9.
!!!

EDB Postgres Advanced Server 15.20.0 includes the following enhancements and bug fixes:

| Type | Description | Addresses&nbsp; |
|------|-------------|-----------------|
| Upstream&nbsp;merge | Merged with community PostgreSQL 15.20. See the [PostgreSQL 15.20 release notes](https://www.postgresql.org/docs/release/15.20/) for more information. | |
| Bug&nbsp;fix | `dblink_oci` no longer sends `IS [NOT] DISTINCT FROM` predicates to Oracle, which rejects them with ORA-00908. EPAS now evaluates them locally. |  |
| Bug&nbsp;fix | Fixed `ALTER TABLE ... ADD PARTITION` so a new partition's privileges get the correct grantor when its owner differs from the root table's owner. Before, a later `REVOKE` on the partition could silently fail and leave the revoked role with access. | #61718 |
| Bug&nbsp;fix | Fixed the error `cache lookup failed for type 0` when selecting an `EXCEPTION` declared in a package (`SELECT pkg.exc`). The query now resolves as it would for any non-variable name. |  |
| Bug&nbsp;fix | Fixed a potential crash or incorrect behavior when checking access to private package variables, caused by reading a catalog cache entry after it had been released. |  |
| Bug&nbsp;fix | Fixed incorrect `--help` text in `edb-psql` and EDB\*Wrap. |  |
| Bug&nbsp;fix | `DBMS_PIPE` now encrypts message payloads on disk when Transparent Data Encryption (TDE) is enabled. Before, they were written in cleartext. |  |

See [Limitations](/epas/15/planning/planning_prerequisites/epas_limitations/) for known limitations in this release.
