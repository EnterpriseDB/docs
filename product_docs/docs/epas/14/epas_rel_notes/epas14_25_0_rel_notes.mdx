Released: 12 Nov 2026

!!! warning "End of Standard Support"
EDB Postgres Advanced Server 14 reaches End of Standard Support on December 1, 2026. We recommend planning your upgrade to a supported version.
!!!

!!! note "Windows OpenSSL and pgAdmin bundling"

- On Windows, EPAS 14.25.0 is bundled with SafeLogic OpenSSL 1.0.2zs.
- On Windows, the 14.25.0 release is bundled with pgAdmin4 version 9.19.
!!!

!!! note "Extension compatibility"
Extensions released on or after November 12, 2026, are compatible only with server versions released on or after November 12, 2026.
!!!
