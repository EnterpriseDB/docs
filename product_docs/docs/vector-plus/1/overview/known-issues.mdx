These are the currently known issues and limitations in this release of Vector Plus. These issues are actively tracked and planned for resolution in a future release.

- There's no `ALTER EXTENSION edb_vectorplus UPDATE` path yet. The extension ships a single `edb_vectorplus--<version>.sql` and no `--<from>--<to>.sql` scripts, so upgrading requires `DROP EXTENSION` / `CREATE EXTENSION`, which drops and requires rebuilding any `ivfplus` indexes. See [Installing](../install).
