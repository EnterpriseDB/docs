EDB Vector Plus (`edb_vectorplus`) is a Postgres extension that provides a new vector index type, `ivfplus`. It implements hierarchical Inverted File (IVF) clustering and RaBitQ quantization for vector search, the same general approach used by leading standalone vector databases (for example, Turbopuffer's ANN v3).

Vector Plus coexists with [pgvector](/pg_extensions/pgvector) — it uses the same `vector` type and requires pgvector 0.7.0 or newer as a dependency — but delivers higher query throughput and lower latency with a reduced CPU and memory footprint, particularly at large row counts where pgvector's `ivfflat` index becomes prohibitively slow.

It's packaged and distributed through EDB's own repositories, the same distribution model as other proprietary EDB extensions like [AIDB](/aidb/latest).

## Names at a glance

| Description                        | Name                                          |
|------------------------------------|-----------------------------------------------|
| SQL extension | `edb_vectorplus`                              |
| Index access method                | `ivfplus`                                     |
| Library / control file             | `edb_vectorplus.so`, `edb_vectorplus.control` |
| Required extension                 | `vector` (pgvector) ≥ 0.7.0                   |

## Requirements

EDB Vector Plus requires Postgres 12–19 and pgvector (`vector`) 0.7.0 or newer. EDB packages are published for Postgres 14–18. See [Supported versions and platforms](install#supported-versions-and-platforms).
