Install Vector Plus from an EDB package repository. See [Supported versions and platforms](supported-platforms) for which Postgres versions, variants, and operating systems are supported.

## Configuring the repository

Setting up the repository is a one-time task; skip this step if you've already set it up for another EDB package. Go to [EDB repositories](https://www.enterprisedb.com/repos-downloads) and follow the instructions there to configure the repository for your platform, using `EDB_REPOSITORY` per the table below to select the right repository for your subscription.

| `EDB_REPOSITORY` | Who                                                                                                     | Contains                                  |
|-------------------|-----------------------------------------------------------------------------------------------------------|-------------------------------------------|
| `enterprise`      | For EDB Postgres Advanced Server (EPAS) or EDB Postgres Extended Server (PGE) | Released packages, all three variants      |
| `standard`        | For Standard subscriptions                                                                     | Released packages                          |
| `community360`    | For Community 360                                                                                | Released packages (community Postgres)   |
| `edb`             | For IBM Z (s390x) platforms                                                                                       | The s390x channel                          |

On s390x, use `edb` instead of `enterprise` (or the equivalent of `standard`/`community360` for your subscription).

## Installing the package

Install Vector Plus, which pulls in pgvector automatically if it isn't already present. If an older pgvector is already installed, installing Vector Plus doesn't upgrade it: resolve the pgvector version manually before continuing (pgvector 0.7.0 or newer is required).

```shell
sudo dnf install -y edb-<variant><V>-vectorplus # EL
sudo zypper install -y edb-<variant><V>-vectorplus # SLES
sudo apt-get install -y edb-<variant><V>-vectorplus # Debian / Ubuntu
```

Replace `<variant>` with `pg` (community PostgreSQL), `as` (EPAS), or `postgresextended` (PGE), and `<V>` with your Postgres major version — for example, `edb-pg17-vectorplus` for PostgreSQL 17.

`<V>` is the Postgres major version. The package name carries no extension-major suffix, so it's identical on RPM and DEB:

| Postgres distribution                    | Package name                         | Installs under                               |
|-------------------------------------|--------------------------------------|----------------------------------------------|
| PostgreSQL                          | `edb-pg<V>-vectorplus`               | `/usr/pgsql-<V>` · `/usr/lib/postgresql/<V>` |
| EDB Postgres Extended (PGE)         | `edb-postgresextended<V>-vectorplus` | `/usr/edb/pge<V>` · `/usr/lib/edb-pge/<V>`   |
| EDB Postgres Advanced Server (EPAS) | `edb-as<V>-vectorplus`               | `/usr/edb/as<V>` · `/usr/lib/edb-as/<V>`     |

pgvector comes from the same repository and installs automatically as a dependency.

## Enabling the extension

Enable the extension. `CASCADE` creates pgvector's `vector` type first, which `edb_vectorplus` requires:

```sql
CREATE EXTENSION edb_vectorplus CASCADE;
```

No `shared_preload_libraries` entry and no restart are needed.

After installing the Vector Plus package, see [Quickstart](../overview/quickstart) to build your first index.
