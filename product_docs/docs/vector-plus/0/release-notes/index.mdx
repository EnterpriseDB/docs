EDB Vector Plus (`edb_vectorplus`) is EDB's Postgres extension that adds the `ivfplus` vector index type, using hierarchical IVF clustering and RaBitQ quantization for faster, lower-footprint vector search at scale. These release notes provide information on what is new in each release.
