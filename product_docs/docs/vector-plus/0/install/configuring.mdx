After [installing the Vector Plus package](installing#installing-the-package), enable the extension in each database where you want to use it.

## Enabling the extension

Enable the extension. `CASCADE` creates pgvector's `vector` type first, which `edb_vectorplus` requires:

```sql
CREATE EXTENSION edb_vectorplus CASCADE;
```

No `shared_preload_libraries` entry and no restart are needed.

After enabling the extension, see [Quickstart](../overview/quickstart) to build your first index.
