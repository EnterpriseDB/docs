WarehousePG bundles PL/pgSQL, PL/Perl, and PL/Python. It also supports PL/Java and PL/R, which you install separately.

## Enabling bundled procedural languages

The bundled languages don't require a separate install. Enable each language with `CREATE EXTENSION` in the target database:

-   [PL/pgSQL](../../../admin_guide/analytics/procedural_languages/pl_sql.mdx): `CREATE EXTENSION plpgsql;`
-   [PL/Perl](../../../admin_guide/analytics/procedural_languages/pl_perl.mdx): `CREATE EXTENSION plperl;`
-   [PL/Python](../../../admin_guide/analytics/procedural_languages/pl_python.mdx): `CREATE EXTENSION plpython3u;`

## Installing PL/Java and PL/R

Install PL/Java and PL/R on every host before you enable them. The EDB distribution of WarehousePG provides both as packages. See the installation instructions for each language, and then enable it:

-   [PL/Java](../../../admin_guide/analytics/procedural_languages/pl_java.mdx#topic4)
-   [PL/R](../../../admin_guide/analytics/procedural_languages/pl_r.mdx#topic3)

Installing PL/R also gives you access to the R Data Science Library. See [R Data Science Library](../external_components/install_r_dslib.mdx) for details.
