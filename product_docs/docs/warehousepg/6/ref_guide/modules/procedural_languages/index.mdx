Procedural languages extend WarehousePG with additional programming languages for writing functions and stored procedures.

PL/pgSQL, PL/Perl, and PL/Python are bundled with WarehousePG, so they don't require a separate install. Enable them with `CREATE EXTENSION` in the target database:

-   [PL/pgSQL](../../../admin_guide/analytics/procedural_languages/pl_sql.mdx)
-   [PL/Perl](../../../admin_guide/analytics/procedural_languages/pl_perl.mdx)
-   [PL/Python](../../../admin_guide/analytics/procedural_languages/pl_python.mdx)

Install the following languages separately on every host before you enable them:

-   [PL/Java](../../../admin_guide/analytics/procedural_languages/pl_java.mdx) - Enables writing functions in the Java programming language.
-   [PL/R](../../../admin_guide/analytics/procedural_languages/pl_r.mdx) - Enables writing functions in the R programming language.
