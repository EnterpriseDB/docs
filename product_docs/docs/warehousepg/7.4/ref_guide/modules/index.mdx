WarehousePG ships with a large set of modules and supports additional separately installed packages. They fall into four categories:

-   **[Bundled modules](/supported-open-source/warehousepg/extensions/bundled)** ship with WarehousePG and don't require a separate package install. See the reference page for the full list and WHPG 6.x/7.x compatibility.
-   **[Additional extensions](/supported-open-source/warehousepg/extensions/additional)** are packages that require a separate install on each host before you can enable them. See the reference page for the full list and WHPG 6/7.3/7.4/7.5 compatibility.
-   **[Procedural languages](procedural_languages)** extend WarehousePG with additional programming languages for writing functions and stored procedures.
-   **[External components](external_components)** are separately installed tools that integrate with WarehousePG but aren't database extensions.
