Released: 10 Aug 2026

EDB ODBC Connector 18.00.0001.01 includes the following enhancement:

|      Type      |                                                                                Description                                                                                 |
| -------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Upstream merge | Merged with the upstream community driver version 18.00.0001. See the community [Release notes](https://odbc.postgresql.org/docs/release.html) for details. |

!!!note
   If you are upgrading an earlier ODBC version on Ubuntu/Debian installation, you need to run the install command and specify the version number in the package name. For example the command for Ubuntu is:

   ```
   sudo apt-get install edb-odbc=18.00.0001.01-1.focal
   ```

   If you get a message about downgrading, you can ignore it.
