Postgres and EDB Postgres Distributed (PGD) versions supported in Hybrid Manager (HM), by cluster type and release.

This page covers LTS releases. For Innovation Releases, see the [Innovation Release version](/edb-postgres-ai/current/hybrid-manager/overview/supported_versions/).

## Postgres versions by cluster type

The versions you can select when you [create a cluster](/edb-postgres-ai/current/hybrid-manager/using_hybrid_manager/cluster_management/create-clusters/cluster-settings/) depend on the operand images in your HM installation. The HM console shows what's available in your environment.

| Distribution                        | Single node | High availability | Distributed high availability |
| ----------------------------------- | ----------- | ----------------- | ----------------------------- |
| PostgreSQL                          | 16–18       | 16–18             | Not supported                 |
| EDB Postgres Extended Server (PGE)  | 16–18       | 16–18             | 16–18                         |
| EDB Postgres Advanced Server (EPAS) | 16–18       | 16–18             | 16–18                         |

## PGD support scenarios

What HM supports for PGD clusters it provisions and for PGD clusters you run outside HM.

| Scenario                                                 | Status |
| -------------------------------------------------------- | ------ |
| HM-provisioned DHA cluster on PGD 6.x                    | Supported |
| HM-provisioned DHA cluster on PGD 5.x                    | Not supported |
| Monitoring an external PGD cluster                       | Supported on PGD 6.x. See [Monitoring external databases](/edb-postgres-ai/current/hybrid-manager/using_hybrid_manager/monitoring/mon_ext_dbs/). |
| Provisioning an external PGD cluster from HM             | Not supported. HM can only provision HM-managed clusters. |
| Upgrading from external PGD 5.9 to HM-managed PGD 6      | Not supported |
