## Overview

With your environment prepared ([Phase 4](../environment_prep)), install Hybrid Manager on the cluster. Choose the method that fits how you operate — all three produce the same running Hybrid Manager:

- **[Install on Kubernetes (operator)](install_hm)** — apply the `HybridControlPlane` custom resource with the EDB Postgres AI Operator. Best for automated, repeatable, or GitOps-managed deployments.
- **[Install with the installer console](install_hm_web_installer)** — a gated, browser-based flow that validates your cluster, assembles the `HybridControlPlane` resource from your answers, and applies it once you confirm. Best for a first installation or an evaluation.
- **[Install on Red Hat OpenShift](install_rhos)** — install through the OpenShift OperatorHub catalog.
