## Overview

The Web Installer is a guided, browser-based alternative to authoring the `HybridControlPlane` custom resource by hand. It runs in the cluster, gates on the `edb-hcp-operator`, and walks you through five screens — Prerequisites, Configure, Preflight, Install, and Postflight — assembling and applying the custom resource for you.

### Prerequisites

- A prepared environment, as described in [Preparing your environment](../environment_prep) — image-pull secret, install secrets, and object-storage secret.
- The `edb-hcp-operator` installed, as described in [Install Hybrid Manager on Kubernetes](install_hm#install-the-edb-postgres-ai-operator).

### When to use the Web Installer

Use the Web Installer for a guided first installation or an evaluation, where its validation and previews reduce manifest errors. Use the [operator manifest method](install_hm) for automated, repeatable, or GitOps-managed deployments where the `HybridControlPlane` resource is version-controlled.

### The five screens

1. **Prerequisites** — validates operator installation, nodes and labels, storage classes, the load-balancer controller, and the required secrets.
2. **Configure** — collects the values that become the `HybridControlPlane` custom resource.
3. **Preflight** — validates the referenced Kubernetes secrets before deployment.
4. **Install** — rolls out the selected components.
5. **Postflight** — runs health checks and surfaces the portal link.
