## Installing Hybrid Manager

This section contains everything you need to install and configure Hybrid Manager (HM).

- **[Quickstart](quickstart)** — The fastest supported path to a running HM using the installer console. Best for proofs of concept and evaluations.

- **[Installation guide](install_guide)** — The six-phase guide covering architecture planning through post-installation configuration. Start here for new installations.

- **[Container registry and artifact reference](registry_artifact_reference)** — Reference for the artifacts HM ships, the canonical image list, required registry layout, signing status, and network access requirements.

- **[Configuration](configuration)** — Detailed SOPs for advanced configuration topics: TLS, IdPs, KMS for TDE, multi-DC, image sync, and more.

- **[Migrate from bootstrap to operator](migrate_bootstrap_to_operator)** — For existing bootstrap installations migrating to the operator method.

- **[Troubleshooting](troubleshooting)** — Guidance for diagnosing and resolving installation issues.
