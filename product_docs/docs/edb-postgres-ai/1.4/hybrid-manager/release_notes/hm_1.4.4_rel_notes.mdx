**Release date:** October 2, 2026

Hybrid Manager (HM) 1.4.4 is a maintenance release that includes bug fixes and improvements.

!!!danger Every Postgres cluster restarts during this upgrade
This release bumps the Barman Cloud Plugin, which restarts every Postgres cluster in your estate as part of applying the HM upgrade — not on your own database maintenance schedule. If you manage a large estate and rely on scheduling platform and Postgres upgrades independently, plan for this before you upgrade.
!!!

## HM platform

- Updated the Barman Cloud Plugin to version 0.15.0 (Barman 3.20.0) to address CVE fixes. This Barman release also reworks the restore pipeline so downloading, decompressing, and extracting a compressed backup run concurrently instead of sequentially, significantly improving restore times for compressed backups stored in the cloud. See the [Barman 3.20.0 documentation](https://docs.pgbarman.org/release/3.20.0/releases/index.html) for more information.

## Observability and monitoring

- Fixed an issue whereby Grafana failed to load the Loki and Prometheus datasources, which broke the dashboard panels and **Explore** queries that depend on them.

## AI Factory

- Updated the [recognized models list](/edb-postgres-ai/1.4/hybrid-manager/using_hybrid_manager/chat_agent/configure/#recognized-models) for the HM chatbot to add newly available third-party models and remove models that are no longer supported, and refreshed documentation across PostgreSQL, EPAS, PGE, PGD, and `edbctl`.
