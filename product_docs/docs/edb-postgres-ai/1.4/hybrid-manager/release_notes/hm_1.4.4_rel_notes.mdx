**Release date:** October 1, 2026

Hybrid Manager (HM) 1.4.4 is a maintenance release that includes bug fixes and improvements.

!!!note Postgres refers to all distributions supported by EDB

-   PostgreSQL
-   EDB Enterprise Postgres - formerly, EDB Postgres Extended Server (PGE)
-   EDB Enterprise Postgres (Oracle Compatible) - formerly, EDB Postgres Advanced Server (EPAS)
!!!

## HM platform

- Updated the Barman Cloud Plugin to version 0.15.0 (Barman 3.20.0) to address CVE fixes. Upgrading to this HM version triggers a restart of every Postgres cluster. See the [Barman 3.20.0 documentation](https://docs.pgbarman.org/release/3.20.0/releases/index.html) for more information. <!-- UPM-139490 -->

## Observability and monitoring

- Fixed an issue whereby Grafana failed to load the Loki and Prometheus datasources, which broke the dashboard panels and **Explore** queries that depend on them. <!-- UPM-139526 -->

## AI Factory

- Updated the [recognized models list](/edb-postgres-ai/1.4/hybrid-manager/using_hybrid_manager/chat_agent/configure/#recognized-models) for the HM chatbot to add newly available third-party models and remove models that are no longer supported, and refreshed documentation across PostgreSQL, EPAS, PGE, PGD, and `edbctl`. <!-- UPM-139561 -->
