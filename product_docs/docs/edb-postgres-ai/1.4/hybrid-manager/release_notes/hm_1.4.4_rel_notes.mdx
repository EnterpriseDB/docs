**Release date:** October 7, 2026

Hybrid Manager (HM) 1.4.4 is a maintenance release that includes bug fixes and improvements.

!!!warning Upcoming Postgres cluster restart in 1.4.5
The next patch release (1.4.5) will include a Barman Cloud Plugin update. Upgrading to that release will restart every Postgres cluster in your estate as part of applying the upgrade. Watch the 1.4.5 release notes for details, and plan ahead if you manage a large estate with independent upgrade windows for the platform and your Postgres instances.
!!!

## Observability and monitoring

- Fixed an issue whereby Grafana failed to load the Loki and Prometheus datasources, which broke the dashboard panels and **Explore** queries that depend on them.
- Fixed an issue whereby the `fluent-bit-federated` log forwarder on Red Hat OpenShift (RHOS) multi-datacenter deployments didn't reload its SPIFFE certificate after rotation, because SELinux prevented the privileged fluent-bit container from receiving the reload signal from its spiffe-helper sidecar. Left unaddressed, this could eventually cause federated log shipping between the primary and secondary data centers to fail once the original certificate expired.

## AI Factory

- Updated the [recognized models list](/edb-postgres-ai/1.4/hybrid-manager/using_hybrid_manager/chat_agent/configure/#recognized-models) for the HM chatbot to add newly available third-party models and remove models that are no longer supported, and refreshed documentation across PostgreSQL, EPAS, PGE, PGD, and `edbctl`.
