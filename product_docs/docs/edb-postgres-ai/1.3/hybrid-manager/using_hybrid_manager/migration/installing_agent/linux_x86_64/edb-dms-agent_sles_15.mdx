## Prerequisites

Before you begin the installation process:

- Set up the EDB repository.

  Setting up the repository is a one-time task. If you already set up your repository, you don't need to perform this step.

  To determine if your repository exists, enter:

  `zypper lr -E | grep enterprisedb`

  If no output is generated, the repository is installed.

  To set up the EDB repository:

  1. Go to [EDB repositories](https://www.enterprisedb.com/repos-downloads).

  1. Select the button that provides access to the EDB repository.

  1. Select the platform and software that you want to download.

  1. Follow the instructions for setting up the EDB repository.

!!!note Air-gapped or self-managed mirrors
The DMS agent is packaged as `cdcagent`, a Java-based, architecture-independent (`noarch`) package. If you're building or syncing a local mirror of the EDB repository for an air-gapped installation, make sure the mirror includes the `noarch` package path in addition to the architecture-specific path, or `cdcagent` won't show up in your local repository. See [Building local mirrors](/repos/working_with_repos/building_local_mirrors/) and [Installing in an air-gapped environment](/repos/working_with_repos/installing_airgapped/).
!!!

## Install the package

Install the EDB DMS agent (packaged as `cdcagent`):

```shell
sudo zypper install cdcagent
```
