!!!warning Every Postgres cluster restarts during this upgrade
This release bumps the Barman Cloud Plugin, which restarts every Postgres cluster in your estate as part of applying the HM upgrade — not on your own database maintenance schedule. If you manage a large estate and rely on scheduling platform and Postgres upgrades independently, plan for this before you upgrade.
!!!

This Innovation Release includes features and enhancements.

**Release date:** 12 Nov 2026

!!!important HM now stores its management resources in the `edb-system` namespace
Starting with HM 2026.11, the HM agent (Beacon) and the app catalog (Carvel `PackageRepository`) use the `edb-system` namespace instead of `default`. The upgrade copies your existing clusters, backups, packages, and the secrets that they use to `edb-system`, then removes the old copies from `default`. If you have scripts, monitoring, or `kubectl` commands that read these resources in `default`, update them to use `edb-system`.

The upgrade doesn't move OSS Library apps that you installed before it. They keep running, and EDB recommends that you delete and recreate them. See [Apps installed before upgrading to HM 2026.11](/edb-postgres-ai/current/hybrid-manager/using_hybrid_manager/hm_overview/oss_library_apps/#apps-installed-before-upgrading-to-hm-202611).
!!!
