Agent Factory is the AI and machine learning workload in Hybrid Manager. It lets you deploy and serve NVIDIA NIM models on your own GPU infrastructure and expose model endpoints to your applications, all within your sovereign Kubernetes environment.

This page walks you through the fastest path to get something running.

## What you'll build

Agent Factory on Hybrid Manager lets you deploy a model cluster from the Model Library and expose its endpoint to your applications. Start by deploying a model cluster.

## Before you start

Complete these steps in order before you call a model endpoint.

-   Enable Agent Factory in your project: [Prerequisites](prerequisites#enabling-agent-factory)
-   Provision GPU node groups: [GPU recommendations](gpu-recommended)
-   Deploy a model cluster from the Model Library: [Deploy with HM UI](deploy-with-hm-ui)

## Access model endpoints from your applications

Any model deployed through HM exposes an OpenAI-compatible REST endpoint. You can call it directly from applications, scripts, or external tools.

-   [Access KServe endpoints](/edb-postgres-ai/1.3/ai-factory/model/access-kserve-endpoints/)
-   [Quickstart (Python)](/edb-postgres-ai/1.3/ai-factory/model/quickstart-python-using-inference-endpoint/)

Once your models are running, use HM's built-in observability to track inference latency and GPU utilization.
