!!!warning AI Factory was removed in Hybrid Manager 2026.10.1
The AI Factory documentation that used to be on this page and its subpages is no longer part of the Hybrid Manager (HM) Innovation Release.
!!!

HM 2026.10.1 removed the `ai` scenario and the components that depend on it, to address critical security vulnerabilities in Langflow:

-   Langflow
-   Visual Pipeline Builder (AI Pipelines)
-   KServe-based model serving (self-hosted models)
-   The HM chatbot (Chat Agent)

Langflow and Visual Pipeline Builder are permanently removed. The HM chatbot and support for external LLM endpoints are expected to return in a future Innovation Release and the next LTS release. For details, see the [2026.10.1 release notes](/edb-postgres-ai/latest/hybrid-manager/release_notes/hm_2026.10.1_rel_notes/#ai-factory).

## If you use HM 1.4

The AI Factory documentation is still available for HM 1.4: see [AI Factory in HM 1.4](/edb-postgres-ai/1.4/hybrid-manager/ai-factory/).
