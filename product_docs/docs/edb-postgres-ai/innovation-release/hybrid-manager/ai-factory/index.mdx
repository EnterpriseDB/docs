!!!warning AI Factory isn't part of the Hybrid Manager Innovation Release
Starting with Hybrid Manager (HM) 2026.10.1, AI Factory is no longer part of the HM Innovation Release, and its documentation is no longer included in this release stream.
!!!

For details of the change, see the [2026.10.1 release notes](/edb-postgres-ai/latest/hybrid-manager/release_notes/hm_2026.10.1_rel_notes/#ai-factory).

## If you use HM 1.4

The AI Factory documentation is still available for HM 1.4: see [AI Factory in HM 1.4](/edb-postgres-ai/1.4/hybrid-manager/ai-factory/).
