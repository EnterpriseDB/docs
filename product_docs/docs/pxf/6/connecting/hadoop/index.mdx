PXF's Hadoop connectors, the Hadoop Distributed File System (HDFS), Hive, and HBase, share the same underlying cluster configuration. Configure the connection to HDFS first if you also plan to use Hive, since Hive builds on top of it.

-   [HDFS](hdfs.mdx): Read and write files directly on HDFS.
-   [Hive](hive.mdx): Read Hive table data.
-   [HBase](hbase.mdx): Read HBase table data.
-   [Authenticating with Kerberos](kerberos.mdx): Connect to a Kerberized Hadoop cluster and configure user impersonation.
