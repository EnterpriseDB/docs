Released: 8 Oct 2026

The edbctl 1.10.0 release includes new features, improvements, bug fixes, and security fixes to enhance the functionality and performance of the Hybrid Manager (HM) CLI tool.

| Type              | Description                                                                                                                                    |
|-------------------|------------------------------------------------------------------------------------------------------------------------------------------------|
| Feature           | Added a `clickhouse-operator-credentials` secret to the `core` install-secrets scenario for Hybrid Manager 2026.10 or later, generated and replicated automatically so the ClickHouse operator no longer connects with a fixed, shared password. |
| Improvement       | Changed `edbctl hybrid-manager create-install-secrets` and `list-install-secrets` to skip, with a warning, any `--scenario` value that has no install secrets (such as `pgd`) or that edbctl doesn't recognize, instead of failing. |
| Improvement       | Changed `edbctl hybrid-manager create-install-secrets` to always generate the Langflow superuser username and password and the ClickHouse Keeper password, without asking in interactive mode. It no longer reads `EDB_AI_LANGFLOW_SUPERUSER`, `EDB_AI_LANGFLOW_SUPERUSER_PASSWORD`, or `EDB_OBSERVABILITY_CLICKHOUSE_KEEPER_PASSWORD`. Existing secrets are left unchanged. |
| Improvement       | Moved the ClickHouse Keeper credentials required by Hybrid Manager 2026.9 from the `observability` install-secrets scenario to `core`, so they're created whenever `core` is selected. |
| Improvement       | Added a `Source` column to `edbctl federation list-pairings` and a `Source` row to `edbctl federation get-pairing`, showing how each pairing was established (for example, `manual` or `adopted`). It replaces the `Adopted` row in `get-pairing`. |
| Improvement       | Updated the default latest Innovation Release (IR) version reference to v2026.10.                                                             |
| Bug&nbsp;fix      | Fixed `edbctl hybrid-manager parse-operator-logs` not showing component names next to their versions for logs from Hybrid Manager operator 2.2.0 or later. |
| Bug&nbsp;fix      | Fixed `edbctl hybrid-manager list-install-secrets` reporting that it was creating secrets when `--scenario` is omitted.                        |
| Bug&nbsp;fix      | Fixed `edbctl hybrid-manager list-install-secrets` producing unparseable `json`, `json-raw`, `yaml`, and `xml` output when `--version` is an alias such as `latest-ir` or `--scenario` is omitted. Informational messages now go to stderr. |
| Bug&nbsp;fix      | Fixed `--verify-signature` on `edbctl image sync-to-local-registry` and `edbctl image export-to-archive` rejecting EDB release images. Release images for Hybrid Manager 2026.9, 1.4.3, or later now pass verification. |
| Security&nbsp;fix | Updated third-party dependencies to resolve known vulnerabilities, including CVE-2026-63308 (Helm), CVE-2026-45404 (OpenTelemetry), and CVE-2026-33997 (Docker client). |
