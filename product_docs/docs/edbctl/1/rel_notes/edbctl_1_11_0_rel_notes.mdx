Released: 12 Nov 2026

The edbctl 1.11.0 release includes new features, improvements, and security fixes to enhance the functionality and performance of the Hybrid Manager (HM) CLI tool.

| Type              | Description                                                                                                                                    |
|-------------------|------------------------------------------------------------------------------------------------------------------------------------------------|
| Feature           | Added `edbctl hybrid-manager create-object-store` and `edbctl project create-object-store` to create the object storage secrets that Hybrid Manager uses, globally and per project. With `--version`, they create the secrets where that version reads them: the `edb-system` namespace for Hybrid Manager 2026.11 or later, the `default` namespace for earlier versions. Without `--version`, they use `default` and print a warning. |
| Feature           | Added the `chatbot` install-secrets scenario for Hybrid Manager 2026.11 or later. `edbctl hybrid-manager create-install-secrets --scenario chatbot` creates the `chatbot-model-creds` secret from one set of `EDB_CHATBOT_MODEL_*<N>` environment variables per model endpoint. |
| Improvement       | Changed `edbctl hybrid-manager create-install-secrets` to create the install secrets in the `edb-system` namespace for Hybrid Manager 2026.11 or later. Earlier versions keep using `default`. When a secret already exists in `default`, its values are reused. |
| Improvement       | Changed `edbctl hybrid-manager create-install-secrets` to stop creating the Migration Portal, AI Copilot, NVIDIA, Hugging Face, and Langflow secrets for Hybrid Manager 2026.11 or later, which no longer use them. Existing secrets are left unchanged. |
| Improvement       | Changed `edbctl image-pull-secret create` to create `edb-cred` in a new `edb-system` namespace and to replicate it only to the namespaces that need it, instead of every namespace in the cluster. |
| Improvement       | `edbctl image sync-to-local-registry`, `edbctl operand sync-to-local-registry`, and `edbctl image import-from-archive` now skip an image only when the destination already holds the expected digest. A destination tag that points to a different image is replaced. |
| Improvement       | Updated the default latest Innovation Release (IR) version reference to v2026.11.                                                              |
| Security&nbsp;fix | Updated third-party dependencies to resolve known security vulnerabilities.                                                                   |
