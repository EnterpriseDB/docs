Learn what EDB Postgres Distributed (PGD) 6 supports and is compatible with, including Postgres versions, operating systems and architectures, and extensions. Check this page before you deploy or upgrade a cluster to confirm your environment is supported.

## PGD compatibility with Postgres versions

PGD supports the following minimum minor version, per major version, across community Postgres, EDB Postgres Extended (PGE), and EDB Postgres Advanced Server (EPAS).

| PGD 6       | Community Postgres | EDB Postgres Extended | EDB Postgres Advanced Server |
|-------------|----------|------------------------|-------------------------------|
| [6.5.0](/pgd/latest/) | 18.1.0+ | 18.6.0+ | 18.6.0+ |
| [6.5.0](/pgd/latest/) | 17.5.0+ | 17.11.0+ | 17.11.0+ |
| [6.5.0](/pgd/latest/) | 16.9.0+ | 16.15.0+ | 16.15.0+ |
| [6.5.0](/pgd/latest/) | 15.13.0+ | 15.19.0+ | 15.19.0+ |
| [6.5.0](/pgd/latest/) | 14.18.0+ | 14.24.0+ | 14.24.0+ |

!!! Important
PGD 6.5.0 requires EDB Postgres Extended or EDB Postgres Advanced Server 14.24, 15.19, 16.15, 17.11, or 18.6, due to internal compatibility changes in PGD 6.5.0. This requirement doesn't apply to community Postgres.

PGD 6.0 through 6.4 aren't compatible with EDB Postgres Extended or EDB Postgres Advanced Server 14.24, 15.19, 16.15, 17.11, or 18.6, or later. Upgrade to PGD 6.5.0 or later if you're upgrading Postgres, EDB Postgres Extended, or EDB Postgres Advanced Server to one of these versions. See [Performing a combined minor upgrade](/pgd/current/upgrades/upgrading-postgres-and-pgd/minor-upgrade/) for the steps.
!!!

!!! Note
Postgres versions 14.24, 15.19, 16.15, 17.11, and 18.6 add the `output_plugin_libraries` parameter. On community Postgres, you must add `bdr` to `output_plugin_libraries` and reload the configuration when you upgrade to one of these versions. See [Postgres configuration](/pgd/current/postgres-configuration/#postgres-settings) for the required setting and instructions. For EPAS or PGE, no action is required.
!!!

EDB recommends that you use the latest minor version of any Postgres major version with a supported PGD.

## PGD compatibility with extensions

PGD supports the following Postgres contrib modules and EDB extensions. The distributed nature of PGD means that you must carefully consider and plan the extensions you select and install. For the full list of extensions available across EDB's Postgres distributions, see [Postgres extensions available by deployment](/pg_extensions/). For steps to install and configure an extension in a PGD cluster, see [Installing extensions](/pgd/current/deploying/deploy-manual/06-extensions/).

`dbms_aq` queue table DDL and queue metadata replicate to all nodes. Enqueued messages don't replicate. They stay local to the node where they're created.
