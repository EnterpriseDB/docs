## PGD compatibility with Postgres versions

The following table shows the minimum minor version, per major version, that EDB Postgres Distributed (PGD) 6 is compatible with, across Postgres, EDB Postgres Extended (PGE), and EDB Postgres Advanced Server (EPAS).

| PGD 6       | Postgres | EDB Postgres Extended | EDB Postgres Advanced Server |
|-------------|----------|------------------------|-------------------------------|
| [6.5.0](/pgd/latest/) | 18.1.0+ | 18.6.0+ | 18.6.0+ |
| [6.5.0](/pgd/latest/) | 17.5.0+ | 17.11.0+ | 17.11.0+ |
| [6.5.0](/pgd/latest/) | 16.9.0+ | 16.15.0+ | 16.15.0+ |
| [6.5.0](/pgd/latest/) | 15.13.0+ | 15.19.0+ | 15.19.0+ |
| [6.5.0](/pgd/latest/) | 14.18.0+ | 14.24.0+ | 14.24.0+ |

!!! Important
PGD 6.5.0 requires EDB Postgres Extended or EDB Postgres Advanced Server 14.24, 15.19, 16.15, 17.11, or 18.6, since these are the minor versions that introduce the `output_plugin_libraries` parameter.

This requirement doesn't apply to community Postgres. You can run PGD 6.5.0 on any Postgres minor version PGD 6 supports, without upgrading it. If you later upgrade to 14.24, 15.19, 16.15, 17.11, 18.6, or later, add `bdr` to the `output_plugin_libraries` parameter and reload the configuration, or PGD's replication slots stop working. See [Postgres configuration](/pgd/current/postgres-configuration/#postgres-settings) for the required setting and instructions.

PGD 6.0 through 6.4 aren't compatible with EDB Postgres Extended or EDB Postgres Advanced Server 14.24, 15.19, 16.15, 17.11, or 18.6, or later. Upgrade to PGD 6.5.0 or later if you're upgrading Postgres, EDB Postgres Extended, or EDB Postgres Advanced Server to one of these versions. See [Performing a combined minor upgrade](/pgd/current/upgrades/upgrading-postgres-and-pgd/minor-upgrade/) for the steps.
!!!

EDB recommends that you use the latest minor version of any Postgres major version with a supported PGD.
