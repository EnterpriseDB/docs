Install the Postgres distribution of your choice on each host in your cluster, then install the PGD software on top of it. Choose from [EDB Postgres Advanced Server](/epas/latest/), [EDB Postgres Extended Server](/pge/latest/), or [community Postgres](https://www.postgresql.org/). The PGD package you install depends on the distribution and the Postgres version. Run all the commands on this page on every host in the cluster. Alternatively, download the packages and their dependencies on one host that can reach the EDB repositories, then transfer them to the other hosts and install them there.

## Configuring the EDB repositories

Configure two repositories, one for the database software and one for the PGD software.

1. Set the following environment variables:

   - `EDB_SUBSCRIPTION_TOKEN` is the token you received when you registered for your EDB subscription. It authenticates your access to the EDB repositories.
   - `EDB_SUBSCRIPTION_PLAN` is the type of subscription you have with EDB, which matches your Postgres distribution. Use `standard` for EDB Postgres Extended Server, `enterprise` for EDB Postgres Advanced Server, or `community` for community Postgres.
   - `EDB_REPO_TYPE` is the type of package manager you use, which tells the installer which type of package you need. Use `deb` for Debian and Ubuntu, or `rpm` for CentOS and Red Hat Enterprise Linux (RHEL).

   For example, to configure the repositories on a RHEL host for EDB Postgres Extended Server:

   ```bash
   export EDB_SUBSCRIPTION_TOKEN=XXXXXXXXXXXXXX
   export EDB_SUBSCRIPTION_PLAN=standard
   export EDB_REPO_TYPE=rpm
   ```

1. Run the following command to download and run a script that configures your package manager to use the EDB repository for databases:

   ```bash
   curl -1sSLf "https://downloads.enterprisedb.com/$EDB_SUBSCRIPTION_TOKEN/$EDB_SUBSCRIPTION_PLAN/setup.$EDB_REPO_TYPE.sh" | sudo -E bash
   ```

1. Run the following command to download and run a script that configures your package manager to use the EDB repository for PGD:

   ```bash
   curl -1sSLf "https://downloads.enterprisedb.com/$EDB_SUBSCRIPTION_TOKEN/postgres_distributed/setup.$EDB_REPO_TYPE.sh" | sudo -E bash
   ```

## Installing the database and PGD packages

Install the database and PGD packages with your package manager.

1. Set an environment variable to specify the major version of Postgres you want to install, for example `17` for Postgres 17:

   ```bash
   export PG_VERSION=17
   ```

1. Set an environment variable to specify the package names for the database and PGD software. The package names vary depending on the database you use and the platform you're on.

   <TabContainer>

   <Tab title="EDB Postgres Advanced Server" active>
   <br/><br/><br/>

   #### EDB Postgres Advanced Server

   <TabContainer syncKey="platform">

   <Tab title="Debian/Ubuntu" active>

   ```shell
   export EDB_PACKAGES="edb-as$PG_VERSION-server edb-pgd6-expanded-epas$PG_VERSION"
   ```

   </Tab>

   <Tab title="CentOS/RHEL">

   ```shell
   export EDB_PACKAGES="edb-as$PG_VERSION-server edb-pgd6-expanded-epas$PG_VERSION"
   ```

   </Tab>
   </TabContainer>

   </Tab>

   <Tab title="EDB Postgres Extended">
   <br/><br/><br/>

   #### EDB Postgres Extended

   <TabContainer syncKey="platform">

   <Tab title="Debian/Ubuntu" active>

   ```bash
   export EDB_PACKAGES="edb-postgresextended-$PG_VERSION edb-pgd6-expanded-pgextended$PG_VERSION"
   ```

   </Tab>

   <Tab title="CentOS/RHEL">

   ```bash
   export EDB_PACKAGES="edb-postgresextended$PG_VERSION-server edb-postgresextended$PG_VERSION-contrib edb-pgd6-expanded-pgextended$PG_VERSION"
   ```

   </Tab>
   </TabContainer>
   </Tab>

   <Tab title="Community Postgres">
   <br/><br/><br/>

   #### Community Postgres

   <TabContainer syncKey="platform">

   <Tab title="Debian/Ubuntu" active>

   ```bash
   export EDB_PACKAGES="postgresql-$PG_VERSION edb-pgd6-expanded-pg$PG_VERSION"
   ```

   </Tab>
   <Tab title="CentOS/RHEL">

   ```bash
   export EDB_PACKAGES="postgresql$PG_VERSION-server postgresql$PG_VERSION-contrib edb-pgd6-expanded-pg$PG_VERSION"
   ```

   </Tab>

   </TabContainer>

   </Tab>

   </TabContainer>

1. Run the installation command for your platform:

   <TabContainer syncKey="platform">

   <Tab title="Debian/Ubuntu" active>

   ```shell
   sudo apt install -y $EDB_PACKAGES
   ```

   </Tab>

   <Tab title="CentOS/RHEL">

   ```shell
   sudo dnf install -y $EDB_PACKAGES
   ```

   </Tab>

   </TabContainer>

   The command installs the specified packages and any dependencies they require. When the installation completes, the database and PGD software are installed on the host.

   For example, to install EDB Postgres Extended 17 with PGD on a RHEL host:

   ```bash
   export PG_VERSION=17
   export EDB_PACKAGES="edb-postgresextended$PG_VERSION-server edb-postgresextended$PG_VERSION-contrib edb-pgd6-expanded-pgextended$PG_VERSION"
   sudo dnf install -y $EDB_PACKAGES
   ```

## Verifying the installation

List the installed database and PGD packages on each host:

<TabContainer syncKey="platform">

<Tab title="Debian/Ubuntu" active>

```shell
dpkg -l | grep -i -E "edb|pgd|postgres"
```

</Tab>

<Tab title="CentOS/RHEL">

```shell
rpm -qa | grep -i -E "edb|pgd"
```

</Tab>

</TabContainer>

The output includes the database packages and the PGD package for your distribution and Postgres version, for example `edb-pgd6-expanded-pgextended17` for EDB Postgres Extended 17.
