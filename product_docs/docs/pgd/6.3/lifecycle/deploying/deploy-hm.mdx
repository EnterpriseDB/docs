EDB Postgres AI Hybrid Manager (HM) is the centralized control plane for the EDB Postgres AI platform, providing additional value such as Oracle compatibility via EDB Postgres Advanced Server and Transparent Data Encryption (TDE) using either EDB Postgres Extended or Advanced Server. It allows you to deploy and manage the full lifecycle of PGD-powered clusters as Distributed High-Availability (DHA) clusters.

DHA clusters are designed for global scale and geographic redundancy. They support multiple data groups, which allows you to distribute workloads across different locations or regions.

Refer to [Creating a database cluster](/edb-postgres-ai/latest/hybrid-manager/using_hybrid_manager/cluster_management/create-clusters/) for step-by-step instructions on deploying DHA clusters.
