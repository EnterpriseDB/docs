## PGD compatibility with PostgreSQL versions

The following table shows the major versions of PostgreSQL that EDB Postgres Distributed (PGD) is compatible with.

| PGD 6       | Postgres Version |
|-------------|------------------|
| [6](/pgd/latest/) | 18.1.0+          |
| [6](/pgd/latest/) | 17.5.0+          |
| [6](/pgd/latest/) | 16.9.0+          |
| [6](/pgd/latest/) | 15.13.0+         |
| [6](/pgd/latest/) | 14.18.0+         |

!!! Note
If you're running PGD on community Postgres 18 and upgrading to Postgres 18.6 or later, add `bdr`
to the new `output_plugin_libraries` parameter and reload the configuration, or PGD's replication
slots stop working. See [Postgres
configuration](/pgd/current/postgres-configuration/#postgres-settings) for the required setting and
instructions.
!!!

EDB recommends that you use the latest minor version of any Postgres major version with a supported PGD.
