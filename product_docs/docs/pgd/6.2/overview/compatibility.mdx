## PGD compatibility with PostgreSQL versions

The following table shows the major versions of PostgreSQL that EDB Postgres Distributed (PGD) is compatible with.

| PGD 6       | Postgres Version |
|-------------|------------------|
| [6](/pgd/latest/) | 18.1.0+          |
| [6](/pgd/latest/) | 17.5.0+          |
| [6](/pgd/latest/) | 16.9.0+          |
| [6](/pgd/latest/) | 15.13.0+         |
| [6](/pgd/latest/) | 14.18.0+         |

!!! Note
If you're running PGD on community Postgres and upgrading to a minor version that introduces the
new `output_plugin_libraries` parameter (14.24, 15.19, 16.15, 17.11, or 18.6, depending on your
major version), add `bdr` to it and reload the configuration, or PGD's replication slots stop
working. EDB Postgres Extended and EDB Postgres Advanced Server already allow `bdr` by default and
aren't affected. See [Postgres configuration](/pgd/current/postgres-configuration/#postgres-settings)
for the required setting and instructions.
!!!

EDB recommends that you use the latest minor version of any Postgres major version with a supported PGD.
