---
title: "Compatibility matrix"
description: Supported combinations of Hybrid Manager operator versions and Hybrid Manager versions.
---

From version 2.0.0, the Hybrid Manager (HM) operator is released independently of HM, with its own versioning lifecycle. Its version numbers don't mirror those of HM.

The following matrix defines the supported compatibility between operator releases and HM versions.

| Operator version | HM version    | Notes                                                    |
|------------------|---------------|----------------------------------------------------------|
| 2.0.0            | 2026.7 (IR)   | First release with independent versioning.               |

!!! Note Hybrid Manager 1.4.x LTS
HM 1.4.x, the current long-term support release, predates the operator being decoupled from HM. It ships its own matching operator version rather than a `2.x` operator, so it doesn't appear in this matrix.
!!!
