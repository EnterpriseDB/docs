---
title: "Compatibility matrix"
description: Supported combinations of Hybrid Manager operator versions and Hybrid Manager versions.
---

From version 2.0.0, the Hybrid Manager (HM) operator is released independently of HM, with its own versioning lifecycle. Its version numbers do not mirror those of HM.

The following matrix defines the supported compatibility between operator releases and HM versions.

| Operator version | HM version   | Notes                                                                       |
|------------------|--------------|-----------------------------------------------------------------------------|
| 2.0.0            | v1.4.x (LTS) | First release with independent versioning. Requires the unified HM Helm chart. |

Before operator 2.0.0, the operator was versioned and released together with HM, so no separate compatibility mapping applies.
