Released: 6 October 2026

EDB Postgres AI for ClickHouse 26.3.37.3 updates the ClickHouse server from 26.3.22.7 and updates the Kubernetes operator, MCP server, and pg_stat_ch.

## ClickHouse server

| Type | Description |
|------|-------------|
| Upstream merge | Updated to the open-source [ClickHouse 26.3.37.3](https://github.com/ClickHouse/ClickHouse/releases/tag/v26.3.37.3-lts) LTS release, from [26.3.22.7](https://github.com/ClickHouse/ClickHouse/releases/tag/v26.3.22.7-lts). |
| Feature | Added Debian 13 (trixie) `.deb` packages for `amd64`, `arm64`, and `ppc64el`, built from the same compile as the RPM packages and published alongside them. |
| Bug fix | Disabled sending crash reports and `LOGICAL_ERROR` exceptions to an external endpoint. The `send_crash_reports` configuration section is still accepted for compatibility with existing configuration files, but it no longer has any effect. |

## Kubernetes operator

| Type | Description |
|------|-------------|
| Upstream merge | Updated to `0.27.4-2edb1`, tracking upstream [Altinity clickhouse-operator release-0.27.4](https://github.com/Altinity/clickhouse-operator/releases/tag/release-0.27.4), from `0.27.3`. The EDB release adds no upstream changes. Images are tagged `0.27.4-2edb1` and the Helm chart is versioned `0.27.4+2edb1`. |
| Bug fix | Updated `google.golang.org/grpc` to `v1.84.0`, `golang.org/x/text` to `v0.42.0`, and `github.com/go-openapi/swag` to `v0.29.2` to address security vulnerabilities, including GHSA-2v4p-qf9q-27wj, GHSA-hrxh-6v49-42gf, and GHSA-vp52-pcj8-j9qc. |
| Bug fix | The Helm chart and the operator's default images now come from the production repository, `docker.enterprisedb.com/clickhouse`, so a default installation works with a production subscription. |
| Bug fix | The operator's default ClickHouse and Keeper image is now pinned to `edb-clickhouse-server:26.3.22.7-1edb1` instead of `latest`, so the deployed ClickHouse version no longer changes without an operator release. |

## MCP server

| Type | Description |
|------|-------------|
| Upstream merge | Synced to upstream [v0.7.0](https://github.com/ClickHouse/mcp-clickhouse/releases/tag/v0.7.0), from `v0.4.1`. Highlights include connection caching, query cancellation, `Host` and `Origin` validation for HTTP and SSE, and named query parameters on `run_query`. Requires clickhouse-connect 1.x. See the upstream release notes for the full list of changes. |
| Feature | Added Debian 13 `.deb` packages for `amd64` and `arm64`, published alongside the RPM packages. |
| Change | `CLICKHOUSE_SECURE` now accepts only `true` or `false`, and `CLICKHOUSE_VERIFY` accepts only `true`, `false`, or `proxy`. Other values fail at startup. |

## pg_stat_ch

| Type | Description |
|------|-------------|
| Change | Repackaged as `0.4.0-1edb2`. The upstream version remains [pg_stat_ch 0.4.0](https://github.com/ClickHouse/pg_stat_ch/releases/tag/v0.4.0). |
| Feature | Added Debian 12 (bookworm) and Debian 13 (trixie) `.deb` packages alongside the RPM packages. Debian 13 packages cover community PostgreSQL only. See [Compatibility](../overview/compatibility). |
| Bug fix | The background worker no longer registers or connects to `postgres` when the postmaster is started by `pg_upgrade` in `-b` mode. Previously, that open connection blocked the `DROP DATABASE "postgres"` step in `pg_restore` and caused every binary upgrade to fail when `pg_stat_ch` was in `shared_preload_libraries`. |
