Released: 30 July 2026

EDB Postgres AI for ClickHouse 26.3.17.56 rolls up upstream bug fixes from ClickHouse 26.3.14 through 26.3.17. Changes include:

| Type | Description |
|------|-------------|
| Upstream merge | Based on open-source ClickHouse 26.3.17.56 LTS. See the [ClickHouse 26.3.17.56 release](https://github.com/ClickHouse/ClickHouse/releases/tag/v26.3.17.56-lts) on GitHub. |
| Kubernetes operator | Updated to `0.27.2-1edb1`, tracking upstream [Altinity clickhouse-operator release-0.27.2](https://github.com/Altinity/clickhouse-operator/releases/tag/release-0.27.2). Separate release train from the ClickHouse server version above. See below for details. |

### Kubernetes operator 0.27.2-1edb1

- Config rename: `reconcile.recovery.from.*` → `reconcile.recovery.onStatus.*` (backward-incompatible)
- Fixed unauthenticated `/debug/pprof` exposure on the metrics port
- Go toolchain bumped to 1.26.5, fixing [CVE-2026-39822](https://nvd.nist.gov/vuln/detail/CVE-2026-39822) and [CVE-2026-42505](https://nvd.nist.gov/vuln/detail/CVE-2026-42505)
