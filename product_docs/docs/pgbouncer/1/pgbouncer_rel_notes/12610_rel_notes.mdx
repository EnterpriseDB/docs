EDB PgBouncer 1.26.1.0 includes the following security fixes and upstream merge:

| Security       | Included fixes for [CVE-2026-6668](https://nvd.nist.gov/vuln/detail/CVE-2026-6668), [CVE-2026-6669](https://nvd.nist.gov/vuln/detail/CVE-2026-6669), and [CVE-2026-19888](https://nvd.nist.gov/vuln/detail/CVE-2026-19888).                                                  |
| Security       | Included fixes for [CVE-2026-107348](https://nvd.nist.gov/vuln/detail/CVE-2026-107348), [CVE-2026-107349](https://nvd.nist.gov/vuln/detail/CVE-2026-107349), and [CVE-2026-107350](https://nvd.nist.gov/vuln/detail/CVE-2026-107350).                                        |
| Upstream merge | Merged with community PgBouncer 1.26.0 and 1.26.1. See the community [Release Notes](https://www.pgbouncer.org/changelog.html#pgbouncer-126x) for details.                                                                                                                   |
