A **tool** is anything an agent can invoke by name. Every tool AIDB knows about — built-in, custom, or imported from an MCP server — is listed in one place, `aidb.tools`:

```sql
SELECT name, tool_type, read_only FROM aidb.tools ORDER BY tool_type, name LIMIT 5;

__OUTPUT__
        name        | tool_type   | read_only
---------------------+-------------+-----------
 chunk_text          | native_tool | t
 create_agent        | native_tool | f
 ...
```

| Column | Description |
|--------|--------------|
| `name` | The name an agent's `tools` array (and the model's own tool calls) refer to it by. |
| `description` | Shown to the model as part of the tool's definition. |
| `tool_type` | `native_tool`, `sql_tool`, or `mcp_tool` — see below. |
| `params` | For `native_tool`/`sql_tool`: a JSON array of `{name, type, description}` objects. For `mcp_tool`: the external server's own JSON Schema `inputSchema`. |
| `read_only` | Whether invoking the tool is known to never write. `mcp_tool` entries are always `false` here — see [read-only mode](../agents/conversing-with-agents#read-only-mode) for why that's a hard `false`, not a real classification. |

Give an agent access to a tool by listing its name in [`create_agent`/`update_agent`](../agents/creating-agents)'s `tools` array. `aidb.tools` unions three kinds of tools:

- **`native_tool`** — AIDB's own built-in catalog. Always available; can't be added, removed, or reconfigured. See [Native tools](native-tools).
- **`sql_tool`** — a parameterized SQL query you register yourself. See [Custom SQL tools](custom-sql-tools).
- **`mcp_tool`** — a tool imported from an external MCP server. See [MCP tools](mcp-tools).
