An **agent** is a named, reusable configuration — instructions, a model, and a set of tools it's allowed to call — that AIDB runs through a ReAct-style reasoning loop: the model thinks, optionally calls one or more tools, observes the results, and repeats until it has an answer. A **tool** is anything an agent can invoke by name: a built-in AIDB operation, a custom parameterized SQL query you register, or an operation imported from an external MCP server.

!!!note
This is a distinct, in-database capability, different from [Agent Factory in Hybrid Manager](/edb-postgres-ai/latest/hybrid-manager/ai-factory/). AIDB's agents run entirely as SQL function calls inside your Postgres database.
!!!

Agents and tools are ordinary Postgres objects, created and queried with SQL:

```sql
-- Register an agent that can query the database
SELECT aidb.create_agent(
    name         => 'db_helper',
    instructions => 'You are a helpful assistant that answers questions about this database.',
    model        => 'my_gpt',
    tools        => ARRAY['run_sql_query']
);

-- Have a conversation with it
SELECT * FROM aidb.agent_converse('db_helper', 'How many rows are in the orders table?');
```
