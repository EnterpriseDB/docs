---
title: Known issues
description: Known limitations in the current release of AIDB.
---

- Limited air-gapped support. The built-in CPU model runtimes (Candle and llama.cpp) run fully offline once their model files are available locally, but any pipeline step or agent tool that calls out to a remote model provider still needs outbound network access to that provider. See [Configuring AIDB](../install/configure#configuring-proxy-settings).
- A model credential holds one secret. To use a different API key, create another credential and models bound to it. See [Model credentials](../integrating-models/credentials).
- Access to models is granted per credential. A role that can use a credential can use every model bound to it.
- Members of a group role that owns a credential can read its secret. Keep credentials owned by individual roles.
- Superusers can read every credential's secret.
- Model credentials can't be renamed.
