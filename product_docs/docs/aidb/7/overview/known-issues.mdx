---
title: Known issues
description: Known limitations in the current release of AIDB.
---

- **Limited air-gapped support.** The built-in CPU model runtimes (Candle and llama.cpp) run fully offline once their model files are available locally, but any pipeline step or agent tool that calls out to a remote model provider still needs outbound network access to that provider. See [Configuring AIDB](../install/configure#proxy-settings).
