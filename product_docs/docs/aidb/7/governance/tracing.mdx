---

AIDB emits OpenTelemetry spans for agent and tool activity beyond purpose-enforcement decisions — the same `aidb.otel_client` exporter setting covers all of it. Full documentation of that wider span set is coming in a future release.

For the governance-specific subset — one record per purpose-scoped tool call, allowed or denied — see [Decision records](decision-records).
