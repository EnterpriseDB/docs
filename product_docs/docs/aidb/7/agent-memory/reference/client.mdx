`AgentMemoryClient` provides agent memory over a PostgreSQL connection. Set the connection once, then call the memory methods:

```python
with AgentMemoryClient("postgresql://localhost/postgres", namespace="chat") as client:
    client.memory_add(actor_id="u1", turns="I prefer oat milk")
    hits = client.memory_search(actor_id="u1", query="milk preference")
    stored = client.memory_list(actor_id="u1")
```

Give it either a `dsn`, in which case it creates and owns a connection pool, or an existing Psycopg connection via `connection=`, which it borrows — see [`AgentMemoryClient()`](#agentmemoryclient) for what borrowing means for your transaction.

Every namespace-scoped method uses the client's namespace unless a call passes `namespace=` explicitly. See [Asynchronous client](async-client) for the asyncio equivalent, which has the same method names.

## `AgentMemoryClient()`

Configures the client against a DSN or an existing connection.

#### Parameters

| Parameter | Type | Default | Description |
| --- | --- | --- | --- |
| `dsn` | `str` | `''` | PostgreSQL connection string. The client creates a connection pool and closes it in `close()`. |
| `namespace` | `str` | `'default'` | Namespace used by any call that doesn't override it. |
| `connection` | `Optional[Connection[Any]]` | `None` | An existing Psycopg connection to borrow instead of pooling. |

Passing `connection=` hands the client a connection it doesn't own, with three consequences worth knowing:

- The client never commits, rolls back, or closes it. Your writes aren't durable until you commit, unless the connection was opened with `autocommit=True`. Committing on your behalf would also silently commit whatever else you have in flight on that connection — so the client doesn't.
- `connect()` and `close()` are no-ops for it.
- One connection means one transaction and serialized traffic, so this gives up the concurrency a pool would provide.

#### Raises

| Type | Description |
| --- | --- |
| `ValueError` | If both `dsn` and `connection` are given, or neither. |

## `namespace` property

```python
namespace: str
```

The namespace used when a call doesn't override it.

## `from_env()`

```python
from_env(
    *,
    dsn: Optional[str] = None,
    namespace: Optional[str] = None,
    connection: Optional[Connection[Any]] = None,
) -> AgentMemoryClient
```

Builds a client from explicit values or 12-factor environment configuration.

`AIDB_DSN` provides the DSN and `AIDB_DEFAULT_NAMESPACE` the namespace, defaulting to `"default"`. Explicit arguments take precedence, and `AIDB_DSN` isn't required when a connection is given.

## `connect()`

```python
connect() -> None
```

Opens the connection pool. A no-op when a connection was supplied.

## `close()`

```python
close() -> None
```

Closes the connection pool. A no-op when a connection was supplied.

Safe to call more than once. A borrowed connection is left open for its owner.

health_check() -> dict[str, Any]

Provisions or validates a namespace and returns its identifier.

Returns every configured namespace and its active provider.

Reads the extension's namespace registry, so it requires a database role permitted to do so.

## `memory_add()`

```python
memory_add(
    actor_id: str,
    turns: TurnsInput,
    *,
    session_id: Optional[str] = None,
    agent_id: Optional[str] = None,
    idempotency_key: Optional[str] = None,
    namespace: Optional[str] = None,
) -> str
```

Ingests turns for an actor and enqueues background memory distillation.

`turns` accepts a bare string (stored as one user turn), a single `Turn` or dict, or a sequence of any of those. Returns the event ID, or `""` when there's nothing to ingest.

On a borrowed connection, this write isn't durable until you commit.

## `memory_search()`

memory_search(

## `memory_list()`

```python
memory_list(
    actor_id: str,
    *,
    session_id: Optional[str] = None,
    agent_id: Optional[str] = None,
    limit: int = 100,
    namespace: Optional[str] = None,
) -> list[Memory]
```

Lists stored memories for an actor.

This is an operator operation. PostgreSQL must grant the connected role permission to execute `aidb_memory.list_memories`.

## `memory_delete()`

```python
memory_delete(
    actor_id: str,
    *,
    reason: str,
    memory_ids: Optional[Sequence[Union[UUID, str]]] = None,
    session_id: Optional[str] = None,
    agent_id: Optional[str] = None,
    all_for_actor: bool = False,
    namespace: Optional[str] = None,
) -> int
```

Deletes memories for an actor and returns how many were removed.

Pass exactly one target: `memory_ids` for one or more specific memories, `session_id` for a session, `agent_id` for an agent, or `all_for_actor=True` for the actor's complete memory scope. `reason` is required.

This is an operator operation. PostgreSQL must grant the connected role permission to execute `aidb_memory.delete`. On a borrowed connection, the deletion isn't durable until its owner commits.
