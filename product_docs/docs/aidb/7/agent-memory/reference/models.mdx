All models are Pydantic (`pydantic.BaseModel`) classes.

## `Turn`

Represents a single message turn in a conversation, with `role` and `content` fields — see [Add structured turns](../index#add-structured-turns) for constructing and passing `Turn` instances.

### `to_sql_dict()`

```python
to_sql_dict() -> dict[str, Any]
```

Converts a `Turn` to a JSON-serializable dictionary for SQL JSONB parameters.

## `SearchHit`

A single result from a semantic memory search, returned by [`memory_search()`](client#memory_search). Search results expose at least `id`, `content`, and `score` — see [Memory operations](../memory-operations#search).

## `Memory`

A stored memory returned by `aidb_memory.list_memories`, and by [`memory_list()`](client#memory_list). A memory exposes at least `id` and `content` — see [Memory operations](../memory-operations#list).

### `from_row()`

```python
from_row(row: Mapping[str, Any]) -> Memory
```

Builds a `Memory` from a row returned by `aidb_memory.list_memories`.

## `NamespaceInfo`

Summary of a configured memory namespace, returned by [`namespace_list()`](client#namespace_list).

## `ModelSpec`

Model configuration supplied by the selected memory runtime — passed as the `model_spec` argument of `MemoryInitConfig`. See [Initialize a namespace](../namespaces#initialize-a-namespace) for an example with `encoder`, `dimensions`, and `llm`.

## `StorageSpec`

Storage configuration supplied by the selected memory runtime — passed as the `storage_spec` argument of `MemoryInitConfig`. See [Initialize a namespace](../namespaces#initialize-a-namespace) for an example with `location`, `dimensions`, `base_url`, and `collection`.

## `MemoryInitConfig`

Configuration passed to `aidb_memory.init(name, provider, config)`, and to [`namespace_init()`](client#namespace_init) as `config`.

### `to_sql_json()`

```python
to_sql_json() -> dict[str, Any]
```

Converts a `MemoryInitConfig` to the exact JSON structure expected by `aidb_memory.init`.
