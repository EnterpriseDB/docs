All agent memory client exceptions inherit from `AIDBError`.

## `AIDBError`

Base exception for all agent memory SDK errors.

## `AIDBConnectionError`

Bases: `AIDBError`. Raised when the database connection fails or drops.

## `AIDBConfigurationError`

Bases: `AIDBError`. Raised when client configuration or provider specs are invalid.

## `AIDBSpecMismatchError`

Bases: `AIDBConfigurationError`. Raised when namespace specifications don't match existing configuration.

## `AIDBQueryError`

Bases: `AIDBError`. Raised when an SQL function execution in PostgreSQL fails.

## `AIDBNamespaceNotFoundError`

Bases: `AIDBError`. Raised when a requested namespace doesn't exist in PostgreSQL.

## `AIDBPermissionError`

Bases: `AIDBError`. Raised when the database role may not perform an operation.

See [Permissions and errors](../permissions-and-errors) for a worked example of catching these.
