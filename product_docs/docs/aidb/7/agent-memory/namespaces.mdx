A namespace separates memory configuration and data for an application or workload. Set the common namespace when constructing the client:

```python
client = AgentMemoryClient(dsn, namespace="customer_support")
```

Every namespace-scoped memory method uses that value by default. A call can override it:

```python
hits = client.memory_search(
    "user_42",
    "billing preferences",
    namespace="billing_assistant",
)
```

## Initialize a namespace

Namespace initialization is normally operator or deployment work. It requires a runtime identifier and runtime configuration matching the AIDB deployment:

```python
from edb_agentmemory import MemoryInitConfig, ModelSpec, StorageSpec

config = MemoryInitConfig(
    model_spec=ModelSpec(
        encoder="<encoder-name>",
        dimensions=1536,
        llm="<optional-model-name>",
    ),
    storage_spec=StorageSpec(
        location="<storage-name>",
        dimensions=1536,
        base_url="<optional-runtime-url>",
        collection="<optional-collection>",
    ),
)

namespace_id = client.namespace_init(
    provider="<configured-runtime-name>",
    config=config,
)
```

The client intentionally has no default runtime — supply values appropriate to the deployment. Calling `namespace_init()` again validates the existing configuration; a mismatch raises `AIDBSpecMismatchError`.

Trusted operator code can inspect configured namespaces with `client.namespace_list()`. That operation requires a database role allowed to read the namespace registry — see [Permissions and errors](permissions-and-errors).
