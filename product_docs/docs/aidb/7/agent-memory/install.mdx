---
title: Installing the agent memory client
navTitle: Install
description: Install the edb-agentmemory Python package and verify connectivity to AIDB.
---

The client supports Python 3.10 and later:

```shell
pip install edb-agentmemory
```

Psycopg is the only PostgreSQL driver the client uses. Its default installation needs the `libpq` client library at runtime. If `libpq` isn't installed on the machine, install Psycopg's self-contained binary build alongside the client:

```shell
pip install edb-agentmemory "psycopg[binary]"
```

Your database must already have the AIDB extension installed, and the PostgreSQL role in the DSN must have permission to use the required functions.

## Verify the installation

```python
from edb_agentmemory import AgentMemoryClient

with AgentMemoryClient("postgresql://app_user@localhost/aidb") as client:
    status = client.health_check()
    print(status["aidb_version"])
```

A successful check returns a dictionary containing `connected=True` and the installed AIDB extension version.
