Install agent memory on your Postgres instance as part of the AIDB extension. It has no dependency on Hybrid Manager.

## Prerequisites

- A running Postgres database.
- Permission to create schemas, tables, and roles in the target database.

## Installing AIDB

Install AIDB by following the instructions in [Installing AIDB](../install). Agent memory comes with the AIDB extension, so there's no separate extension to install.

## Setting up the Agent Memory Server

Set up the EDB Agent Memory Server, which agent memory requires. The server builds memories from the messages your agents send. EDB provides it as a container, and you must configure it before agents can add or search memories.
