Install agent memory on your Postgres instance as part of the AIDB extension. It has no dependency on Hybrid Manager.

## Prerequisites

- A running Postgres database. AIDB 7 includes agent memory and supports Postgres 14 through 18, including EDB Postgres Advanced Server, EDB Postgres Extended Server, and community PostgreSQL.
- Permission to create schemas and roles in the target database.

Agent memory needs no extra steps on EDB Postgres Distributed (PGD) clusters.

## Installing AIDB

Install AIDB by following the instructions in [Installing AIDB](../install). Agent memory comes with the AIDB extension, so there's no separate extension to install.

## Setting up the Agent Memory Server

Set up the EDB Agent Memory Server, which agent memory requires. The server builds memories from the messages your agents send. EDB provides it as a container, and you must configure it before agents can add or search memories.

To set up the server, follow [Configuring agent memory](configuring). It covers preparing the storage schema, running the server container, registering models, and initializing a namespace.
