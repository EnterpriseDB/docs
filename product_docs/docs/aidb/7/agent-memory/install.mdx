Install agent memory on your Postgres instance as part of the AIDB extension. It has no dependency on Hybrid Manager.

Agent memory also needs the EDB Agent Memory Server, a separate service that EDB provides as a Docker container. It builds memories from the conversations that your agents send and stores them in your database. To set up the server, see [Configuring agent memory](configuring). To learn how the database and the server work together, see [Understanding agent memory](overview#architecture).

## Prerequisites

- A running Postgres database. AIDB 7 includes agent memory and supports EDB Postgres Advanced Server, EDB Postgres Extended Server, and PostgreSQL, version 14 and later. AIDB also supports EDB Postgres Distributed (PGD) clusters without any extra configuration.
- Permission to create schemas and roles in the database where AIDB is installed.

## Installing AIDB

Install AIDB by following the instructions in [Installing AIDB](../install). Agent memory comes with the AIDB extension, so there's no separate extension to install.
