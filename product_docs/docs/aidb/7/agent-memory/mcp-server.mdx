---
title: Agent memory MCP server
navTitle: MCP server
description: Run the agent memory MCP server to expose memory search and save as tools.
---

An MCP server exposes agent memory's search and save operations as tools, for MCP-compatible agent frameworks that call tools rather than a typed client.

```shell
pip install edb-agentmemory-mcp
export AIDB_DSN="postgresql://user:pass@localhost/aidb"
edb-agentmemory-mcp
```

The server reads its database connection from `AIDB_DSN`, the same environment variable the Python client uses — see [Connections](connections).
