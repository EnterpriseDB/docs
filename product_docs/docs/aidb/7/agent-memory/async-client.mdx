navTitle: Async client
description: Use AsyncAgentMemoryClient in asyncio applications, and borrow an async Psycopg connection.
---

`AsyncAgentMemoryClient` provides the same operations as the synchronous client. Every database method is awaited:

```python
import asyncio
from edb_agentmemory import AsyncAgentMemoryClient

async def main() -> None:
    async with AsyncAgentMemoryClient(
        "postgresql://app_user@localhost/aidb",
        namespace="my_app",
    ) as client:
        await client.memory_add("user_42", "I prefer dark mode")
        hits = await client.memory_search("user_42", "interface preferences")
        for hit in hits:
            print(hit.content)

asyncio.run(main())
```

The async pool binds to the running event loop. Create or connect the client from the event loop that will serve its requests. In a web application, this normally means opening the client during application startup and closing it during shutdown.

## Borrow an async connection

```python
import psycopg
from edb_agentmemory import AsyncAgentMemoryClient

async def save_preference(dsn: str) -> None:
    async with await psycopg.AsyncConnection.connect(dsn) as connection:
        client = AsyncAgentMemoryClient(connection=connection, namespace="my_app")
        await client.memory_add("user_42", "I prefer dark mode")
        await connection.commit()
```

As with the synchronous client, transaction and connection ownership remain with the code that supplied the connection — see [Transactions](transactions).
