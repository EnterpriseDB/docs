Released: 12 Oct 2026

This release introduces named model credentials. Any member of `aidb_users` can now create models that use an API key, without a superuser. See [Model credentials](../../integrating-models/credentials).

Upgrading from 7.7.0 keeps existing models working, but changes how their secrets are stored and who can use them. Review [Upgrading from 7.7.0](#upgrading-from-770) before you upgrade.
