---
title: AIDB 7.7.0 release notes
navTitle: "Version 7.7.0"
---

Released: 30 Sep 2026

AIDB 7.7.0 introduces built-in **OpenTelemetry (OTel) observability**: AIDB can now trace its own function calls, background workers, and SQL query execution, and store or forward that data as standard OTel traces, logs, and metrics. See [Observability](../../reference/observability) and [Configuring AIDB parameters](../../install/configure#opentelemetry-tracing) to get started.

AIDB 7.7.0 includes the following enhancements:

| Type        | Description                                                                                                                                                                                                                                                                                                                                                                       |
|-------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Enhancement | **OpenTelemetry client:** A new embedded OTel client emits traces, logs, and metrics for AIDB's own activity. Select the destination with `aidb.otel_client`: discard (`noop`, the default), write to the `aidb_otel` schema (`database`), print to stdout, write to the server log, or push OTLP/gRPC to an external collector. See [Configuring AIDB parameters](../../install/configure#opentelemetry-tracing). |
| Enhancement | **Agent Hub and Tools Hub tracing:** Agent and tool calls are now traced with `gen_ai.*` semantic-convention attributes plus custom `aidb.*` attributes (agent purpose, status, task and message IDs, MCP server name, transport, and session ID). See [Observability — Traced attributes](../../reference/observability#traced-attributes). |
| Enhancement | **Broader function coverage:** OTel spans were extended to pipeline CRUD and execution, semantic knowledge base CRUD and search, model inference and maintenance, data processors, and volume operations. |
| Enhancement | **SQL query tracing:** Traced calls now capture the SQL they execute in a `db.query.text` span attribute. Bound parameter values are included only when `aidb.otel_capture_query_parameters` is enabled. |
| Enhancement | **PostgreSQL session correlation:** Every trace's root span now carries a `db.postgresql.session_id` attribute matching Postgres's own `%c` log_line_prefix format, so a trace can be correlated with the corresponding server log lines. |
| Enhancement | **Storage format:** The `database` client can write trace, log, and metric payloads as JSON, raw OTLP protobuf, or both, controlled by `aidb.otel_client_storage_format`. `aidb_otel.{traces,logs,metrics}` split their old single `data` column into `payload_json`/`payload_binary` accordingly. |
| Enhancement | **Grouping indexes:** `aidb_otel.traces` and `aidb_otel.logs` gained promoted, indexed columns for trace/span IDs, the PostgreSQL session, conversation, and MCP session identifiers, and the allowed/denied outcome of each purpose-enforcement decision, so you can filter and group without parsing the payload columns. See [Observability — Schemas](../../reference/observability#schemas). |
| Enhancement | **Exporter background worker:** Forwards pending `aidb_otel.*` rows to an external OTLP/HTTP collector on a periodic tick, with per-row retry and backoff. Disabled by default; configure with `aidb.otel_exporter_enabled` and the related `aidb.otel_exporter_*` parameters. |
| Enhancement | **Retention cleaner background worker:** Deletes `aidb_otel.*` rows older than a configurable retention window. Disabled by default; configure with `aidb.otel_cleaner_enabled` and the related `aidb.otel_cleaner_*` parameters, or trigger a pass immediately with `aidb.run_otel_retention_cleanup()`. |
| Enhancement | **aidb_governance role:** A new role, separate from `aidb_users`, for read-only access to `aidb_otel.*` and the manual retention cleanup function. See [Managing audit access](../../install/configure#managing-audit-access-with-the-aidb_governance-role). |
