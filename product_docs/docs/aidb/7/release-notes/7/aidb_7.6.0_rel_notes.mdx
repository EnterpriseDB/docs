navTitle: "Version 7.6.0"

Released: 26 Aug 2026

AIDB 7.6.0 introduces **Agents and tools**, a SQL-native framework for building in-database AI agents: an agent reasons over multiple steps — calling tools, observing their results, and repeating — instead of answering in one shot. Tools range from a large catalog of built-in operations to your own custom SQL queries and tools imported from an external MCP server. Some of the underlying groundwork for this shipped quietly in 7.5.0; 7.6.0 is the first release where it's complete, and this is its first appearance in these release notes. See [Agents and tools](../../agents-and-tools) to get started.

AIDB 7.6.0 includes the following enhancements and bug fixes:

| Type        | Description                                                                                                                                                                                                                                                                                                                                                                       |
|-------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Enhancement | **Agents:** `aidb.create_agent()` registers a named agent — instructions, a model, and the tools/other agents it may use — and `aidb.agent_converse()` runs it against a prompt, including multi-turn conversations retrievable with `aidb.get_conversation()`. See [Creating agents](../../agents-and-tools/creating-agents) and [Conversing with agents](../../agents-and-tools/conversing-with-agents). |
| Enhancement | **Agent budgets and limits:** Cap an agent's token usage, reasoning iterations, and wall-clock time per call, with configurable behavior (`budget_strategy`) for what happens when a budget is exceeded — halt, summarize, warn, or grant a grace period to wrap up. See [Budgets and limits](../../agents-and-tools/conversing-with-agents#budgets-and-limits). |
| Enhancement | **Agent delegation:** An agent can hand off part of a request to another named agent, exposed to the model as an ordinary tool call. See [Delegation](../../agents-and-tools/delegation). |
| Enhancement | **Tools hub:** A unified tool catalog (`aidb.tools`) spanning a large built-in native tool set, custom parameterized SQL queries registered with `aidb.create_sql_tool()`, and tools imported from external MCP servers with `aidb.import_mcp_tools()`. See [Tools](../../agents-and-tools/tools), [Custom SQL tools](../../agents-and-tools/custom-sql-tools), and [MCP tools](../../agents-and-tools/mcp-tools). |
| Enhancement | **Native tool-calling model adapters:** The new `openai_responses` and `anthropic_messages` providers (plus `openai_responses_azure` and `anthropic_messages_azure`/`anthropic_messages_bedrock` hosting variants) connect to OpenAI's Responses API and Anthropic's Messages API natively, emitting real `tools`/`tool_choice` request fields and parsing real tool-call responses, instead of simulating tool calls through prompt injection. See [External model connections](../../integrating-models/external-model-connections#openai-responses-api). |
| Bug fix     | **Credentials with invalid header characters:** An `api_key` or `basic_auth` value containing characters that aren't valid in an HTTP header (for example, a stray newline) now fails with a clear configuration error instead of crashing the backend. |
| Enhancement | **Local reranking via llama.cpp:** The new `llamacpp_reranking` provider reranks text locally from a GGUF file, supporting both cross-encoder models (for example, `bge-reranker-v2-m3`) and the Qwen3-Reranker decoder-only family — no external API required. See [Local models](../../integrating-models/integrated-models#llamacpp_reranking). |
| Enhancement | **Renamed `decode_text` to `generate_text`:** `aidb.decode_text()` and `aidb.decode_text_batch()` are renamed to `aidb.generate_text()` and `aidb.generate_text_batch()`, matching `encode_text()`'s naming on the embedding side. The old names still work but are deprecated and will be removed in a future version. See [Inference functions](../../reference/models#inference-functions). |
