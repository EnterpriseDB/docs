The `edb-endpoints` HTTP server, shipped in the AIDB package, serves both the [MCP endpoint](../mcp-endpoint) and the [OTLP receiver](../otlp-server). A Postgres background worker, the supervisor, starts it, restarts it if it exits, and shuts it down with Postgres. The pages in this section cover what both servers share.

| Page                                                     | What it covers                                                                                                 |
|----------------------------------------------------------|----------------------------------------------------------------------------------------------------------------|
| [Configuring the endpoint](configuring-the-endpoint)     | Every `edb.endpoints_*` parameter, what the supervisor derives on its own, what a reload does                  |
| [Serving multiple databases](serving-multiple-databases) | Listing several databases, routing clients by URL, controlling access to each, upgrading from 7.8.0            |
| [Authenticating with OAuth](oauth)                       | Signing in MCP clients through your identity provider, bearer tokens for OTLP senders, mapping token identities to roles |
| [Operating the endpoint](operating-the-endpoint)         | Health checks, logging, the restart budget, configuration rejections, restarting or stopping it, launching it yourself, troubleshooting |
