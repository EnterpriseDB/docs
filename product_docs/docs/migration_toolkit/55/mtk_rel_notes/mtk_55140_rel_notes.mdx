---
title: "Migration Toolkit 55.14.0 release notes"
navTitle: Version 55.14.0
---

Released: 24 Nov 2026

New features, enhancements, bug fixes, and other changes in Migration Toolkit 55.14.0 include:

| Type         | Description                                                                                                                                                                                                                                        | Ticket              |
|--------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|---------------------|
| Enhancement  | Added support for PostgreSQL version 19 and EDB Postgres Advanced Server version 19 both as a source and target database.                                                                                                             |                     |
| Enhancement  | Added support for installation and use on RHEL 10 and OL 10.                                                                                                                                                                          |                     |
| Enhancement  | Migration Toolkit now supports the parallel data-loading options `-loaderCount`, `-parallelLoadRowLimit`, and `-tableLoaderLimit` for Sybase source databases.                                                                                     | #56108              |
| Enhancement  | Migration Toolkit can now migrate identity (`GENERATED AS IDENTITY`) columns from EDB Postgres Advanced Server to an Oracle target.                                                                                                                |                     |
| Security Fix | Migration Toolkit now includes Apache Log4j 2.25.5, which addresses [CVE-2026-34480](https://nvd.nist.gov/vuln/detail/CVE-2026-34480) and [CVE-2026-34477](https://nvd.nist.gov/vuln/detail/CVE-2026-34477).                                       |                     |
| Security Fix | Improved the handling of source and target database passwords in memory. Migration Toolkit now clears them after use instead of leaving them in memory as immutable strings.                                                                       |                     |
| Bug&nbsp;fix | Fixed an issue where migrating a `GENERATED ALWAYS AS IDENTITY` column between EPAS databases failed in `-safeMode`.                                                                                                                               |                     |
| Bug&nbsp;fix | Fixed an issue where the `-fetchSize` option was ignored in an offline migration of LOB data from MySQL, causing out-of-memory errors when migrating large tables.                                                                                 | #54602              |
| Bug&nbsp;fix | Fixed an issue where table creation failed with error MTK-15013 when migrating an Oracle table with a `DEFAULT` timestamp expression to a PostgreSQL target.                                                                                       | #55361 <br/> #54028 |
| Bug&nbsp;fix | Fixed an issue where Oracle identifiers that contain full-width digits were treated as case sensitive, causing data load to fail because the column didn't exist in the target table.                                                              | #56302              |
| Bug&nbsp;fix | Fixed an issue where migrating a PostgreSQL schema failed because a shared or custom-named sequence was incorrectly converted to a `serial` column type, leaving a table that referenced a sequence that didn't exist.                             | #57272              |
| Bug&nbsp;fix | Fixed an issue where duplicate sequences with numeric suffixes were created when migrating a `bigserial` column from PostgreSQL to EPAS.                                                                                                           | #57487              |
| Bug&nbsp;fix | Fixed an issue where triggers weren't disabled during a `-dataOnly -truncLoad` migration from Oracle to PostgreSQL because of a table name case mismatch.                                                                                          |                     |
| Bug&nbsp;fix | Fixed an issue where data migration failed for SQL Server tables with names longer than 63 characters when the target is PostgreSQL or EPAS.                                                                                                       |                     |
| Bug&nbsp;fix | Fixed an issue where `UNLOGGED` sequences in a PostgreSQL 15 or later source database were migrated as regular sequences.                                                                                                                          |                     |
| Bug&nbsp;fix | Fixed an issue where an offline migration from PostgreSQL or EPAS to an Oracle target generated invalid `E'...'` string literals, causing `ORA-00917` errors.                                                                                      |                     |
| Bug&nbsp;fix | Fixed an issue where `runMTK.sh` returned exit code `0` after a connection failure or other migration error. Migration Toolkit now returns a nonzero exit code on failure so that scripts and automation can detect it.                            | #63352              |
| Bug&nbsp;fix | Fixed an issue where migrating a PostgreSQL schema to EPAS failed with `permission denied for language c` because Migration Toolkit tried to migrate functions owned by extensions, such as `uuid-ossp`.                                           |                     |
| Bug&nbsp;fix | Fixed an issue where mapping an Oracle `BLOB` column to the `xml` type with a custom column mapping failed with `ORA-17004`.                                                                                                                       |                     |
| Bug&nbsp;fix | Fixed an issue where the `-lobBatchSize` option didn't control how many rows were fetched at a time from the source for tables with LOB columns, which slowed the migration of large LOB tables.                                                   |                     |
| Bug&nbsp;fix | Fixed an issue where the target sequence or identity counter wasn't set to the current source value when migrating from MySQL, SQL Server, or Sybase. New inserts after migration could collide with migrated rows.                                |                     |
| Bug&nbsp;fix | Fixed an issue where data load failed with a `relation does not exist` error for SQL Server tables with uppercase or mixed-case names in a database with a case-sensitive collation.                                                               |                     |
| Bug&nbsp;fix | Fixed an issue where SQL Server identity columns were migrated to PostgreSQL or EPAS as `SERIAL` columns of the wrong width. They're now migrated as `GENERATED BY DEFAULT AS IDENTITY` columns with an integer type that matches the source type. |                     |
| Bug&nbsp;fix | Fixed an issue where Sybase identity columns were migrated to EPAS as plain numeric columns that lost auto-generation. They're now migrated as `GENERATED BY DEFAULT AS IDENTITY` columns with an integer type that matches the source type.       |                     |
| Bug&nbsp;fix | Fixed an issue where dropping indexes before a data load with `-truncLoad` failed on a partitioned table with the error `cannot drop index ... because index ... requires it`.                                                                     | #67518              |
| Bug&nbsp;fix | Fixed an issue where fractional seconds with leading zeros in SQL Server and Sybase timestamp values were migrated incorrectly in COPY mode. For example, `.003` was migrated as `.333`.                                                           |                     |
