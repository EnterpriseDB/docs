# Installing Advanced Storage Pack

Advanced Storage Pack is supported on the same platforms as the Postgres distribution you're using. Support starts with Postgres 14 for Autocluster and Refdata, and with Postgres 15 for Bluefin. For details, see:

- [EDB Postgres Advanced Server Product Compatibility](https://www.enterprisedb.com/platform-compatibility#epas)
- [PostgreSQL Product Compatibility](https://www.enterprisedb.com/resources/platform-compatibility#pg)
- [EDB Postgres Extended Server Product Compatibility](https://www.enterprisedb.com/resources/platform-compatibility#epas_extended)

| Operating system                                                                                     | TAMs available                | Minimum version                                           | Installation method               |
| ---------------------------------------------------------------------------------------------------- | ----------------------------- | --------------------------------------------------------- | --------------------------------- |
| [Linux](https://www.enterprisedb.com/docs/pg_extensions/advanced_storage_pack/installing/linux/)     | Autocluster, Refdata, Bluefin | Postgres 14 (Autocluster, Refdata), Postgres 15 (Bluefin) | EDB repository package manager    |
| [Windows](https://www.enterprisedb.com/docs/pg_extensions/advanced_storage_pack/installing/windows/) | Bluefin only                  | PostgreSQL / EPAS 15                                      | StackBuilder or StackBuilder Plus |

- [Linux](https://www.enterprisedb.com/docs/pg_extensions/advanced_storage_pack/installing/linux/): Install Advanced Storage Pack on Linux using your system package manager.
- [Windows](https://www.enterprisedb.com/docs/pg_extensions/advanced_storage_pack/installing/windows/): Install Bluefin on Windows using StackBuilder or StackBuilder Plus.
