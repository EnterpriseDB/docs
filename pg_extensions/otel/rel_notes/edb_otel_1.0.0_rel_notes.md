# Release notes for EDB OTEL version 1.0.0

Release date: 28 March 2025

This is the initial release of the `edb_otel` extension.

The `edb_otel` extension enables you to export query execution traces in the OpenTelemetry format — making it easier to monitor, visualize, and troubleshoot database performance using your existing observability tools.

**Highlights:**

- Overview of the extension and its purpose

- Installation and configuration steps

- Examples for integrating with OpenTelemetry backends
