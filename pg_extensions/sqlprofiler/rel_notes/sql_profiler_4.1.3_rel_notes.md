# Release notes for SQL Profiler version 4.1.3

Release date: 13 Feb 2025

This release of SQL Profiler includes:

| Type        | Description                                                                                                                                                                                                                         |
| ----------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Improvement | The `query_id` logged in trace files is generated by the server and matches the one used in EDB Wait States results. This enables seamless navigation between data collected by EDB Wait States and SQL Profiler for a given query. |
