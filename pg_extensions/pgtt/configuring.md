# Configuring pgtt

To enable pgtt, create the extension in the database:

```sql
CREATE EXTENSION pgtt;
```

After enabling the extension, you can perform additional configuration. See the [pgtt official documentation](https://github.com/darold/pgtt?tab=readme-ov-file#configuration).
