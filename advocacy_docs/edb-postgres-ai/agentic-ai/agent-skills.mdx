Agent Skills give AI coding agents — currently Claude Code — local, validated knowledge of how EDB Postgres AI products work. They're markdown files that describe a product's concepts and how to use it, in a form the agent reads directly, rather than one it has to piece together on its own.

Without a skill, an agent asked to work with one of these products has to discover that information itself: searching online, or relying on whatever its underlying model already knows. That's slower, costs more tokens, and can lead the agent to outdated or incorrect information. Installing the relevant skill gives it EDB-maintained, accurate product knowledge instead.

## Benefits

Installing an Agent Skill gives your AI agent:

- Faster answers: the agent reads the skill locally instead of searching online for product information.

- Accurate, validated information: skill content is maintained by EDB alongside each product, so the agent isn't relying on outdated posts or guesses from its training data.

- Fewer mistakes in generated SQL and configuration: the agent works from the product's actual concepts and syntax, not from unrelated or outdated sources it finds elsewhere.

## What Agent Skills cover

Skills are available for:

| Product                                               | What it does                                                                                       |
|-------------------------------------------------------|----------------------------------------------------------------------------------------------------|
| [AIDB](/aidb/latest)                                  | Brings native AI capabilities — embeddings, RAG pipelines, and in-database agents — into Postgres. |
| [Postgres Analytics Accelerator (PGAA)](/pgaa/latest) | Analytics in Postgres over Apache Iceberg, Delta Lake, and Parquet tables.                         |
| [Postgres File System (PGFS)](/pg_extensions/pgfs)    | Companion extension for AIDB and PGAA that provides access to external storage.                    |

## Getting the skills

The skills are maintained in the [`edb-agent-skills`](https://github.com/EnterpriseDB/edb-agent-skills) GitHub repository.

## Installing a skill

1. Decide which product's skill you want to install, or install all of them by not selecting a specific directory.

2. Ask your AI agent to install the skill, for example: `Install the skills from https://github.com/EnterpriseDB/edb-agent-skills`.

3. Follow any instructions the agent gives you to complete the installation.

## Using the skills

Once a skill is installed, ask your agent to help with tasks like:

- Discovery and solution design — for example, "How can I build a back end for a RAG application with EDB AIDB?"

- SQL generation, or asking the agent to run SQL directly

- Installing and configuring the product — for example, "Register a new LLM for use with AIDB; I want to use OpenAI GPT-5"

- Tuning, experimentation, and optimization — for example, "I want to try different chunking strategies for my RAG vector embeddings"

- Debugging — for example, "My RAG knowledge base 'products' returns poor results; what could the reason be?"

- Coding — for example, "Integrate the local Python demo app with PG and the AIDB extension so I can add semantic search to the UI"

## Where skills are available

!!!note Verified platforms
Installing and using a skill is generic, and expected to work with most agentic coding platforms. So far, though, it has only been verified on Claude Code. EDB plans to test other platforms and will update this page once that testing is complete.
!!!

Once installed, a skill runs as part of your agent's local session — there's no separate service to deploy or account to configure. The agent loads the skill's content itself when it decides the skill is relevant to your request.
