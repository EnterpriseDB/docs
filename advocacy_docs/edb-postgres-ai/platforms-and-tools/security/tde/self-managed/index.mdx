Transparent Data Encryption (TDE) encrypts data as it's written, so you can only enable it when you create a database cluster. You can't turn it on for data that already exists.

Enable TDE on a self-managed database server (Enterprise Postgres (Oracle Compatible) or Enterprise Postgres installed on virtual machines or physical servers, on-premises or in the cloud) by initializing a new database cluster with [initdb](https://www.postgresql.org/docs/current/app-initdb.html). TDE is built into both distributions, so there's no separate package or extension to install.

To migrate an existing database to a TDE-enabled environment instead, see [Enabling, migrating, and upgrading](../upgrading/).

## Before you begin

-   Enabling TDE always involves choosing how to protect the generated data encryption key. See [Protecting the data encryption key](../about/how/#protecting-the-data-encryption-key) to compare your options, then follow [Configuring the data encryption key](../secure_key) to implement your choice.

-   Review the [initdb TDE options](../reference/initdb_tde_options/) to ensure you have all information required for initializing a TDE-enabled database cluster.

-   Review [Limitations](../reference/limitations/) to understand limitations and changes in the handling of PostgreSQL utilities when you enable TDE.

## Initializing a server

Follow these steps to create a new TDE-enabled database server from scratch.

1.  Export the wrap and unwrap commands to secure the encryption key, using the method you chose when [configuring the data encryption key](../secure_key):

    ```shell
    export PGDATAKEYWRAPCMD='<wrap-command> -out "%p"'
    export PGDATAKEYUNWRAPCMD='<unwrap-command> -in "%p"'
    ```

    Alternatively, skip the environment variables and pass the commands directly to `initdb` with `--key-wrap-command=<command>` and `--key-unwrap-command=<command>`. See [Using a passphrase](../secure_key/passphrase/#via-command-argument) or [Using a key store](../secure_key/key_store/) for worked examples.

1.  Initialize the database cluster with `--data-encryption` enabled:

    ```shell
    <bin_directory>/initdb --data-encryption -D <data_directory>
    ```

    Include other [initdb TDE options](../reference/initdb_tde_options/) as required.

1.  Start the database cluster:

    ```shell
    <bin_directory>/pg_ctl -D <data_directory> start
    ```

1.  [Verify that TDE is enabled](../reference/verifying_tde/).

See [Creating a database with TDE](enabling_tde/) for a complete worked example with real commands and output.
