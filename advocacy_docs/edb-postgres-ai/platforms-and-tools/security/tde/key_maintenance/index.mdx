Once a cluster is TDE-enabled, you may need to revisit how its data encryption key is protected: enabling protection you skipped at creation time, or rotating the key or passphrase currently in use.

- [Protecting an existing key](protecting_existing_key) shows how to add a protection mechanism to a key that was left unprotected when the cluster was created.

- [Rotating the key](key_rotation) shows how to change the passphrase or key-store wrapping key currently protecting your data encryption key.

If you're choosing a protection mechanism for a new cluster instead, see [Configuring the data encryption key](../secure_key).
