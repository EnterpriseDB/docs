Revisit how an already TDE-enabled cluster's data encryption key is protected: add protection you skipped at creation time, or rotate the key or passphrase currently in use.

- [Protecting an existing key](protecting_existing_key) shows how to add a protection mechanism to a key that was left unprotected when the cluster was created.

- [Rotating the key](key_rotation) shows how to change the passphrase or key-store wrapping key currently protecting your data encryption key.

If you're choosing a protection mechanism for a new cluster instead, see [Choosing a key protection mechanism](../secure_key).
