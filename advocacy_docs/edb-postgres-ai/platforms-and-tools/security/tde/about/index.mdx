Transparent data encryption (TDE) is an optional feature supported by Enterprise Postgres (Oracle Compatible), formerly EDB Postgres Advanced Server, and Enterprise Postgres, formerly EDB Postgres Extended Server, in version 15 and later.

It encrypts user data stored in the database system.
