If you want to start using Transparent Data Encryption (TDE) on a self-managed database server, you create a TDE-enabled database by initializing a new database cluster using [initdb](https://www.postgresql.org/docs/current/app-initdb.html). You can't enable TDE in place on an existing database server.

If you want to migrate an existing database server to a TDE-enabled environment instead, see [Enabling, migrating, and upgrading](upgrading/).

## Before you begin

-   Choose a method to [secure the data encryption key](../secure_key) generated by TDE.
    
    You can protect the key with a [passphrase](../secure_key/passphrase/) or a wrapping key from a [key store](../secure_key/key_store/). Or, for testing purposes, you can choose to [not protect the key](../secure_key/disabling_key/).

-   Review the [initdb TDE options](../reference/initdb_tde_options/) to ensure you have all information required for initializing a TDE-enabled database cluster.

-   Review [Limitations](../reference/limitations/) to understand limitations and changes in the handling of PostgreSQL utilities when you enable TDE.

## Initializing a server

Follow these steps to create a new TDE-enabled database server from scratch.

1.  Export the wrapping and unwrapping commands to secure the encryption key. Use the wrapping method you chose during the planning phase. 

    Alternatively, you can provide the wrapping and unwrapping commands when initializing the server with the command line arguments.

    See [Providing the wrapping and unwrapping commands](../secure_key/#providing-the-wrapping-and-unwrapping-commands-to-tde) for examples.

1.  Initialize a database server with `--data-encryption` enabled on the target directory. Include other [TDE options](../reference/initdb_tde_options/) as required.

1.  Start the database cluster and [verify that TDE is enabled](tutorials/verifying_tde/).

See [Creating a TDE-enabled database server](tutorials/enabling_tde/) for a detailed initialization example.
