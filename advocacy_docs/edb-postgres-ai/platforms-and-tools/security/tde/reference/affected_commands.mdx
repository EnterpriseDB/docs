## Commands affected by TDE
When TDE is enabled, the following commands have TDE-specific options or read TDE settings in environment variables or configuration files:

- [initdb](./initdb_tde_options/)
- [pg_waldump](wal_file_options/#pg_waldump)
- [pg_resetwal](wal_file_options/#pg_resetwal)
- [pg_verifybackup](backup_file_options/#pg_verifybackup)
- [pg_rewind](backup_file_options/#pg_rewind)
- [pg_upgrade](pg_upgrade_arguments)

## Other tools affected by TDE
When TDE is enabled, EDB*Loader doesn't support the `DIRECT=TRUE` option and returns an error. See [Running a direct path load](/epas/18/database_administration/02_edb_loader/invoking_edb_loader/direct_path_load.mdx) for details.
