AI pipelines ingest, prepare, and vectorize your data for semantic search and RAG with configurable steps for chunking, parsing, OCR, and embedding, and automatic sync that keeps the resulting knowledge base up to date with your source data.

AI pipelines can be created once the AIDB extension is installed and configured — see [Installing and configuring AIDB](/aidb/latest/install).

Create a pipeline to define its data source, processing steps, and sync behavior, and explore the available step types — see [Creating pipelines](/aidb/latest/data-pipelines/data-processing) and [Pipeline steps](/aidb/latest/data-pipelines/pipeline-steps).

Call the same chunking, parsing, OCR, and embedding logic directly as standalone SQL functions outside a pipeline — see [SQL functions](/aidb/latest/sql-functions).

Once a pipeline has indexed your data, query the resulting knowledge base with semantic search, hybrid search, and retrieval functions — see [Knowledge bases](/aidb/latest/knowledge-bases) under [Context](../context).
