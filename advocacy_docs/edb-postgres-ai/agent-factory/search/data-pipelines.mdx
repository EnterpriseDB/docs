AI pipelines ingest, prepare, and vectorize your data for semantic search and RAG. A pipeline reads from a Postgres table or external storage, transforms the data through one or more steps (chunking, parsing, OCR, embedding), and writes the result to a knowledge base you can query.

- **[Creating pipelines](/aidb/latest/data-pipelines/data-processing)** — Define a pipeline's data source, processing steps, and auto-processing mode with `aidb.create_pipeline()`.

For installing AIDB and other reference material, see [AIDB extension under Packages](../../packages/aidb). For pipeline steps, orchestration, and the full interface reference, see the [full AI pipelines documentation](/aidb/latest/data-pipelines).
