[pgvector](/pg_extensions/pgvector) is an open-source Postgres extension for storing and querying vector embeddings directly in your database using standard SQL.

- **[Using pgvector](/pg_extensions/pgvector/using)** — Store and query vector data, choose and configure an index type, and optimize storage for vector workloads.

For installing, upgrading, release notes, and known issues, see [pgvector under Packages](../../packages/pgvector). For platform compatibility, configuration, security, and operations, see the [full pgvector documentation](/pg_extensions/pgvector).
