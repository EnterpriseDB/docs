Search covers how Agent Factory gets your data in and makes it queryable — pipelines that keep a knowledge base in sync, connectors to external sources, and the vector extensions that power similarity search.

- **[Connectors](connectors)** — Connect Agent Factory pipelines to external data sources.

- **[AI pipelines](data-pipelines)** — Define pipelines to parse, chunk, embed, and index your data, then keep your knowledge base in sync automatically.

- **[pgvector](pgvector)** — Store and query vector embeddings directly in Postgres using standard SQL.

- **[EDB Vector Plus](vector-plus)** — A faster, lower-footprint vector index type that coexists with pgvector at scale.

Once your data is indexed, query it with semantic search, hybrid search, and retrieval functions — see [Knowledge bases](/aidb/latest/knowledge-bases) under [Context](../context).
