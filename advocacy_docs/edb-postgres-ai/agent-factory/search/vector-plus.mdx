[EDB Vector Plus](/vector-plus/latest) is a Postgres extension that adds the `ivfplus` vector index type for faster, lower-footprint vector search at scale. It works alongside pgvector, using the same `vector` type.

- **[Using Vector Plus](/vector-plus/latest/using)** — Store and query vector data, filter results, tune the index, and measure recall.

For installing, upgrading, release notes, and troubleshooting, see [Vector Plus under Packages](../../packages/vector-plus). For platform compatibility, a quickstart, and the full interface reference, see the [full Vector Plus documentation](/vector-plus/latest).
