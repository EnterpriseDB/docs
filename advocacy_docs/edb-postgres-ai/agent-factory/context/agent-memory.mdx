Agent memory gives AI agents a durable, per-user memory of past conversations, stored in Postgres and built into the AIDB extension, with per-actor scoping, session and agent filters, safe retries, and auditable deletion.

Install AIDB and configure the Agent Memory Server before using agent memory — see [Installing agent memory](/aidb/latest/agent-memory/install) and [Configuring agent memory](/aidb/latest/agent-memory/configuring).

Add, search, list, and delete memories with the `aidb_memory` SQL functions — see [Managing agent memories](/aidb/latest/agent-memory/memory-operations).
