navTitle: Semantic knowledge bases
description: Index your database's schema metadata into a semantic knowledge base for natural-language schema search, agent tools, and text-to-SQL.
---

Semantic knowledge bases index your database's schema, including tables, views, columns, and comments, into a searchable vector store, so an agent, or you, can find the right relations and columns by meaning instead of guessing from column names.

Install and configure the AIDB extension before creating a semantic knowledge base — see [Installing and configuring AIDB](/aidb/latest/install).

Create a semantic knowledge base with `aidb.create_semantic_kb()`, then search it by meaning or use it for text-to-SQL — see [Getting started](/aidb/latest/semantic-knowledge-bases#getting-started), [Searching a semantic knowledge base](/aidb/latest/semantic-knowledge-bases/searching), and [Text-to-SQL](/aidb/latest/semantic-knowledge-bases/text-to-sql).
