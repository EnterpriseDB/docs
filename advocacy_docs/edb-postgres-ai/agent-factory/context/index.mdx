Context gives agents the memory and knowledge they need to reason well — durable conversation memory, a searchable model of your schema, and vector-indexed knowledge bases over your own data.

- **[Agent memory](agent-memory)** — Give AI agents a durable, per-user memory of past conversations, stored in Postgres and built into AIDB.

- **[Semantic knowledge bases](semantic-knowledge-bases)** — Index your database's schema metadata for natural-language schema search, agent tools, and text-to-SQL.

- **[Knowledge bases](knowledge-bases)** — Query vector-indexed knowledge bases using semantic search, hybrid search, and retrieval functions.
