Context gives agents the memory and knowledge they need to reason well — durable conversation memory and a searchable model of your schema.

- **[Agent memory](/aidb/latest/agent-memory)** — Give AI agents a durable, per-user memory of past conversations, stored in Postgres and built into AIDB.
- **[Semantic knowledge bases](/aidb/latest/semantic-knowledge-bases)** — Index your database's schema metadata for natural-language schema search, agent tools, and text-to-SQL.
