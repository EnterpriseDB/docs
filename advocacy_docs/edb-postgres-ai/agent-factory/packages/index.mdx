Install, upgrade, and track releases and known issues for each extension and application that implements Search, Context, and Runtime.

- **[AIDB extension](aidb)** — AIDB acts as the orchestrator of your AI workflows. It automates the complex backend tasks required to make your data AI-ready:

  - **In-Database LLM integration**: Connect directly to OpenAI, Azure, Google Cloud Storage, AWS S3, or local models using SQL.

  - **AI data preparation**: Automatically transform table data into vector embeddings.

  - **Semantic management**: No more glue code — manage your RAG workflows with standard SQL commands.

  AIDB's own capabilities — pipelines, agent memory, semantic knowledge bases, model integration, agents, and the MCP endpoint — are covered under [Search](../../search), [Context](../../context), and [Runtime](../../runtime) in Agent Factory.

- **[pgvector](pgvector)** — pgvector is an open-source Postgres extension for storing and querying vector embeddings directly in your database using standard SQL. It's also one of the extensions behind [Search](../../search) in Agent Factory.

- **[EDB Vector Plus](vector-plus)** — EDB Vector Plus is a Postgres extension that adds the `ivfplus` vector index type for faster, lower-footprint vector search at scale. It works alongside pgvector, using the same `vector` type, and is one of the extensions behind [Search](../../search) in Agent Factory.

- **[Agent Governance](agent-governance)** — EDB Agent Governance is a standalone application that audits and governs how AI agents interact with your Postgres data. It connects to your HM-managed clusters or standalone Loki instances to reconstruct agent sessions from Postgres query logs.

  Key capabilities:

  - **[Reconstructing agent sessions](/agent-governance/latest/session_detail)**: Inspect every SQL statement an AI agent executed, with full execution metadata.

  - **[Auditing across multiple data sources](/agent-governance/latest/connecting_data_sources)**: Connect to several HM or Loki sources at once and audit clusters across all of them from one place.

  - **[Incremental sync](/agent-governance/latest/architecture)**: Session data is cached and synced incrementally, so audit views load quickly without re-querying the full log history on every visit.


- **[Agent Skills](agent-skills)** — Install EDB's Agent Skills so AI coding agents have built-in, validated knowledge of each product.
