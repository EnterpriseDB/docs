[pgvector](/pg_extensions/pgvector) is an open-source Postgres extension for storing and querying vector embeddings directly in your database using standard SQL. It's also one of the extensions behind [Search](../../search) in Agent Factory.

- **[Install & Upgrade](/pg_extensions/pgvector/installing)** — Install pgvector and upgrade to a newer version.
- **[Release Notes](/pg_extensions/pgvector/rel_notes)** — What's new in each pgvector release.
