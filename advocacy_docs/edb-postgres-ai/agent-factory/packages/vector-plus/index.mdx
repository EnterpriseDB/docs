[EDB Vector Plus](/vector-plus/latest) is a Postgres extension that adds the `ivfplus` vector index type for faster, lower-footprint vector search at scale. It works alongside pgvector, using the same `vector` type, and is one of the extensions behind [Search](../../search) in Agent Factory.
