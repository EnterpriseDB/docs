navTitle: Agents
description: Build in-database AI agents that reason over multiple steps and delegate to other agents — all driven from SQL.
---

Define agents as named, reusable configurations, including instructions, a model, and a set of tools, that AIDB runs through a ReAct-style reasoning loop to answer multi-step questions, entirely from SQL.

Register the model an agent will use before creating it — see [Model serving](model-serving).

Create an agent, converse with it, and let agents delegate work to each other — see [Managing agents](/aidb/latest/agents/creating-agents), [Invoking agents](/aidb/latest/agents/conversing-with-agents), and [Delegation](/aidb/latest/agents/delegation).
