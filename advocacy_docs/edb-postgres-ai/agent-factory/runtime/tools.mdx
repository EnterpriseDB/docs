navTitle: Tools
description: AIDB's unified tool catalog — native, custom SQL, and MCP tools that agents can call.
---

A tool is anything an agent can invoke by name, in one unified catalog and can list every built-in AIDB operation, custom parameterized SQL query, and operation imported from an external MCP server.

AIDB's tool catalog is available once AIDB is installed and configured — see [Installing and configuring AIDB](/aidb/latest/install).

Call AIDB's built-in operations, register your own SQL queries as tools, or import tools from an external MCP server — see [Native tools](/aidb/latest/tools/native-tools), [Custom SQL tools](/aidb/latest/tools/custom-sql-tools), and [MCP tools](/aidb/latest/tools/mcp-tools).
