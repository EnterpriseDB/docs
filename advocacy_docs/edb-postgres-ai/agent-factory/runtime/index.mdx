Register and serve models, build agents that reason over multiple steps, call tools, and expose AIDB's tools to external MCP clients.

## Model serving

Register a model once to power every AI operation in AIDB, including embeddings, text chunking, summarization, OCR, and completions, and reuse it across pipelines, agents, and SQL functions.

Install and configure AIDB before registering a model — see [Installing and configuring AIDB](/aidb/latest/install).

Register a local model that runs on the Postgres host, or a remote model called over an API, and store its credentials securely — see [Local models](/aidb/latest/integrating-models/integrated-models), [Remote models](/aidb/latest/integrating-models/remote-models), and [Model credentials](/aidb/latest/integrating-models/credentials).

## Agents

Define agents as named, reusable configurations, including instructions, a model, and a set of tools, that AIDB runs through a ReAct-style reasoning loop to answer multi-step questions, entirely from SQL.

Register the model an agent will use before creating it — see [Model serving](#model-serving).

Create an agent, converse with it, and let agents delegate work to each other — see [Managing agents](/aidb/latest/agents/creating-agents), [Invoking agents](/aidb/latest/agents/conversing-with-agents), and [Delegation](/aidb/latest/agents/delegation).

## Tools

List every built-in AIDB operation, custom parameterized SQL query, and operation imported from an external MCP server as a tool an agent can invoke by name, in one unified catalog.

AIDB's tool catalog is available once AIDB is installed and configured — see [Installing and configuring AIDB](/aidb/latest/install).

Call AIDB's built-in operations, register your own SQL queries as tools, or import tools from an external MCP server — see [Native tools](/aidb/latest/tools/native-tools), [Custom SQL tools](/aidb/latest/tools/custom-sql-tools), and [MCP tools](/aidb/latest/tools/mcp-tools).

### MCP endpoint

The MCP endpoint serves AIDB's tool catalog to external MCP clients over streamable HTTP, so agents outside the database can call AIDB's tools, enforced by the Postgres role the agent authenticates with.

Turn on the endpoint and set up a Postgres role for each external agent before connecting a client — see [Enabling the endpoint](/aidb/latest/mcp-endpoint/enabling-the-endpoint) and [Configuring your agent role](/aidb/latest/mcp-endpoint/configuring-agent-roles).

Connect a client over the MCP wire protocol and call tools or run SQL directly — see [Connecting a client](/aidb/latest/mcp-endpoint/connecting-a-client).
