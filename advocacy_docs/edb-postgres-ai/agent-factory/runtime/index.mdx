Runtime covers how models and agents actually run — registering and serving models, building agents that reason over multiple steps, calling tools, enforcing what those tools can do, and exposing AIDB's tools to external MCP clients.

- **[Model serving](model-serving)** — Register and connect AI models with AIDB, both local models that run on the Postgres host and remote models called over an API.

- **[Agents](agents)** — Build in-database AI agents that reason over multiple steps and delegate to other agents, all driven from SQL.

- **[Tools](tools)** — AIDB's unified tool catalog — native, custom SQL, and MCP tools that agents can call.

- **[Governance](governance)** — Confine what an agent's tools can do, and record every allow/deny decision, using purposes and Postgres roles.

- **[MCP endpoint](mcp-endpoint)** — Serve AIDB's tool catalog to external MCP clients over streamable HTTP.
