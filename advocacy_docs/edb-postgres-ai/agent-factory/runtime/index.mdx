Runtime covers how models and agents actually run — registering and serving models, building agents that reason over multiple steps, and exposing AIDB's tools to external MCP clients.

- **[Integrating models](/aidb/latest/integrating-models)** — Register and connect AI models with AIDB, both local models that run on the Postgres host and remote models called over an API.

- **[Model serving](model-serving)** — Serve models for Agent Factory agents and pipelines. No existing source yet — see DOCS-4239.

- **[Agents](/aidb/latest/agents)** — Build in-database AI agents that reason over multiple steps and delegate to other agents, all driven from SQL.

- **[MCP endpoint](/aidb/latest/mcp-endpoint)** — Serve AIDB's tool catalog to external MCP clients over streamable HTTP.
