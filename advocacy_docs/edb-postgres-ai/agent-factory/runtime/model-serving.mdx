navTitle: Model serving
description: How to register and connect AI models with AIDB, both local models that run on the Postgres host and remote models called over an API.
---

Models power every AI operation in AIDB — embeddings, text chunking, summarization, OCR, and completions — registered once and reused across pipelines, agents, and SQL functions.

Install and configure AIDB before registering a model — see [Installing and configuring AIDB](/aidb/latest/install).

Register a local model that runs on the Postgres host, or a remote model called over an API, and store its credentials securely — see [Local models](/aidb/latest/integrating-models/integrated-models), [Remote models](/aidb/latest/integrating-models/remote-models), and [Model credentials](/aidb/latest/integrating-models/credentials).
