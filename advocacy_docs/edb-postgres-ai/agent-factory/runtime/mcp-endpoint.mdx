---
title: Model Context Protocol (MCP) endpoint
navTitle: MCP endpoint
description: Serve AIDB's tool catalog to external MCP clients over streamable HTTP.
---

The MCP endpoint serves AIDB's tool catalog to external MCP clients over streamable HTTP, so agents outside the database can call AIDB's tools, enforced by the Postgres role the agent authenticates with.

Turn on the endpoint and set up a Postgres role for each external agent before connecting a client — see [Enabling the endpoint](/aidb/latest/mcp-endpoint/enabling-the-endpoint) and [Configuring your agent role](/aidb/latest/mcp-endpoint/configuring-agent-roles).

Connect a client over the MCP wire protocol and call tools or run SQL directly — see [Connecting a client](/aidb/latest/mcp-endpoint/connecting-a-client).
