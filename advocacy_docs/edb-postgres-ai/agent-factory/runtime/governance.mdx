Governance confines what an agent's tool calls can do, and records every allow/deny decision, by mapping named purposes to Postgres roles enforced by Postgres's own privilege system.

Register the [agents](../agents) and [tools](../tools) you want to govern before assigning them a purpose.

Register a purpose that resolves to a Postgres role, assign it to an agent, and review what happens when that agent runs — see [Purposes](/aidb/latest/governance/purposes) and [Enforcement](/aidb/latest/governance/enforcement).
