EDB Agent Governance is a separate, standalone application, not a feature of AIDB, that audits how AI agents interact with your Postgres data. It reconstructs full agent sessions, including every SQL statement and its execution metadata, synced incrementally from your HM-managed clusters or standalone Loki instances.

Install EDB Agent Governance and connect it to your HM-managed clusters or Loki instances before auditing a session — see [Installing Agent Governance](../../packages/agent-governance) and [Connecting data sources](/agent-governance/latest/connecting_data_sources).

Reconstruct an agent's session to inspect every SQL statement it executed, with full execution metadata — see [Session detail](/agent-governance/latest/session_detail).
