Audit what AI agents did against your Postgres data using EDB Agent Governance, a separate, standalone application, not a feature of AIDB: reconstruct agent sessions from the telemetry `aidb` records, including the governance decision behind each step. Postgres query logs from HM or Loki are supported as a legacy source.

Install EDB Agent Governance and connect it to a Postgres database running the `aidb` extension before auditing a session — see [Installing Agent Governance](../packages/agent-governance) and [Connecting an aidb database](/agent-governance/latest/connecting_aidb).

Inspect the recorded steps and available execution metadata for a session — see [Session detail](/agent-governance/latest/session_detail).
