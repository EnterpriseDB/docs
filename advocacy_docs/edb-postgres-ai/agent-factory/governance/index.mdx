Governance covers how you control and audit AI agents across Agent Factory — confining what an agent's tool calls can do while it runs, and auditing what it actually did against your Postgres data afterward.

- **[Access control](access-control)** — Confine what an in-database agent's tools can do, and record every allow/deny decision, using purposes and Postgres roles. This is a built-in AIDB feature.

- **[Auditing](auditing)** — Audit AI agent activity against your Postgres data by reconstructing agent sessions from Postgres query logs, using EDB Agent Governance — a separate, standalone application, not a feature of AIDB.
