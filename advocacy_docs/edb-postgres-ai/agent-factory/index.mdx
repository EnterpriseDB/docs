Agent Factory is EDB's set of Postgres extensions and applications for building AI agents that run directly on your data — without moving it to a separate vector database or agent framework.

- **[Search](search)** — Index and search your data with pipelines, connectors, and vector extensions.
- **[Context](context)** — Give agents durable memory and searchable knowledge bases.
- **[Runtime](runtime)** — Register and serve models, run agents, and expose tools to external MCP clients.
- **[Governance](governance)** — Confine what an agent's tools can do while it runs, and audit what it did against your Postgres data afterward.
- **[Packages](packages)** — Install, upgrade, and track releases and known issues for each extension and application.
