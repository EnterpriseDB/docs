navTitle: "Version 1.2.4"

This release of Query Advisor includes:

| Type         | Description                                                                                                                                                                                                                                                      | Addresses |
|--------------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|-----------|
| Enhancement  | Added support for PostgreSQL, EDB Postgres Advanced Server, and EDB Postgres Extended Server version 19.                                                                                                                                                         |           |
| Bug&nbsp;fix | Fixed an issue where a truncated workload query text wasn't always null-terminated, which could crash the server when the text was read later, especially under concurrent or high-load workloads. This completes the fix for the shared memory overflow in 1.2.3. |           |
