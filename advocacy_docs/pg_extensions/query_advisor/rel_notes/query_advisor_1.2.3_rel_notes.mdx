This release of Query Advisor includes:

| Type         | Description                                                                                                                                                                                                                                                                                  | Addresses |
|--------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|-----------|
| Bug&nbsp;fix | Fixed an issue where a query longer than `query_advisor.max_workload_query_size` could overflow the workload entry in shared memory. This could happen when the query was run with `EXPLAIN (ANALYZE, BUFFERS)` and could cause shared memory corruption and a server crash. The query text copy is now bounded. |           |
| Change       | Removed support for Postgres 13, which is end of life.                                                                                                                                                                                                                                       |           |
