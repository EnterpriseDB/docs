title: Release notes for Apache AGE 1.8.0
navTitle: "Version 1.8.0"
---

Released: 11 August 2026

This release of Apache AGE supports PostgreSQL, EDB Postgres Advanced Server, and EDB Postgres Extended version 18 only, as documented in the [Apache AGE release notes for 1.8.0](https://github.com/apache/age/releases#release-PG18/v1.8.0-rc0).

The number was adjusted to 1.8.0 in order to match the upstream versioning scheme.
