## Summary

Webhook URLs are not validated, and the PEM agent does not restrict the URL schemes it uses to deliver webhooks. A user with the alert configuration role (pem_config_alert) can set up a webhook with a file:// URL. When the webhook is sent, the agent on the PEM server, which runs as root by default, reads the local file and stores its contents in the webhook error record in the PEM database, where any PEM user can read it.

## Affected products and versions

* Affected Product: Postgres Enterprise Manager (PEM)
* Affected Versions: PEM 8.0.0 and later versions prior to PEM 10.6.1

## Remediation/fixes

Impacted users must upgrade to PEM 10.6.1 or later. From PEM 10.6.1, PEM accepts and sends only http and https webhook URLs.

| Product | VRMF | Remediation/First Fix |
|---------|------|-----------------------|
| PEM | PEM 8.0.0 and later versions prior to PEM 10.6.1 | Update to PEM 10.6.1 or later |

## Mitigation

Until you can upgrade, reduce exposure as follows:

* Grant the pem_config_alert role only to trusted users.
* Review existing webhooks and remove any whose URL does not start with http:// or https://.
