## Summary

Any PEM user can read the encrypted passwords that PEM agents use to connect to monitored servers, including the PEM backend superuser password stored when the PEM server is configured. Unless a custom encryption key is configured, these passwords are encrypted with a key that is the same in every PEM installation, so they can be decrypted.

## Vulnerability details

CVE-ID: [CVE-2026-132664](https://nvd.nist.gov/vuln/detail/CVE-2026-132664)

CVSS Base Score: 7.0 High

CVSS Temporal Score: Undefined

CVSS Environmental Score: Undefined

CVSS Vector: CVSS:4.0/AV:N/AC:L/AT:P/PR:L/UI:N/VC:H/VI:N/VA:N/SC:H/SI:N/SA:N

## Affected products and versions

* Affected Product: Postgres Enterprise Manager (PEM)
* Affected Versions: PEM 2.0.1 and later versions prior to PEM 10.6.1

## Remediation/fixes

Impacted users must upgrade to PEM 10.6.1 or later. From PEM 10.6.1, PEM users can no longer read these passwords.

| Product | VRMF | Remediation/First Fix |
|---------|------|-----------------------|
| PEM | PEM 2.0.1 and later versions prior to PEM 10.6.1 | Update to PEM 10.6.1 or later |

## Mitigation

Until you can upgrade, reduce exposure as follows:

* Configure a custom encryption key for PEM (see [Custom encryption keys](/pem/latest/custom_encryption_keys/)).
* After upgrading, change the passwords of the database accounts that PEM agents use, including the PEM backend superuser.
