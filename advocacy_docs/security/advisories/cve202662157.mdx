## Summary

mongo_fdw converts _id values to 12-byte MongoDB ObjectIds with libbson functions that read a fixed number of bytes without checking the input length: 12 bytes for a bytea _id, and 24 characters for name-typed values and $oid fields in JSON. A shorter value causes a read past the end of the input, which can crash the PostgreSQL backend or include adjacent memory in the query sent to MongoDB. Any user who can supply an _id value or predicate on a foreign table can trigger it.

## Affected products and versions

* Affected Product: MongoDB Foreign Data Wrapper (mongo_fdw)
* Affected Versions: mongo_fdw 5.5.3 and earlier, on all supported PostgreSQL and EDB Postgres Advanced Server versions

## Remediation/fixes

Impacted users must upgrade to mongo_fdw TBD-MONGO-FDW-FIXED or later. From mongo_fdw TBD-MONGO-FDW-FIXED, mongo_fdw accepts only valid 24-character hexadecimal ObjectIds and 12-byte bytea values.

| Product | VRMF | Remediation/First Fix |
|---------|------|-----------------------|
| mongo_fdw | 5.5.3 and earlier | Update to mongo_fdw TBD-MONGO-FDW-FIXED or later |

## Mitigation

Until you can upgrade, reduce exposure as follows:

* Grant access to mongo_fdw foreign tables only to trusted roles.
