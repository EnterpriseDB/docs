## Summary

mysql_fdw accepts several security-sensitive connection options from roles that are not superusers. A role with USAGE on the mysql_fdw foreign data wrapper can set init_command, which runs arbitrary SQL on the remote MySQL server at every connection, including connections made with other users' mappings on a shared foreign server. The same role can set mysql_default_file, ssl_key, ssl_cert, ssl_ca and ssl_capath, which name files read from the PostgreSQL server host, allowing server-side file reads and connection redirection.

## Affected products and versions

* Affected Product: MySQL Foreign Data Wrapper (mysql_fdw)
* Affected Versions: mysql_fdw 2.9.3 and earlier, on all supported PostgreSQL and EDB Postgres Advanced Server versions

## Remediation/fixes

Impacted users must upgrade to mysql_fdw TBD-MYSQL-FDW-FIXED or later. From mysql_fdw TBD-MYSQL-FDW-FIXED, only superusers can set init_command, mysql_default_file, ssl_key, ssl_cert, ssl_ca and ssl_capath.

| Product | VRMF | Remediation/First Fix |
|---------|------|-----------------------|
| mysql_fdw | 2.9.3 and earlier | Update to mysql_fdw TBD-MYSQL-FDW-FIXED or later |

## Mitigation

Until you can upgrade, reduce exposure as follows:

* Revoke USAGE on the mysql_fdw foreign data wrapper from roles that are not trusted.
* Review existing foreign servers for these options set by roles that are not superusers.
