| Repository           | [Required subscriptions](https://www.enterprisedb.com/products/plans-comparison)                                                          | Contents                                                                                |
|----------------------|---------------------------------------------------------------------------------|-----------------------------------------------------------------------------------------|
| community360         | Open Source Support                                                             | PostgreSQL                                                                              |
| gpsupp               | Open Source Support                                                             | WarehousePG (WHPG)                                                                      |
| clickhouse           | Open Source Support                                                             | Clickhouse                                                                              |
| standard             | Enterprise Postgres®                                                            | Enterprise Postgres, or formerly EDB Postgres Extended Server (PGE), AI for Database, EFM, TDE                                                          |
| enterprise           | Enterprise Postgres® Plus                                                       | Enterprise Postgres (Oracle Compatible) or formerly EDB Postgres Advanced Server (EPAS), TDE+, Vector Engine, Agent Factory, Governance |
| analytics            | Analytics                                                                       | WHPG WEM, PGAA for WHPG                                                                 |
| postgres_distributed | Distributed High Availability                                                   | PGD 5 & 6                                                                               |
| pgai-platform        | Enterprise Postgres® & Enterprise Postgres® Plus                                | Hybrid Manager, PGAA, GPU Acceleration, Vector Engine, Agent Factory, Governance        |
| k8s                  | Enterprise Postgres®, Enterprise Postgres® Plus & Distributed High Availability | CloudNativePG, CNPG-C, CNPG-GC                                                          |
