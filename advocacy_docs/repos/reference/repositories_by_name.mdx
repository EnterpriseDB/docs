## Current major repositories

For current supported products from EDB, the following repositories are available.

| Repository           | Required subscriptions            | Contents                                                             |
|----------------------|-----------------------------------|----------------------------------------------------------------------|
| community360         | E1: Open Source Support           | PostgreSQL                                                           |
| gpsupp               | E1                                | WarehousePG (WHPG)                                                   |
| clickhouse           | E1                                | Clickhouse                                                           |
| standard             | E2: Enterprise Postgres           | PGE, AI for Database, EFM, TDE                                       |
| enterprise           | E3: Enterprise Postgres Plus      | EPAS, TDE+                                                           |
| analytics            | E4: Analytics                     | WHPG WEM, PGAA for WHPG                                              |
| postgres_distributed | E5: Distributed High Availability | PGD 5+                                                               |
| pgai-platform        | E2, E3, E6                        | Hybrid Manager, PGAA, GPU Acceleration, Vector Engine, Agent Factory |
| k8s                  | E2, E3, E5, E6                    | CloudNativePG, CNPG-C, CNPG-GC                                       |
