Tune the workload and infrastructure to ensure consistent, high-speed execution and system continuity.

- [Monitoring and evaluating queries:](query-monitor) Track real-time SQL execution to identify bottlenecks and use the editor to test query logic or performance improvements.

- [Watching a running query with the live query plan:](live-query-plan) Follow the execution plan, processes, and disk I/O of a running query to find skew and stuck processes while the query runs.

- [Managing system resources:](managing-resources) Control CPU and memory boundaries via resource groups and resource queues to prevent contention.

- [Analyzing data distribution:](data-analysis) Investigate table statistics, data skew, and bloat to improve query execution plans.

- [Planning storage capacity:](storage) Monitor disk utilization and historical growth trends across all hosts to prevent "disk full" events.
