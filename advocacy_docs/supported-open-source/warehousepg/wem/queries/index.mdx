Find the queries that slow down your WarehousePG cluster, follow them while they run, and test the changes that fix them.

- [Monitoring and evaluating queries:](query-monitor) Track real-time SQL execution to identify bottlenecks and use the editor to test query logic or performance improvements.

- [Viewing query plans:](live-query-plan) Follow the execution plan, processes, and disk I/O of a running query to find skew and stuck processes while the query runs.
