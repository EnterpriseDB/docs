Safeguard provides disaster recovery (DR) for WarehousePG through [WarehousePG Disaster Recovery](/supported-open-source/warehousepg/whpg-dr/) (`whpg-dr`). Install Safeguard when you want WEM to monitor and manage DR status, backup counts, and WAL continuity between a primary WarehousePG cluster and a DR standby.

!!! Note
    Safeguard requires you install the [host agent](host-agent) on both the primary and DR coordinators, plus the `edb-whpg-dr` package on every host, coordinator and segments, in both clusters. It also requires a storage repository, reachable by both clusters, for `whpg-dr` to archive WAL and base backups to. Set one up by following [Setting up the storage repository](/supported-open-source/warehousepg/whpg-dr/setting-up-primary/storage/) before configuring Safeguard.

## Installing WarehousePG Disaster Recovery

Install `edb-whpg-dr` on the primary cluster by following [Installing the package](/supported-open-source/warehousepg/whpg-dr/setting-up-primary/configuring-primary/#installing-the-package), which installs the RPM on the coordinator and every segment host. Install it on the DR cluster the same way, following [Installing whpg-dr](/supported-open-source/warehousepg/whpg-dr/configuring-dr/#installing-whpg-dr).

Once installed, configure it through Safeguard's **Configuration** tab in WEM. See [Configuring Safeguard](../protecting-data/safeguard#configuring-safeguard) for the WEM-driven option.

## Configuring the host agent for Safeguard

Configure the value of `WEM_TASK_QUEUES` on each coordinator:

1. On the primary coordinator, edit `/etc/edb/acp-host-agent/acp-host-agent.conf` and set:

    ```ini
    WEM_TASK_QUEUES=coordinator-tasks
    ```

1. On the DR coordinator, edit `/etc/edb/acp-host-agent/acp-host-agent.conf` and set:

    ```ini
    WEM_TASK_QUEUES=dr-standby-tasks
    ```

1. If you haven't done it before, start and enable the host agent on both coordinators:

    ```bash
    sudo systemctl enable --now acp-host-agent
    sudo systemctl status acp-host-agent
    ```

1. Verify the service is running and connected to WEM:

    ```bash
    tail -f /var/log/edb/acp-host-agent/acp-host-agent.log
    ```
