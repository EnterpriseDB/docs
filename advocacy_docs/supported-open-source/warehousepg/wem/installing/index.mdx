Install WarehousePG Enterprise Manager (WEM) manually by following the steps on each page in this section, or automate the process with the provided Ansible playbooks.

## Choosing a deployment topology

Before you start, decide where ClickHouse and WEM run relative to your WHPG cluster. This determines whether you also need the gateway collector, and whether you set `OTEL_GATEWAY_ENDPOINT` in `wem.conf`.

- **WEM and ClickHouse on the standby coordinator:** WEM auto-provisions the gateway collector on the standby coordinator internally, so you don't need to set `OTEL_GATEWAY_ENDPOINT`. This is the simplest topology for a single WHPG cluster. If your cluster has no standby coordinator, WEM auto-provisions the gateway on the coordinator instead, so this topology works there too.
- **WEM and ClickHouse on a dedicated host, outside the cluster:** Set `OTEL_GATEWAY_ENDPOINT=<dedicated-host>:4317` in `wem.conf`, and install the [gateway collector](collector) on that same host. Use this topology to keep observability components isolated from the cluster's own nodes, or when one ClickHouse instance serves multiple clusters.

ClickHouse doesn't have to run on either host WEM does. You can instead point WEM at an existing ClickHouse instance you already manage elsewhere, as long as it's reachable from every cluster node's OTel Collector or gateway collector. See [Installing ClickHouse](observability-stack) for details.

The installation process consists of the following steps:

1. Verify the [prerequisites](prerequisites).
1. [Install ClickHouse](observability-stack), the storage backend for historical metrics and log data.
1. [Install the gateway collector](collector), a centralized OTLP ingestion endpoint. Needed only for multi-cluster or external telemetry sources, so skip this step for a single-cluster deployment.
1. [Install and configure WEM](wem) on your dedicated host.
1. [Install the host agent](host-agent) on every cluster node to enable privileged operations, such as HBA editing, and to collect host metrics and logs.

If you're upgrading an existing installation, see [Upgrading](upgrading).
