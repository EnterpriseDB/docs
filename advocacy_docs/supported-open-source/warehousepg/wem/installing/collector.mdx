The gateway collector (`edb-otelcol`) is a centralized OpenTelemetry Protocol (OTLP) ingestion endpoint. It receives telemetry data (metrics, logs, and traces) from external sources and forwards it to ClickHouse.

You need a dedicated gateway collector only when multiple systems or clusters send observability data to the same ClickHouse instance, or when applications outside your WHPG cluster need to ship telemetry to ClickHouse. If your deployment consists of a single WHPG cluster sending data directly to ClickHouse, skip this page. WEM auto-provisions the gateway collector for you in that case.

!!! Note
    Install the gateway collector on the same host as ClickHouse. If ClickHouse runs on the coordinator or standby coordinator, skip this page entirely. WEM auto-provisions the gateway collector for you.

## Installing the gateway collector

1. Configure the EDB repository, then install the gateway collector package:

    ```bash
    export EDB_SUBSCRIPTION_TOKEN=<your-token>
    export EDB_REPO=gpsupp
    curl -1sSLf "https://downloads.enterprisedb.com/$EDB_SUBSCRIPTION_TOKEN/$EDB_REPO/setup.rpm.sh" | sudo -E bash
    sudo yum install -y edb-otelcol
    ```

1. The package ships `/etc/edb/otelcol/config.yaml` with a default pipeline that sends telemetry to a `debug` exporter rather than to ClickHouse. Replace the whole file rather than editing pieces of it, since the two pipelines don't merge:

    ```bash
    sudo tee /etc/edb/otelcol/config.yaml << 'EOF'
    receivers:
      otlp:
        protocols:
          grpc:
            endpoint: "0.0.0.0:4317"
          http:
            endpoint: "0.0.0.0:4318"

    exporters:
      clickhouse:
        endpoint: "clickhouse://default:<password>@localhost:9000"
        database: acp_observability
        timeout: 5s
        retry_on_failure:
          enabled: true
          initial_interval: 5s
          max_interval: 30s
          max_elapsed_time: 300s

    processors:
      batch:
        timeout: 5s
        send_batch_size: 8192

    service:
      pipelines:
        metrics:
          receivers: [otlp]
          processors: [batch]
          exporters: [clickhouse]
        logs:
          receivers: [otlp]
          processors: [batch]
          exporters: [clickhouse]
        traces:
          receivers: [otlp]
          processors: [batch]
          exporters: [clickhouse]
    EOF
    ```

    Under `endpoint`, replace `default` with your ClickHouse username. `default` is just ClickHouse's built-in user, and what [Installing ClickHouse](observability-stack#installing-clickhouse) uses as an example, any username works. Replace `<password>` with that user's password. Replace `localhost` with your ClickHouse host if the gateway collector runs on a different host than ClickHouse.

    Optionally, add a `prometheus` exporter alongside `clickhouse` to also expose a scrape endpoint for an external Prometheus instance, without giving up the ClickHouse write path:

    ```yaml
    exporters:
      clickhouse:
        # ...
      prometheus:
        endpoint: "0.0.0.0:8889"

    service:
      pipelines:
        metrics:
          receivers: [otlp]
          processors: [batch]
          exporters: [clickhouse, prometheus]
    ```

    Only the metrics pipeline supports the `prometheus` exporter. Logs and traces still export to ClickHouse only.

1. Start the gateway collector:

    ```bash
    sudo systemctl daemon-reload
    sudo systemctl enable edb-otelcol
    sudo systemctl start edb-otelcol
    sudo systemctl status edb-otelcol
    ```

1. Verify the gateway collector is listening and forwarding data:

    ```bash
    # Check the gateway is listening
    ss -tlnp | grep -E '4317|4318'

    # Check logs for errors
    journalctl -u edb-otelcol -n 20 --no-pager
    ```
