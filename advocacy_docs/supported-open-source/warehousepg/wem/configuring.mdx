After the initial installation of WarehousePG Enterprise Manager (WEM), use these configuration methods to fine-tune your settings or enable optional observability features. 

### Modifying settings using the WEM console

Administrators can modify operational parameters directly through the web interface. It's the most convenient way to change settings without editing files on the WEM host.

1. Navigate to **Management** > **Settings** and select **Edit Settings**.
1. Update the required fields, such as **ClickHouse URL** or **OTel collector metrics collection interval**.
1. Select **Save** to apply the changes.
1. Restart WEM for the changes to take effect:

    ```bash
    systemctl restart wem
    ```

!!! Note
    Some system parameters are only accessible via the configuration file.

### Modifying settings manually

Edit the configuration file directly on the WEM host to edit parameters not exposed in the browser.

1. Open `/etc/wem/wem.conf` and update the required parameters. See the [Configuration parameters](reference/configuration#wem-parameters) reference for a full list of supported parameters.
1. Restart the WEM service for the changes to take effect:

    ```bash
    systemctl restart wem
    ```



!!! Note
    The installer auto-generates `WEM_COOKIE_SECRET` and `WEM_ADMIN_PASSWORD` if either is blank at install time. The generated values are printed in the install output. Copy them before proceeding. Edit these values only if you want to share sessions across multiple WEM instances or set a specific admin password.

!!! Note "Configuration precedence and overrides"
    WEM prioritizes settings defined in the host environment over those in the WEM console.

    If you define a parameter in the `wem.conf` file, that value takes precedence. Changes made in the WEM console don't override values set in the configuration file. 
    If a change you made through the WEM console does not take effect, check the host configuration file for an existing entry.

### Changing OTel Collector settings

WEM generates and manages `/etc/edb/otelcol/config.yaml` on every cluster node, and regenerates it when its configuration changes or the host agent restarts. Don't edit that file directly, because WEM overwrites your changes.

Collector settings come from WEM's own configuration, such as the ClickHouse URL, the metrics collection interval, and the `WHPG_*` connection parameters. To change them:

1. Update the setting in the WEM console or in `/etc/wem/wem.conf`, then restart WEM:

    ```bash
    sudo systemctl restart wem
    ```

1. Restart the host agent on each node so WEM regenerates the collector configuration and ships it to the node:

    ```bash
    gpssh -f all_hosts -u gpadmin -e "sudo systemctl restart acp-host-agent"
    ```
