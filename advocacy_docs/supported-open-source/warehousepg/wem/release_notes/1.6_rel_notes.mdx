## WEM 1.6.0

Released: 24 Nov 2026

WEM 1.6.0 includes new features, enhancements, and bug fixes. It's released with [host agent 1.2.0](#host-agent-120), which you install separately, so upgrade the host agent on every cluster node along with WEM. It also removes the compatibility links that WEM 1.5 kept and moves several settings from `wem.conf` into the console, so review the [changes](#changes) and [upgrade steps](../installing/upgrading) before you upgrade.

### Highlights

- **Live query plan and process monitoring:** Watch the execution plan of a running query as it executes, and see the processes, disk I/O, and skew behind it. See [Viewing query plans](../queries/live-query-plan).
- **FlowServer jobs management:** Create, start, stop, and remove FlowServer jobs, and review their activity, from the WEM console. See [Running FlowServer jobs](../flowserver-jobs).
- **Startup and runtime settings:** The **Settings** tab now separates the settings that need a restart from the settings you can change without one. See [Configuring WEM](../configuring).

### New features

- **Live query plan:** Select the plan icon on a running query in **Active Queries** to watch its plan update until the query ends, with the rows processed, the time, and the row skew across segments for each step. It requires the `whpg_live_query_plan` extension. See [Viewing query plans](../queries/live-query-plan).
- **Process monitoring and per-query disk I/O:** Find stragglers and blocked queries in the new **Processes** tab, and see disk reads and writes for each query in **Active Queries** and each session in **Sessions**. See [Viewing query plans](../queries/live-query-plan) and [Monitoring and evaluating queries](../queries/query-monitor).
- **FlowServer jobs management:** Create, start, stop, and remove FlowServer jobs, and review their status and activity, from the new **FlowServer** page. It requires host agent 1.2.0 on the coordinator, and FlowServer running on the coordinator. See [Running FlowServer jobs](../flowserver-jobs).
- **Startup and runtime settings:** The **Settings** tab shows startup settings as read-only, and groups the settings you can change without a restart, such as the cluster name, slow query logging, and the AI Assistant key, in a separate section. See [Configuring WEM](../configuring).

### Changes

- **Compatibility links removed:** WEM 1.6 removes the compatibility measures that WEM 1.5 kept for the previous file locations. If your scripts, cron jobs, monitoring, or log tools still use an old path, switch to the new one:

    | Item | Old path | New path |
    |------|----------|----------|
    | Binary | `/usr/local/greenplum-db/wem/wem` or `/usr/edb/wem/wem` | `/usr/edb/wem/bin/wem` |
    | Log file | `/var/log/wem/wem.log` | `/var/log/edb/wem/wem.log` |
    | Configuration file | `/etc/wem/wem.conf` | `/etc/edb/wem/wem.conf` |

    WEM no longer reads `/etc/wem/wem.conf` when `/etc/edb/wem/wem.conf` is missing. The upgrade prints a `[WARN]` line for each link it removes, and names the systemd units, cron files, and `wem.conf` files that still use an old path. See [Upgrading WarehousePG Enterprise Manager](../installing/upgrading#upgrading-wem).
- **Runtime settings moved out of `wem.conf`:** Settings such as the cluster name, query thresholds, AI Assistant key, and FlowServer address are now stored in WEM and managed from **Settings**. On upgrade, WEM imports the values from `wem.conf` once, but keeps any value you saved in the WEM 1.5 console. Later changes to these parameters in `wem.conf` have no effect, so check your runtime settings in **Management** > **Settings** after you upgrade. See [Configuring WEM](../configuring).
- **ppc64le packages:** WEM 1.6 includes ppc64le packages for RHEL 8, RHEL 9, and RHEL 10.
- **Activity tabs renamed:** The **Activity** tab on the **Backups** page is now **Activities**.

### Bug fixes

- Fixed a partitioned table with mixed storage being listed more than once on the **Database Objects** page.
- Fixed the **Active Queries** tooltip on the cluster overview not matching how the panel filters queries. The top-row tiles are now the same height.
- Fixed the AI Assistant model setting not being applied during remote upgrades.
- Fixed the **HBA Editor** failing with `no approved agent polling "coordinator-tasks"` when an approved host agent has a task queue override that lists several queues.

## Host agent 1.2.0

Host agent 1.2.0 is released with WEM 1.6.0 as a separate package that you install on every cluster node. It installs `edb-otelcol` 0.158.0-1edb2 as a dependency. See [Installing the host agent](../installing/host-agent).

### New features

- **FlowServer jobs management:** The host agent on the coordinator now connects to FlowServer to run the job actions that WEM requests. See [Running FlowServer jobs](../flowserver-jobs).

### Changes

- **Host agent settings moved to `wem.conf`:** The host agent now reads the settings that connect it to WEM, `WEM_CONNECT_ADDRESS`, `WEM_TASK_QUEUES`, and `WEM_DATABASE`, from `/etc/edb/acp-host-agent/wem.conf`. The common settings stay in `acp-host-agent.conf`. The upgrade moves your existing values and keeps them. Update any scripts that edit these settings. See [Host agent configuration](../reference/host-agent-config).

### Bug fixes

- Fixed a host agent that started while WEM was unreachable staying without segment information after WEM came back, which made tasks that need the data directory, such as backups, fail until you restarted the agent.
- Fixed the backup helper hiding the real cause when it can't resolve the WarehousePG data directory. It now reports the data directory problem.
- Fixed the host agent log omitting the cause of a failed registration with WEM.
