## WEM command reference

WEM includes a powerful CLI tool for initialization, diagnostics, and service management.

- [wem setup:](commands#wem-setup) Initialize the monitoring database, install schemas, and set the admin password.
- [wem doctor:](commands#wem-doctor) Run pre-flight checks to validate database connectivity and observability stack reachability.

## Metrics

WEM collects WHPG cluster health, query state, and host hardware metrics through an OTel Collector pipeline and stores them in ClickHouse. It also exposes a set of [Prometheus metrics](metrics) at `/prom/metrics`, covering canary checks and WEM's own internal state.

## Role permissions matrix

WEM uses Role-Based Access Control (RBAC). The matrix below shows which panels each profile can access by default, and whether they have read-only or read-write access within that panel. Within a panel, individual actions, such as running a backup or deleting an alert rule, carry their own default grants too. See [Defining role-based access control](../system-access/management#defining-role-based-access-control).

**Dashboard** is always visible to all profiles and isn't listed here because it isn't controlled by the permissions system.

| Panel | Admin | Operator | Viewer |
|-------|-------|----------|--------|
| Cluster | Yes | Yes | Yes |
| Query Monitoring | Yes | Yes | Yes |
| Query Editor | Yes | Yes | View only |
| Data Analysis | Yes | Yes | No |
| Storage | Yes | Yes | Yes |
| System Metrics | Yes | Yes | Yes |
| Backups | Yes | Yes | No |
| Safeguard | Yes | No | No |
| Logs | Yes | Yes | No |
| Canary Checks | Yes | Yes | Yes |
| Alerts | Yes | Yes | Yes |
| Access Management | Yes | No | No |
| Resource Management | Yes | Yes | No |
| Management | Yes | No | No |

Viewers can open **Query Editor** to see query and result history, but can't execute queries.

**Safeguard** covers disaster-recovery backup and restore and is separate from the **Backups** panel. Its default access is Admin-only, but unlike **Management**, this default can be changed from **Management > Permissions**.

!!! Note
    This matrix represents the default system settings. Administrators can customize panel and action access for each profile via **Management > Permissions**. The **Management** panel is always restricted to the Admin profile and can't be reassigned.

## Keyboard shortcuts

Speed up your workflow within the WEM interface using the following shortcuts:

| Shortcut | Action | Context |
|----------|--------|---------|
| `Ctrl+Enter` (`Cmd+Enter` on Mac) | Execute query | Query Editor |
| `Ctrl+K` (`Cmd+K` on Mac) | Open AI Assistant | Query Editor, Alerts |
| `Escape` | Close modal/dialog | Anywhere except in-progress dialogs |
