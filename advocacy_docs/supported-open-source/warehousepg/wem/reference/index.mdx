Review WarehousePG Enterprise Manager (WEM) technical specifications, definitions, and permission structures.

## Configuration parameters

A complete reference for all [WEM and Collector configuration parameters](configuration), including defaults, types, and descriptions.

## Host agent configuration

A complete reference for all [`acp-host-agent` configuration variables](host-agent-config), including WEM connection settings, agent identity, and logging.

## Alert rules

WEM ships three sets of [Prometheus alert rules](alert-rules). Canary rules cover cluster health indicators. System rules cover WEM service availability. WHPG rules cover query performance, disk usage, segment health, and data distribution.

## WEM command reference

WEM includes a powerful CLI tool for initialization, diagnostics, and service management.

- [wem setup:](commands#wem-setup) Initialize the monitoring database, install schemas, and set the admin password.
- [wem doctor:](commands#wem-doctor) Run pre-flight checks to validate database connectivity and observability stack reachability.

## Prometheus metrics

WEM exposes a complete set of [Prometheus metrics](metrics) covering cluster health, query states, resource groups, host hardware, canary checks, and WEM internal state.

## Role permissions matrix

WEM uses Role-Based Access Control (RBAC). The matrix below shows which panels each profile can access by default, and whether they have read-only or read-write access within that panel.

**Dashboard** and **Alerts** are always visible to all profiles and aren't listed here because they aren't controlled by the permissions system.

| Panel | Admin | Operator | Viewer |
|-------|-------|----------|--------|
| Cluster | Yes | Yes | Yes |
| Query Monitoring | Yes | Yes | Yes |
| Query Editor | Yes | Yes | No |
| Data Analysis | Yes | Yes | No |
| Storage | Yes | Yes | Yes |
| System Metrics | Yes | Yes | Yes |
| Backups | Yes | Yes | No |
| Logs | Yes | Yes | No |
| Canary Checks | Yes | Yes | Yes |
| Access Management | Yes | No | No |
| Resource Management | Yes | Yes | No |
| Management | Yes | No | No |

!!! Note
    This matrix represents the default system settings. Administrators can customize panel access for each profile via **Management > Permissions**. The **Management** panel is always restricted to the Admin profile and can't be reassigned.
