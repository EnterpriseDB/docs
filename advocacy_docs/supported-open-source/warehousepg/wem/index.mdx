WarehousePG Enterprise Manager (WEM) is a comprehensive management and monitoring platform for WarehousePG (WHPG) clusters. By integrating real-time telemetry, AI-assisted development, and interactive configuration, WEM streamlines complex distributed database operations into a single visual interface. It provides a single pane of glass for auditing cluster health, tuning SQL performance, and managing security in high-performance environments.

## Why WEM?

Managing a distributed architecture across multiple segment nodes is inherently complex. WEM simplifies cluster management by providing:

- **Consolidated visibility:** Stop jumping between nodes. View host metrics, SQL statistics, and system logs in one place.

- **Built-in intelligence:** Use the AI Assistant to explain execution plans and optimize distributed queries.

- **Proactive health:** Identify data skew, monitor resource bottlenecks, and run automated Canary checks.


### Key capabilities

WEM introduces a robust suite of tools for the modern database administrator and developer:

- **Observability & health**
    - [Real-time & historical metrics:](overview/architecture) Monitor live cluster pulse using WEM's internal database extraction engine, and analyze long-term trends stored in ClickHouse.

    - [Cluster overview:](monitoring/cluster-overview) A dedicated dashboard for the immediate health status of your coordinator and segment architecture.

    - [Hardware monitoring:](monitoring/system-metrics) Real-time and historical tracking of CPU, memory, disk I/O, and network usage across the cluster, filterable by host and time range.

    - [Log management:](monitoring/logs) Searchable, aggregated log streams powered by ClickHouse for rapid root-cause analysis.

    - [Alerting & incident management:](monitoring/alerts) Configurable alert rules against canary check failures, segment outages, disk thresholds, and long-running queries, with notifications, silencing, and history.

- **Intelligence & analysis**
    - [Query monitoring & editor:](performance/query-monitor) Track active queries and sessions in real time, and use a full-featured SQL editor with an AI Assistant and a unified output panel for query results, `EXPLAIN`, and `ANALYZE`, to write, optimize, and explain distributed queries.

    - [Data skew & schema analysis:](performance/data-analysis) Deep-dive tools to analyze table distribution, compression, bloat, and missing statistics, keeping schemas efficient across the cluster segments.

    - [Storage capacity planning:](performance/storage) Audit disk utilization across the cluster, spot storage imbalances between hosts, and forecast future capacity needs from historical growth trends.

    - [PXF management:](performance/data-analysis#managing-pxf) Start, stop, and sync the PXF service across your cluster from a dedicated tab, dispatched through the host agent.

- **Cluster administration**
    - [Cluster lifecycle management:](monitoring/cluster-overview#starting-stopping-and-restarting-the-cluster) Start, stop, and restart the cluster, and recover failed segments, directly from WEM, without shell access to the coordinator.

    - [Resource governance:](performance/managing-resources) Configure resource groups or resource queues to govern CPU, memory, and concurrency limits per workload, and schedule limit changes for specific days and times.

    - [Access policies:](system-access/access-management) An interactive HBA editor for `pg_hba.conf` and role-based permissions at the schema and table level.

    - [Administrative management:](system-access/management) A centralized interface for user accounts, profiles, and per-action permission grants, alongside existing panel-level access controls.

    - [Audit logging:](system-access/management#auditing-administrative-actions) A chronological record of every administrative action, including logins, failed logins, and account changes, filterable by time range and action type.

    - [System settings audit:](system-access/access-management#auditing-system-settings) A searchable interface to verify and audit cluster-level configuration parameters.

    - [Secure, self-registering host agents:](installing/host-agent) Host agents register themselves with WEM automatically and authenticate every connection with mutual TLS, with Admin approval for each new agent from a dedicated tab.

    - [Dedicated database role:](installing/wem#target-cluster) WEM connects to your WarehousePG cluster with a dedicated login role, created automatically during setup, instead of reusing the same superuser credentials for every connection.

    - [Canary checks:](monitoring/monitoring) Automated "heartbeat" tests that proactively verify cluster connectivity and query responsiveness.

- **Data protection**
    - [Backup & recovery:](protecting-data/backups) Take, restore, and schedule backups directly from WEM, and audit recovery points and snapshot health across the cluster.

    - [Disaster recovery:](protecting-data/safeguard) Check DR readiness at a glance with Safeguard, and manage backups, restores, and promotion between your primary cluster and a DR standby, through `whpg-dr` integration.
