Verify cluster health, maintain operational awareness, respond to system events in real time, and control the cluster directly, through the following core actions:

- [Verifying and managing cluster health:](cluster-overview) Maintain a real-time view of the cluster's topology and health, and start, stop, restart, or recover it directly from WEM when coordinator, standby, or segment nodes need attention.

- [Visualizing hardware performance:](system-metrics) Track the physical health of your infrastructure. Identify OS-level bottlenecks, such as CPU spikes, memory exhaustion, or network latency across specific hosts.

- [Validating database responsiveness:](monitoring) Ensure the database engine is actively processing requests. Review automated Canary checks, which are synthetic SQL probes that verify connectivity and execution speed.

- [Auditing system logs:](logs) Investigate the unified stream of system and database telemetry stored in ClickHouse, to pinpoint the root cause of query failures or administrative changes.

- [Managing alerts:](alerts) Evaluate metric thresholds against ClickHouse and govern the incident lifecycle through real-time notifications.
