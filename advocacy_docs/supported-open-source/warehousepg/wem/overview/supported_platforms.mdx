## Supported WarehousePG versions

WarehousePG Enterprise Manager (WEM) is compatible with the following versions of WarehousePG (WHPG):

| WHPG version | Supported RHEL versions |
|--------------|--------------------------|
| 6.x          | RHEL 7, RHEL 8, RHEL 9   |
| 7.x          | RHEL 8, RHEL 9           |

## Supported platforms

| Component  | Supported RHEL versions        |
|------------|---------------------------------|
| WEM        | RHEL 8, RHEL 9                  |
| ClickHouse | RHEL 8, RHEL 9                  |

WEM requires ClickHouse for metrics and log storage. You can deploy ClickHouse inside your WHPG cluster, on the coordinator or standby coordinator, or on a separate host outside the cluster.

## Host agent compatibility

WEM 1.4 requires `acp-host-agent` 1.1.0 or later on every cluster node, an older host agent can't connect. See [Upgrading the host agent](../installing/upgrading#upgrading-the-host-agent) if you're upgrading WEM.

!!! Note
    Neither WEM nor ClickHouse supports RHEL 7. If you're running WHPG 6.x on RHEL 7, you can't deploy WEM or ClickHouse on a node inside that cluster. Deploy WEM and ClickHouse on a separate host running a supported RHEL version instead. WEM can still monitor the RHEL 7 cluster remotely.
