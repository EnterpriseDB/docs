**Release Date:** September 28, 2026

## Packages included

The release of FlowServer for WarehousePG 1.1.1 comprises the following packages and their dependencies:

| Package name | Package version | Required WarehousePG version |
| ------------ | --------------- | ---------------------------- |
| whpg7-flow-server | 1.1.1 | 7.x |

## Improvements

- FlowServer packages are now available for the ppc64le (Power) architecture on RHEL 8 and RHEL 9, in addition to x86_64. See [Supported platforms](/supported-open-source/warehousepg/flowserver/overview/supported_platforms).

## Security fixes

- Upgraded `github.com/rabbitmq/amqp091-go` from v1.10.0 to v1.15.0 to address [CVE-2026-77403](https://nvd.nist.gov/vuln/detail/CVE-2026-77403), [CVE-2026-77404](https://nvd.nist.gov/vuln/detail/CVE-2026-77404), [CVE-2026-77405](https://nvd.nist.gov/vuln/detail/CVE-2026-77405), [CVE-2026-77406](https://nvd.nist.gov/vuln/detail/CVE-2026-77406), [CVE-2026-77407](https://nvd.nist.gov/vuln/detail/CVE-2026-77407), [CVE-2026-77408](https://nvd.nist.gov/vuln/detail/CVE-2026-77408), [CVE-2026-77410](https://nvd.nist.gov/vuln/detail/CVE-2026-77410), [CVE-2026-77411](https://nvd.nist.gov/vuln/detail/CVE-2026-77411), [CVE-2026-77412](https://nvd.nist.gov/vuln/detail/CVE-2026-77412), and [CVE-2026-79921](https://nvd.nist.gov/vuln/detail/CVE-2026-79921).
- Upgraded `google.golang.org/grpc` from v1.82.0 to v1.83.2 to address [CVE-2026-84304](https://nvd.nist.gov/vuln/detail/CVE-2026-84304) ([GO-2026-6348](https://pkg.go.dev/vuln/GO-2026-6348)) and [CVE-2026-84445](https://nvd.nist.gov/vuln/detail/CVE-2026-84445) ([GO-2026-6443](https://pkg.go.dev/vuln/GO-2026-6443)).
- Upgraded `github.com/valyala/fasthttp` from v1.60.0 to v1.70.0 to address [GO-2026-4950](https://pkg.go.dev/vuln/GO-2026-4950).
- Upgraded `github.com/klauspost/compress` from v1.18.0 to v1.18.7 to address [GO-2026-5841](https://pkg.go.dev/vuln/GO-2026-5841).
- Upgraded `golang.org/x/text` from v0.38.0 to v0.41.0 to address [CVE-2026-56852](https://nvd.nist.gov/vuln/detail/CVE-2026-56852) ([GO-2026-5970](https://pkg.go.dev/vuln/GO-2026-5970)).
