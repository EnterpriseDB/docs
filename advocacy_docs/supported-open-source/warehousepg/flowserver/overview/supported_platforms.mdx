## Supported WarehousePG versions

FlowServer for WarehousePG is compatible with the following version of WarehousePG:

- WarehousePG (WHPG) version 6.x running on RH7, RH8, or RH9.
- WarehousePG version 7.x running on RH8 or RH9.

## Supported architectures

FlowServer for WarehousePG is available for the following architectures:

- x86_64
- ppc64le (Power), available from FlowServer 1.1.1 for WarehousePG 7.x running on RH8 or RH9 only.
