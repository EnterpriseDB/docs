## Supported WarehousePG versions

FlowServer for WarehousePG is compatible with the following version of WarehousePG:

- WarehousePG (WHPG) version 6.x running on RHEL 7, RHEL 8, or RHEL 9.
- WarehousePG version 7.x running on RHEL 8 or RHEL 9.

## Supported architectures

FlowServer for WarehousePG is available for the following architectures:

- x86_64, for all WarehousePG versions and operating systems listed above.
- ppc64le (Power), available from FlowServer 1.1.1 for WarehousePG 7.x running on RHEL 8 or RHEL 9 only.
