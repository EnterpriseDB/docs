The user_profile documentation describes the latest version, including minor releases and patches. These release notes cover what's new in each release.

## 1.0.3

Release date: October 28, 2026

!!!info No SQL changes

This release doesn't change the SQL objects. The extension version stays `1.0`, so you don't need to run `ALTER EXTENSION`. See [Upgrading user_profile](installing.mdx#upgrading-user_profile) for the upgrade steps.
!!!

### Changes

-   Added support for RHEL 7 on WarehousePG 6. Earlier versions used an SQLite feature that needs SQLite 3.24 or later, which RHEL 7 doesn't have. user_profile 1.0.3 works with the RHEL 7 system SQLite (3.7.17).

### Bug fixes

-   Fixed an integer overflow that made passwords expire too early, grace periods end too early, and account locks release too early. The overflow occurred when `PASSWORD_LIFE_TIME`, `PASSWORD_GRACE_TIME`, or `PASSWORD_LOCK_TIME` was longer than about 24.8 days. For example, a `PASSWORD_LIFE_TIME` of 30 or 90 days made passwords expire at once. If any profile sets one of these parameters to a longer time, upgrade to 1.0.3 or later. Roles that an earlier version marked as expired by mistake keep that state after the upgrade. At the next login, these roles must change their password with `ALTER ROLE ... PASSWORD`, or an administrator sets a new password.
-   Fixed the error that `up_alter_role_profile()` returned for a profile that doesn't exist. The function now returns `user_profile: profile "<name>" does not exist` instead of an internal SQLite error.
