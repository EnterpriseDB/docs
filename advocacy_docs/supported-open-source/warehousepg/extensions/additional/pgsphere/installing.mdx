Install whpg-pgsphere on each host in your WarehousePG cluster, as it doesn't ship as part of the WarehousePG server package.

!!!info Version availability

whpg-pgsphere is available starting with WarehousePG 7.3.0.
!!!

## Installing the package

Refer to [Downloading and installing an extension](/supported-open-source/warehousepg/extensions/additional/#downloading-and-installing-an-extension) for installation instructions. The package name is `edb-whpg7-pgsphere`.

## Registering whpg-pgsphere

After you install the package on every host, create the extension in each database where you want to use it:

```sql
CREATE EXTENSION pg_sphere;
```

## Verifying the installation

Confirm that `pg_sphere` is registered in the database, and check the installed version:

```sql
\dx pg_sphere
SELECT pg_sphere_version();
```

## Upgrading whpg-pgsphere

First, upgrade the `whpg-pgsphere` package on every host. Refer to [Upgrading an extension](/supported-open-source/warehousepg/extensions/additional/#upgrading-an-extension) for downloading and distributing the new package. The package name is `edb-whpg7-pgsphere`.

Then restart WarehousePG with `gpstop -ar`, or reconnect every session. Upgrading the package replaces the `pg_sphere.so` library on disk, but sessions that already loaded the old library keep using it. For example, they keep raising `could not find function "healpix_nest"` until they reconnect.

Patch releases, such as 1.5.2-WHPG.1, keep the same extension version, 1.5.2, so you don't need to run `ALTER EXTENSION pg_sphere UPDATE` after you upgrade the package. For a release that changes the extension version, update the extension in each database where you registered it, for example:

```sql
ALTER EXTENSION pg_sphere UPDATE TO '<new_version>';
```

!!!info Upgrading from 1.5.2-WHPG

1.5.2-WHPG (package `edb-whpg7-pgsphere` 1.5.2-1) is built without the HEALPix functions and the `smoc` type, and 1.5.2-WHPG.1 (package 1.5.2-2) includes them. Both register as extension version 1.5.2, so there's no update script between them. If you ran `CREATE EXTENSION pg_sphere` in a database with 1.5.2-WHPG, upgrading the package doesn't add the new objects to that database, and `ALTER EXTENSION pg_sphere UPDATE` does nothing.

To check whether a database is affected, run the following query. A result of `0` means the database was created with 1.5.2-WHPG and has none of the HEALPix objects. Databases whose catalog already contains `healpix_nest` only need the package upgrade.

```sql
SELECT count(*) FROM pg_proc WHERE proname = 'healpix_nest';
```

To add the HEALPix functions and the `smoc` type to an affected database, drop and re-create the extension. `DROP EXTENSION` cascades to every `spoint` and `spoly` column, so plan to reload the data.
!!!

## Uninstalling whpg-pgsphere

```sql
DROP EXTENSION pg_sphere;
```

!!!warning

`DROP EXTENSION` cascades to every column that uses a pgSphere data type, such as `spoint` or `spoly`, and drops the column data. Back up or export the data first.
!!!
