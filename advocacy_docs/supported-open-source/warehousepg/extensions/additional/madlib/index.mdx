Use whpg-madlib to run data-parallel implementations of mathematical, statistical, graph, machine learning, and deep learning methods on structured and unstructured data without moving the data out of the database. It runs inside WarehousePG itself, so you don't need to install or maintain any additional services alongside your cluster.

whpg-madlib is a fork of [Apache MADlib](http://madlib.apache.org/documentation.html), an open source library for scalable in-database analytics, with changes specific to WarehousePG. The source is in the [whpg-madlib repository](https://github.com/warehouse-pg/whpg-madlib).

To get started with whpg-madlib, see:

-   [Release notes](release_notes.mdx)
-   [Installing whpg-madlib](installing.mdx)
-   [Using whpg-madlib](using.mdx)

See [Machine learning and deep learning using MADlib](/warehousepg/latest/admin_guide/analytics/madlib.mdx) in the WarehousePG 7 analytics guide, or the [WarehousePG 6 version](/warehousepg/6/admin_guide/analytics/madlib.mdx), for an overview of the machine learning and deep learning capabilities. See the [Apache MADlib documentation](http://madlib.apache.org/documentation.html) for the full function reference.
