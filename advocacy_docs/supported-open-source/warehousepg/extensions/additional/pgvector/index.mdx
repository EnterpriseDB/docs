!!!info Version availability

whpg-vector is available starting with WarehousePG 7.3.0.
!!!

The whpg-vector extension provides high-performance vector similarity search capabilities for WarehousePG (WHPG). By representing complex data (like text, images, or audio) as machine-learning-generated embeddings, you can perform semantic and syntactic searches at scale.

The WarehousePG whpg-vector extension is equivalent to version 0.7.4 of the pgvector extension used with PostgreSQL. See [Limitations](using.mdx#limitations) to understand the limitations of the WarehousePG version of the extension.

To get started with whpg-vector, see:

-   [Release notes](release_notes.mdx)
-   [Installing whpg-vector](installing.mdx)
-   [Using whpg-vector](using.mdx)
