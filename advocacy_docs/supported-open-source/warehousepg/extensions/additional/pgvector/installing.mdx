## Installing the extension

Download and install whpg-vector from the [whpg-vector repository](https://github.com/warehouse-pg/whpg-vector).

## Registering whpg-vector

After you install whpg-vector on every host, create the extension in each database where you want to use it:

```sql
CREATE EXTENSION vector;
```

## Verifying the installation

Confirm that `vector` is registered in the database:

```sql
\dx vector
```

## Upgrading whpg-vector

After you install the new whpg-vector package on every host, update the extension in each database where you registered it:

```sql
ALTER EXTENSION vector UPDATE;
```
