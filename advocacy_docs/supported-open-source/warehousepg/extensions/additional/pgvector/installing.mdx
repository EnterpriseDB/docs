Install the `whpg-vector` package on each host in your WarehousePG cluster, as it doesn't ship as part of the WarehousePG server package.

!!!info Version availability

whpg-vector is available starting with WarehousePG 7.3.0.
!!!

## Installing the package

Refer to [Downloading and installing an extension](/supported-open-source/warehousepg/extensions/additional/#downloading-and-installing-an-extension) for repository setup instructions. The package name is `edb-whpg7-pgvector`.

## Registering whpg-vector

After you install the package on every host, create the extension in each database where you want to use it:

```sql
CREATE EXTENSION vector;
```

## Verifying the installation

Confirm that `vector` is registered in the database:

```sql
\dx vector
```

## Upgrading whpg-vector

First, upgrade the `whpg-vector` package on every host. Refer to [Upgrading an extension](/supported-open-source/warehousepg/extensions/additional/#upgrading-an-extension) for downloading and distributing the new package. The package name is `edb-whpg7-pgvector`.

Then update the extension in each database where you registered it:

```sql
ALTER EXTENSION vector UPDATE;
```

## Uninstalling whpg-vector

```sql
DROP EXTENSION vector;
```
