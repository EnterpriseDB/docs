The `whpg_live_query_plan` extension shows the execution plan of a running query from another session, with per-node, per-segment progress. WarehousePG Enterprise Manager (WEM) 1.6 and later use the extension to show live query plans.

For the changes in each release, see the [release notes](release_notes.mdx).

## Installing whpg_live_query_plan

For full installation instructions, including package names and cluster configuration, see [Installing the live query plan extension](/supported-open-source/warehousepg/wem/installing/live-query-plan/).

## Using whpg_live_query_plan

For guidance on watching running queries, see [Viewing query plans](/supported-open-source/warehousepg/wem/queries/live-query-plan/). For the extension's settings, see [Live query plan extension settings](/supported-open-source/warehousepg/wem/reference/live-query-plan-extension/).
