These release notes cover what's new in each release of the `whpg_live_query_plan` extension.

## 1.0.0

Release date: November 24, 2026

-   First release of `whpg_live_query_plan`. It provides the live plan, process, and disk I/O data of a running query, including the per-node totals and skew from the `whpg_live_query_plan_summary` function. WarehousePG Enterprise Manager (WEM) 1.6 and later use this data to show live query plans.
