Install `whpg-backup` on all hosts in your WarehousePG cluster.

## Downloading and installing the utility

1. On the coordinator, download the package from the EDB repository:

    <TabContainer syncKey="download">
    <Tab title="RHEL 8, 9">

    ```bash
    export EDB_SUBSCRIPTION_TOKEN=<your-token>
    export EDB_REPO=gpsupp
    curl -1sSLf "https://downloads.enterprisedb.com/$EDB_SUBSCRIPTION_TOKEN/$EDB_REPO/setup.rpm.sh" | sudo -E bash
    sudo dnf download whpg-backup
    ```

    </Tab>
    <Tab title="RHEL 7">

    ```bash
    export EDB_SUBSCRIPTION_TOKEN=<your-token>
    export EDB_REPO=gpsupp
    curl -1sSLf "https://downloads.enterprisedb.com/$EDB_SUBSCRIPTION_TOKEN/$EDB_REPO/setup.rpm.sh" | sudo -E bash
    sudo yumdownloader whpg-backup
    ```

    </Tab>
    </TabContainer>

1. On the coordinator, create a file `all_hosts` which lists all hosts in the WHPG cluster. For example:

    ```ini
    cdw
    scdw
    sdw1
    sdw2
    sdw3
    ```

1. From the coordinator, transfer the package to all hosts in the cluster. Use the `gpsync` utility on WarehousePG 7, or the `gpscp` utility on WarehousePG 6:

    <TabContainer syncKey="whpg-version">
    <Tab title="WHPG 7">

    ```bash
    gpsync -f all_hosts <whpg-backup-package-name> =:/tmp
    ```

    </Tab>
    <Tab title="WHPG 6">

    ```bash
    gpscp -f all_hosts <whpg-backup-package-name> =:/tmp
    ```

    </Tab>
    </TabContainer>

    Where `<whpg-backup-package-name>` is the name of the WarehousePG Backup package file you downloaded, for example `whpg-backup-1.33.1-WHPG-2.el8.x86_64.rpm`.

1. From the coordinator, use the `gpssh` utility to install the package on all hosts:

    <TabContainer syncKey="install">
    <Tab title="RHEL 8, 9">

    ```bash
    gpssh -f all_hosts -e 'sudo dnf install -y /tmp/<whpg-backup-package-name>'
    ```

    </Tab>
    <Tab title="RHEL 7">

    ```bash
    gpssh -f all_hosts -e 'sudo yum install -y /tmp/<whpg-backup-package-name>'
    ```

    </Tab>
    </TabContainer>

1. Verify the installation by checking the `gpbackup` and `gprestore` versions:

    ```bash
    gpbackup --version
    gprestore --version
    ```
