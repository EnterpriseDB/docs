Released: 28 Sep 2026

WarehousePG Disaster Recovery 1.1.0 adds ppc64le packages and fixes for backing up and restoring clusters that use tablespaces.

### Features

- Adds ppc64le packages for RHEL-compatible 8 and 9. ppc64le packages work with WarehousePG 7 only.
- `whpg-dr list-cluster` now shows the `WHPG_DR_HOME` path for each cluster, even when no cluster is configured. It also lists clusters that have only a restore configuration, such as restore-only recovery hosts.

### Bug fixes

- Fixed restores that left every tablespace unreachable. After a restore, `whpg-dr` now points each `pg_tblspc` symbolic link at the correct per-segment tablespace directory before WAL replay. `whpg-dr restore --resume-failed` also repairs links left by an earlier version.
- Fixed POSIX backups that silently skipped tablespace data. Backups now capture each segment's tablespace directory and fail if the copy doesn't complete, for example when a tablespace file system isn't mounted.
- Fixed concurrent segment restores on the same host deleting each other's tablespace files, and a race when parallel restores shared a tablespace location.
- Cancelling a backup or restore now reliably terminates local and remote Barman processes before `whpg-dr` releases state files and cluster locks.
- Fixed deleted backup metadata being recreated by a Barman process that was still running.
- Fixed remote shell commands that contain single quotes.

### Dependencies

- Upgraded the bundled Barman from 3.19.1 to 3.20.0.
