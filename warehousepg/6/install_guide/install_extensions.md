# Procedural Language, Machine Learning, and Geospatial Extensions

The extension documentation in the _[WarehousePG Reference Guide](https://www.enterprisedb.com/docs/warehousepg/6/ref_guide/)_ contains information about installing extension packages and using extensions.

- [WarehousePG PL/R Language Extension](https://www.enterprisedb.com/docs/warehousepg/6/admin_guide/analytics/procedural_languages/pl_r/)
- [WarehousePG PL/Java Language Extension](https://www.enterprisedb.com/docs/warehousepg/6/admin_guide/analytics/procedural_languages/pl_java/)
- [WarehousePG MADlib Extension for Analytics](https://www.enterprisedb.com/docs/supported-open-source/warehousepg/extensions/additional/madlib/)
- [WarehousePG PostGIS Extension](https://www.enterprisedb.com/docs/warehousepg/6/admin_guide/analytics/postGIS/)

> **Important** If you intend to use an extension package with WarehousePG 6 you must install and use a WarehousePG extension package that is built for WarehousePG 6. Any custom modules that were used with earlier versions must be rebuilt for use with WarehousePG 6.
