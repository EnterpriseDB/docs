# DROP USER

<a id="topic1"></a><a id="dm20941"></a><a id="sql_command_desc"></a>

Removes a database role.

<a id="section2">

</a>

## Synopsis

<a id="sql_command_synopsis"></a>

```
DROP USER [IF EXISTS] <name> [, ...]
```

<a id="section3">

</a>

## Description

`DROP USER` is an alias for [DROP ROLE](https://www.enterprisedb.com/docs/warehousepg/6/ref_guide/sql_commands/DROP_ROLE/). See [DROP ROLE](https://www.enterprisedb.com/docs/warehousepg/6/ref_guide/sql_commands/DROP_ROLE/) for more information.

<a id="section5">

</a>

## Compatibility

There is no `DROP USER` statement in the SQL standard. The SQL standard leaves the definition of users to the implementation.
