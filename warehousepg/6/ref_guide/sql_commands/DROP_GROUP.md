# DROP GROUP

<a id="topic1"></a><a id="cw20941"></a><a id="sql_command_desc"></a>

Removes a database role.

<a id="section2">

</a>

## Synopsis

<a id="sql_command_synopsis"></a>

```
DROP GROUP [IF EXISTS] <name> [, ...]
```

<a id="section3">

</a>

## Description

`DROP GROUP` is an alias for `DROP ROLE`. See [DROP ROLE](https://www.enterprisedb.com/docs/warehousepg/6/ref_guide/sql_commands/DROP_ROLE/) for more information.

<a id="section5">

</a>

## Compatibility

There is no `DROP GROUP` statement in the SQL standard.

</a>
