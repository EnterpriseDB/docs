# Installation Utilities Reference

References for the command-line management utilities used to install and initialize a WarehousePG cluster.

For a full reference of all WarehousePG utilities, see the [WarehousePG Utility Guide](https://www.enterprisedb.com/docs/warehousepg/latest/ref_guide/utility_guide/).

The following WarehousePG management utilities are located in `$GPHOME/bin`.

- [gpactivatestandby](https://www.enterprisedb.com/docs/warehousepg/latest/ref_guide/utility_guide/reference/gpactivatestandby/)
- [gpaddmirrors](https://www.enterprisedb.com/docs/warehousepg/latest/ref_guide/utility_guide/reference/gpaddmirrors/)
- [gpcheckperf](https://www.enterprisedb.com/docs/warehousepg/latest/ref_guide/utility_guide/reference/gpcheckperf/)
- [gpdeletesystem](https://www.enterprisedb.com/docs/warehousepg/latest/ref_guide/utility_guide/reference/gpdeletesystem/)
- [gpinitstandby](https://www.enterprisedb.com/docs/warehousepg/latest/ref_guide/utility_guide/reference/gpinitstandby/)
- [gpinitsystem](https://www.enterprisedb.com/docs/warehousepg/latest/ref_guide/utility_guide/reference/gpinitsystem/)
- [gpssh](https://www.enterprisedb.com/docs/warehousepg/latest/ref_guide/utility_guide/reference/gpssh/)
- [gpssh-exkeys](https://www.enterprisedb.com/docs/warehousepg/latest/ref_guide/utility_guide/reference/gpssh-exkeys/)
- [gpstart](https://www.enterprisedb.com/docs/warehousepg/latest/ref_guide/utility_guide/reference/gpstart/)
- [gpstop](https://www.enterprisedb.com/docs/warehousepg/latest/ref_guide/utility_guide/reference/gpstop/)
- [gpsync](https://www.enterprisedb.com/docs/warehousepg/latest/ref_guide/utility_guide/reference/gpsync/)
