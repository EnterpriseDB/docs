# Installing external components

External components are separately installed tools that extend WarehousePG's capabilities beyond the database itself.

- **[WarehousePG Platform Extension Framework (PXF)](https://www.enterprisedb.com/docs/pxf/latest/)**\
  Provides access to external data stores including Hadoop, object storage, and relational databases.

- **[Python Data Science Module](https://www.enterprisedb.com/docs/warehousepg/latest/install_guide/additional_modules/external_components/install_python_dsmod/)**\
  Provides a collection of data science Python packages for use with PL/Python.

- **[R Data Science Library](https://www.enterprisedb.com/docs/warehousepg/latest/install_guide/additional_modules/external_components/install_r_dslib/)**\
  Provides a collection of data science R packages for use with PL/R.

- **[whpg-backup](https://www.enterprisedb.com/docs/supported-open-source/warehousepg/whpg-backup/)**\
  Provides parallel backup and restore for WarehousePG clusters.

- **[whpg-backup-s3-plugin](https://www.enterprisedb.com/docs/supported-open-source/warehousepg/whpg-backup/s3-plugin/)**\
  Adds Amazon S3 support to whpg-backup.

- **[WarehousePG Enterprise Manager](https://www.enterprisedb.com/docs/supported-open-source/warehousepg/wem/)**\
  Provides a web-based management and monitoring interface for WarehousePG clusters.

- **[FlowServer for WarehousePG](https://www.enterprisedb.com/docs/supported-open-source/warehousepg/flowserver/)**\
  Provides workflow orchestration and scheduling for WarehousePG.

- **[WarehousePG Copy](https://www.enterprisedb.com/docs/supported-open-source/warehousepg/whpg-copy/)**\
  Provides high-performance data loading and unloading for WarehousePG.

- **[WarehousePG Disaster Recovery](https://www.enterprisedb.com/docs/supported-open-source/warehousepg/whpg-dr/)**\
  Provides physical backups, point-in-time recovery, and warm standby for WarehousePG clusters.

* [WarehousePG Platform Extension Framework (PXF)](https://www.enterprisedb.com/docs/warehousepg/latest/install_guide/additional_modules/external_components/install_pxf/): Installation instructions for the WarehousePG Platform Extension Framework (PXF).
* [Data Science Package for Python](https://www.enterprisedb.com/docs/warehousepg/latest/install_guide/additional_modules/external_components/install_python_dsmod/): Install and use EDB's Data Science Package, a curated collection of Python machine learning and data science modules for use with WarehousePG PL/Python.
* [Data Science Package for R](https://www.enterprisedb.com/docs/warehousepg/latest/install_guide/additional_modules/external_components/install_r_dslib/): Install and use EDB's Data Science Package, a curated collection of R data science, statistics, and machine learning packages for use with WarehousePG PL/R.
