# External Components

External components are separately installed tools that extend WarehousePG's capabilities beyond the database itself.

- [WarehousePG Platform Extension Framework (PXF)](https://www.enterprisedb.com/docs/pxf/latest/) - Provides connectors for accessing data stored in external sources such as object storage and Hadoop.
- [whpg-backup](https://www.enterprisedb.com/docs/supported-open-source/warehousepg/whpg-backup/) - Provides parallel backup and restore for WarehousePG clusters.
- [whpg-backup-s3-plugin](https://www.enterprisedb.com/docs/supported-open-source/warehousepg/whpg-backup/s3-plugin/) - Adds Amazon S3 support to whpg-backup.
- [Python Data Science Module](https://www.enterprisedb.com/docs/warehousepg/latest/install_guide/additional_modules/external_components/install_python_dsmod/) - Provides a collection of data science Python packages for use with PL/Python.
- [R Data Science Library](https://www.enterprisedb.com/docs/warehousepg/latest/install_guide/additional_modules/external_components/install_r_dslib/) - Provides a collection of data science R packages for use with PL/R.
- [WarehousePG Enterprise Manager](https://www.enterprisedb.com/docs/supported-open-source/warehousepg/wem/) - Provides a web-based management and monitoring interface for WarehousePG clusters.
- [FlowServer for WarehousePG](https://www.enterprisedb.com/docs/supported-open-source/warehousepg/flowserver/) - Provides workflow orchestration and scheduling for WarehousePG.
- [WarehousePG Copy](https://www.enterprisedb.com/docs/supported-open-source/warehousepg/whpg-copy/) - Provides high-performance data loading and unloading for WarehousePG.
- [WarehousePG Disaster Recovery](https://www.enterprisedb.com/docs/supported-open-source/warehousepg/whpg-dr/) - Provides physical backups, point-in-time recovery, and warm standby for WarehousePG clusters.
