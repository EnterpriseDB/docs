# Additional Supplied Modules

WarehousePG ships with a large set of modules and supports additional separately installed packages. They fall into four categories:

- **[Bundled modules](https://www.enterprisedb.com/docs/supported-open-source/warehousepg/extensions/bundled/)** ship with WarehousePG and don't require a separate package install. See the reference page for the full list and WHPG 6/7.6 compatibility.
- **[Additional extensions](https://www.enterprisedb.com/docs/supported-open-source/warehousepg/extensions/additional/)** are packages that require a separate install on each host before you can enable them. See the reference page for the full list and WHPG 6/7.6 compatibility.
- **[Procedural languages](https://www.enterprisedb.com/docs/warehousepg/latest/ref_guide/modules/procedural_languages/)** extend WarehousePG with additional programming languages for writing functions and stored procedures.
- **[External components](https://www.enterprisedb.com/docs/warehousepg/latest/ref_guide/modules/external_components/)** are separately installed tools that integrate with WarehousePG but aren't database extensions.

* [Procedural Languages](https://www.enterprisedb.com/docs/warehousepg/latest/ref_guide/modules/procedural_languages/): Procedural language extensions for writing functions and stored procedures in WarehousePG.
* [External Components](https://www.enterprisedb.com/docs/warehousepg/latest/ref_guide/modules/external_components/): Separately installed tools and frameworks that integrate with WarehousePG but are not database extensions.
