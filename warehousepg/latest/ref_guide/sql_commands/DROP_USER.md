# DROP USER

Removes a database role.

<a id="section2"></a>

## Synopsis

<div id="sql_command_synopsis"></div>

```
DROP USER [IF EXISTS] <name> [, ...]
```

<a id="section3"></a>

## Description

`DROP USER` is an alias for [DROP ROLE](https://www.enterprisedb.com/docs/warehousepg/latest/ref_guide/sql_commands/DROP_ROLE/).

<a id="section5"></a>

## Compatibility

The `DROP USER` statement is a WarehousePG extension. The SQL standard leaves the definition of users to the implementation.
