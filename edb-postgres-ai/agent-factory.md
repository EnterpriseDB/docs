# Agent Factory

Agent Factory is EDB's set of Postgres extensions and applications for building, running, and governing AI agents directly on your Postgres data, without moving your data to a separate vector database or agent framework. It includes the extensions that implement Search, Context, Runtime, and Governance, as well as the packages that install and manage them.

- **[Search](https://www.enterprisedb.com/docs/edb-postgres-ai/agent-factory/search/)** — Index and search your data with pipelines, connectors, vector extensions, and the knowledge bases they populate.

- **[Context](https://www.enterprisedb.com/docs/edb-postgres-ai/agent-factory/context/)** — Give agents durable memory and a searchable model of your schema.

- **[Runtime](https://www.enterprisedb.com/docs/edb-postgres-ai/agent-factory/runtime/)** — Register and serve models, run agents, and expose tools to external MCP clients.

- **[Governance](https://www.enterprisedb.com/docs/edb-postgres-ai/agent-factory/governance/)** — Confine what an agent's tools can do while it runs, and audit what it did against your Postgres data afterward.

- **[Packages](https://www.enterprisedb.com/docs/edb-postgres-ai/agent-factory/packages/)** — Install, upgrade, and track releases and known issues for each extension and application.

* [Search](https://www.enterprisedb.com/docs/edb-postgres-ai/agent-factory/search/): Index and search your data with Agent Factory's pipelines, connectors, and vector extensions.
* [Context](https://www.enterprisedb.com/docs/edb-postgres-ai/agent-factory/context/): Give agents durable memory and a searchable model of your schema.
* [Runtime](https://www.enterprisedb.com/docs/edb-postgres-ai/agent-factory/runtime/): Serve models and agents, and connect external MCP clients.
* [Governance](https://www.enterprisedb.com/docs/edb-postgres-ai/agent-factory/governance/): Confine what agents can do while they run, and audit what they did, across Agent Factory.
* [Packages](https://www.enterprisedb.com/docs/edb-postgres-ai/agent-factory/packages/): Install and reference each of the packages that make up Agent Factory.
