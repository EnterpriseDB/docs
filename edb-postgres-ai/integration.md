# EDB Postgres AI Integration

The EDB Postgres AI Integration documentation provides information on how to integrate your applications with EDB Postgres AI. This includes information on connectors, connection poolers, and foreign data wrappers that you can use to connect your applications to EDB Postgres AI.

## Connectors

- Java and [JDBC](https://www.enterprisedb.com/docs/jdbc_connector/latest/)
- .NET and [EDB .NET Connector](https://www.enterprisedb.com/docs/net_connector/latest/)
- C and Open Client with the [EDB OCL Connector](https://www.enterprisedb.com/docs/ocl_connector/latest/)
- ODBC with the [EDB ODBC Connector](https://www.enterprisedb.com/docs/odbc_connector/latest/)

## Connection Poolers

- [EDB PgBouncer](https://www.enterprisedb.com/docs/pgbouncer/latest/) for connection pooling
- [pgpool-II](https://www.enterprisedb.com/docs/pgpool/latest/) for connection pooling and load balancing

## Foreign Data Wrappers

- [Hadoop](https://www.enterprisedb.com/docs/hadoop_data_adapter/latest/) for Hadoop integration
- [MongoDB](https://www.enterprisedb.com/docs/mongo_data_adapter/latest/) for MongoDB integration
- [MySQL](https://www.enterprisedb.com/docs/mysql_data_adapter/latest/) for MySQL integration
- [TDS](https://www.enterprisedb.com/docs/tds_data_adapter/latest/) for TDS integration

## Developer Tools

- [postgREST](https://www.enterprisedb.com/docs/supported-open-source/postgrest/) for postgREST integration
