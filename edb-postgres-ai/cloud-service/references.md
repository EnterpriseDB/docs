# Supported configurations

This reference guide provides information on the supported configurations for EDB Postgres AI Cloud Service.

- [Supported cluster types](https://www.enterprisedb.com/docs/edb-postgres-ai/cloud-service/references/supported_cluster_types/): Cloud Service supports three cluster types and faraway replicas.
- [Database version policy](https://www.enterprisedb.com/docs/edb-postgres-ai/cloud-service/references/supported_database_versions/): How Cloud Service supports the major Postgres versions.
- [Supported regions](https://www.enterprisedb.com/docs/edb-postgres-ai/cloud-service/references/supported_regions/): CSP Regions supported by EDB Postgres AI Cloud Service
- [Supported extensions and tools](https://www.enterprisedb.com/docs/edb-postgres-ai/cloud-service/references/supported_extension_tools/): Cloud Service supported postgres extensions and tools available for use with your cluster.
- [EDB PgBouncer](https://www.enterprisedb.com/docs/edb-postgres-ai/cloud-service/references/poolers/): EDB PgBouncer availability on Cloud Service.
- [Foreign data wrappers](https://www.enterprisedb.com/docs/edb-postgres-ai/cloud-service/references/foreign_data_wrappers/): Using foreign data wrappers in EDB Postgres AI Cloud Service
- [Distributed High Availability](https://www.enterprisedb.com/docs/edb-postgres-ai/cloud-service/references/distributed_high_availability/): The PGD defaults and commands for Distributed high availability on EDB Postgres AI Cloud Service.
- [Pricing and billing](https://www.enterprisedb.com/docs/edb-postgres-ai/cloud-service/references/pricing_and_billing/): The costs include database pricing for EDB Postgres AI Cloud Service and the associated costs from other providers. You can also view usage and metering information.
