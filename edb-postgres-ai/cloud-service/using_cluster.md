# Using your cluster

Account owners and contributors can connect, edit, scale, monitor, back up, and restore clusters through the EDB Postgres AI Console.

- [Connecting to your cluster](https://www.enterprisedb.com/docs/edb-postgres-ai/cloud-service/using_cluster/connecting_your_cluster/): Connect to your cluster from your applications, client apps, and EDB's tools.
- [Connect to your cluster from a client app](https://www.enterprisedb.com/docs/edb-postgres-ai/cloud-service/using_cluster/connect_from_a_client/): Connecting to a Cloud Service cluster from several common clients
- [Your Cloud Account](https://www.enterprisedb.com/docs/edb-postgres-ai/cloud-service/using_cluster/your_cloud_account/): Using your own cloud account for tagging and to enable AWS Secrets Manager and your own policies on EDB Postgres AI Cloud Service.
- [Faraway replicas](https://www.enterprisedb.com/docs/edb-postgres-ai/cloud-service/using_cluster/faraway_replicas/): How to create, manage, promote, delete, and restore faraway replicas.
- [Postgres access](https://www.enterprisedb.com/docs/edb-postgres-ai/cloud-service/using_cluster/postgres_access/): Managing access to your Postgres databases
- [Using the Cloud Service CLI](https://www.enterprisedb.com/docs/edb-postgres-ai/cloud-service/using_cluster/cli/): Using the Cloud Service CLI to create and manage clusters.
- [Monitoring and logging](https://www.enterprisedb.com/docs/edb-postgres-ai/cloud-service/using_cluster/monitoring_and_logging/): All the available monitoring and logging solutions on EDB Postgres AI Cloud Service.
- [Fault injection testing](https://www.enterprisedb.com/docs/edb-postgres-ai/cloud-service/using_cluster/fault_injection_testing/): How to test the fault injections for your clusters.
- [Tagging resources](https://www.enterprisedb.com/docs/edb-postgres-ai/cloud-service/using_cluster/tagging/): How to tag a resource in EDB Postgres AI Cloud Service.
- [Managing Postgres extensions](https://www.enterprisedb.com/docs/edb-postgres-ai/cloud-service/using_cluster/managing_postgres_extensions/): How to manage the Postgres extensions on EDB Postgres AI Cloud Service.
- [Oracle SQL compatibility](https://www.enterprisedb.com/docs/edb-postgres-ai/cloud-service/using_cluster/demonstration_oracle_compatibility/): Cloud Service lets you run Oracle SQL queries in the cloud using EDB Postgres Advanced Server. This demonstration shows two Oracle SQL-syntax queries running unmodified on a Cloud Service test cluster, populated with the Chinook sample database.
