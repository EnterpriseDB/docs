# EDB Postgres AI Console

The EDB Postgres® AI Console is a web-based interface that allows you to manage your EDB Postgres AI environment. The console provides a user-friendly interface for managing your estate, including the remote agents and databases that run on your servers.

- [Quickstart](https://www.enterprisedb.com/docs/edb-postgres-ai/cloud-service/console/quickstart/): A speed run through getting onto EDB Postgres AI, creating a Cloud Service database cluster and connecting to it from your local machine.
- [Using the console](https://www.enterprisedb.com/docs/edb-postgres-ai/cloud-service/console/using/): Using the EDB Postgres AI console from creating clusters and managing users to connecting cloud services and enabling encryption.
- [Estate and Agent](https://www.enterprisedb.com/docs/edb-postgres-ai/cloud-service/console/estate/): How to monitor and integrate EDB Postgres AI databases and more with EDB Postgres AI Console's single pane of glass.
