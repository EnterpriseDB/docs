# Deploying with Azure

To use Azure as your cloud account:

- Sign in for the first time with your EDB account, and then either use the EDB Postgres AI Console as your identity provider or [set up your own provider](https://www.enterprisedb.com/docs/edb-postgres-ai/cloud-service/console/using/organizations/identity_provider/) afterward.
- Check the readiness of [your Azure subscription](https://www.enterprisedb.com/docs/edb-postgres-ai/cloud-service/getting_started/your_cloud_account/preparing_cloud_account/preparing_azure/) before deploying.
- [Connect your Azure cloud](https://www.enterprisedb.com/docs/edb-postgres-ai/cloud-service/getting_started/your_cloud_account/connecting_to_your_cloud/connecting_azure/) to Cloud Service.
- [Connect to Cloud Service](https://www.enterprisedb.com/docs/edb-postgres-ai/cloud-service/using_cluster/connecting_your_cluster/connecting_from_azure/) from your application's virtual network in Azure.
- [Review the supported Azure regions](https://www.enterprisedb.com/docs/edb-postgres-ai/cloud-service/references/supported_regions/#azure-regions) where you can create clusters for the Azure account, enabling you to locate your cloud resources close to your customers.
- [View metrics and logs](https://www.enterprisedb.com/docs/edb-postgres-ai/cloud-service/using_cluster/monitoring_and_logging/monitoring_from_azure/) sent from Cloud Service in your Azure account.
- [Configure Azure](https://www.enterprisedb.com/docs/edb-postgres-ai/cloud-service/using_cluster/monitoring_and_logging/alerts/) to trigger real-time alerts based on the metrics in Cloud Service.
