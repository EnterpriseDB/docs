# Deploying with AWS

To use AWS as your cloud account:

- Sign in for the first time with your EDB account, and then either use the EDB Postgres AI Console as your identity provider or [set up your own provider](https://www.enterprisedb.com/docs/edb-postgres-ai/cloud-service/console/using/organizations/identity_provider/) afterward.
- [Check the readiness of your AWS account](https://www.enterprisedb.com/docs/edb-postgres-ai/cloud-service/getting_started/your_cloud_account/preparing_cloud_account/preparing_aws/) before deploying.
- [Connect your AWS cloud](https://www.enterprisedb.com/docs/edb-postgres-ai/cloud-service/getting_started/your_cloud_account/connecting_to_your_cloud/connecting_aws/) to Cloud Service.
- [Connect to Cloud Service](https://www.enterprisedb.com/docs/edb-postgres-ai/cloud-service/using_cluster/connecting_your_cluster/02_connecting_from_aws/) using AWS VPC endpoint service.
- [Review the supported AWS regions](https://www.enterprisedb.com/docs/edb-postgres-ai/cloud-service/references/supported_regions/#aws-regions) where you can create clusters for the AWS account, enabling you to locate your cloud resources close to your customers.
- [View metrics and logs](https://www.enterprisedb.com/docs/edb-postgres-ai/cloud-service/using_cluster/monitoring_and_logging/monitoring_from_aws/) sent from Cloud Service with AWS CloudWatch.
