# Deploying using your own cloud account

You can choose your own cloud account to manage databases on EDB Postgres AI Cloud Service:

- [AWS](https://www.enterprisedb.com/docs/edb-postgres-ai/cloud-service/getting_started/your_cloud_account/deploying_using_your_cloud_account/deploy_aws/)
- [Azure](https://www.enterprisedb.com/docs/edb-postgres-ai/cloud-service/getting_started/your_cloud_account/deploying_using_your_cloud_account/deploy_azure/)
- [Google Cloud](https://www.enterprisedb.com/docs/edb-postgres-ai/cloud-service/getting_started/your_cloud_account/deploying_using_your_cloud_account/deploy_gcp/)

* [Deploying with AWS](https://www.enterprisedb.com/docs/edb-postgres-ai/cloud-service/getting_started/your_cloud_account/deploying_using_your_cloud_account/deploy_aws/): Choose AWS to manage databases on EDB Postgres AI Cloud Service.
* [Deploying with Azure](https://www.enterprisedb.com/docs/edb-postgres-ai/cloud-service/getting_started/your_cloud_account/deploying_using_your_cloud_account/deploy_azure/): Choose Azure to manage databases on EDB Postgres AI Cloud Service.
* [Deploying with Google Cloud](https://www.enterprisedb.com/docs/edb-postgres-ai/cloud-service/getting_started/your_cloud_account/deploying_using_your_cloud_account/deploy_gcp/): Choose Google Cloud to manage databases on EDB Postgres AI Cloud Service.
