# Cloud Service June 2026 release notes

EDB Postgres® AI Cloud Service's June 2026 release includes these enhancements and bug fixes:

| Type        | Description                                                          |
| ----------- | -------------------------------------------------------------------- |
| Enhancement | BigAnimal CLI v3.11.0 is now available.                              |
| Enhancement | Added name filter in the `pgd show` command.                         |
| Bug fix     | BigAnimal PGD cluster now requires 32Gi minimum volume size.         |
| Bug fix     | Fixed cloud provider update hiding error.                            |
| Bug fix     | Fixed security issues.                                               |
| Bug fix     | Fixed config examples.                                               |
| Bug fix     | Improved credential show message.                                    |
| Bug fix     | Added warning before deleting the credential of the current context. |
| Deprecation | Removed Analytics cluster commands.                                  |
