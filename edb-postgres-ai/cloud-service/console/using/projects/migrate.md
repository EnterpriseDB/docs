# Migrate

The Migrate menu option allows you to view the status of data migration for an EDB Postgres AI project.

Currently, the following migration options are available:

- **Migrations**: Shows the status of data migrations.

* [Migrations](https://www.enterprisedb.com/docs/edb-postgres-ai/cloud-service/console/using/projects/migrate/migrations/): Displaying the status of data migrations for an EDB Postgres AI project
