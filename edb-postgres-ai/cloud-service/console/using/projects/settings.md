# Configuring Project Settings

The Project Settings page allows you to configure the settings for an EDB Postgres AI project. The settings are divided into the following sections:

- [Integrations](https://www.enterprisedb.com/docs/edb-postgres-ai/cloud-service/console/using/projects/settings/integrations/): How to manage integrations in an EDB Postgres AI project
- [Profile](https://www.enterprisedb.com/docs/edb-postgres-ai/cloud-service/console/using/projects/settings/profile/): How to manage your project's profile in EDB Postgres AI
- [Security and TDE keys](https://www.enterprisedb.com/docs/edb-postgres-ai/cloud-service/console/using/projects/settings/security/): Add and delete TDE keys for your project
