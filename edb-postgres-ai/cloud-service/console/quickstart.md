# Quickstart

This quickstart guide takes you through the steps to get started with the EDB Postgres AI Console and Cloud Service. You'll learn how to create an account on EDB Postgres AI, then use that account to create a single node database cluster on the Cloud Service. Finally, you'll learn how to connect to your new database cluster.

It starts with you [creating an account and signing in](https://www.enterprisedb.com/docs/edb-postgres-ai/cloud-service/console/quickstart/create_account_and_sign_in/).

- [Signing in](https://www.enterprisedb.com/docs/edb-postgres-ai/cloud-service/console/quickstart/create_account_and_sign_in/): The first step to getting started with EDB Postgres AI is to create an account and sign in.
- [Viewing the Project and Clusters](https://www.enterprisedb.com/docs/edb-postgres-ai/cloud-service/console/quickstart/the_project_and_clusters_views/): How to quickly navigate the project and clusters views in the EDB Postgres AI Console.
- [Creating a database cluster](https://www.enterprisedb.com/docs/edb-postgres-ai/cloud-service/console/quickstart/creating_a_database_cluster/): Create a single node Cloud Service database cluster on EDB Postgres AI.
- [Connecting with psql](https://www.enterprisedb.com/docs/edb-postgres-ai/cloud-service/console/quickstart/connecting_to_the_database_with_psql/): How to get the credentials and connect to the database cluster you just created in the EDB Postgres AI Console with psql.
- [Connecting with pgAdmin](https://www.enterprisedb.com/docs/edb-postgres-ai/cloud-service/console/quickstart/connecting_to_the_database_with_pgadmin/): How to get the credentials and connect to the database cluster you just created in the EDB Postgres AI Console.
- [Connecting with DBeaver](https://www.enterprisedb.com/docs/edb-postgres-ai/cloud-service/console/quickstart/connecting_to_the_database_with_dbeaver/): How to get the credentials and connect to the database cluster you just created in the EDB Postgres AI Console using DBeaver.
- [Exploring](https://www.enterprisedb.com/docs/edb-postgres-ai/cloud-service/console/quickstart/exploring_the_database/): Exploring the database in EDB Postgres AI with psql
