# Postgres access

You control access to your Postgres database using database authentication implemented by creating databases with specific roles and privileges. Database authentication differs from portal authentication, which controls access to the Console.

For information on portal authentication, see:

[Setting up your identity provider](https://www.enterprisedb.com/docs/edb-postgres-ai/cloud-service/console/using/organizations/identity_provider/)

- [Database authentication](https://www.enterprisedb.com/docs/edb-postgres-ai/cloud-service/using_cluster/postgres_access/database_authentication/): Setting up the database authentication for the Postgres clusters.
- [Admin roles](https://www.enterprisedb.com/docs/edb-postgres-ai/cloud-service/using_cluster/postgres_access/admin_roles/): Available admin roles in EDB Postgres AI Cloud Service to perform the administrative tasks.
- [pg\_ba\_admin role](https://www.enterprisedb.com/docs/edb-postgres-ai/cloud-service/using_cluster/postgres_access/pg_ba_admin/): pg\_ba\_admin role and the privileges available with this role.
