# Customizing compliance rules and policies

Your cloud provider has rules and policies to help you to monitor, identify, and remediate noncompliant resources. You can customize the default policies and rules to match Cloud Service's resource configurations.

- [Customizing AWS Config rules](https://www.enterprisedb.com/docs/edb-postgres-ai/cloud-service/using_cluster/your_cloud_account/customizing_compliance/aws_config_rules/): Customize default AWS configuration settings to match Cloud Service's resource configurations
- [Customizing Azure policy definitions](https://www.enterprisedb.com/docs/edb-postgres-ai/cloud-service/using_cluster/your_cloud_account/customizing_compliance/azure_policy_definitions/): Customize default Azure policies to match Cloud Service's resource configurations
- [Customizing Google Cloud compliance policies](https://www.enterprisedb.com/docs/edb-postgres-ai/cloud-service/using_cluster/your_cloud_account/customizing_compliance/gcp_policy_definitions/): Customize Google Cloud compliance configuration settings to match Cloud Service's resource configurations
