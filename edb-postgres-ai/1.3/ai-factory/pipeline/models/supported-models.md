# Pipelines supported models

This section provides details of the supported models in EDB Postgres AI - AI Accelerator Pipelines and their capabilities.

- [Support matrix](https://www.enterprisedb.com/docs/edb-postgres-ai/1.3/ai-factory/pipeline/models/supported-models/support_matrix/) for embedded models.
- [T5](https://www.enterprisedb.com/docs/edb-postgres-ai/1.3/ai-factory/pipeline/models/supported-models/t5/).
- [Embeddings](https://www.enterprisedb.com/docs/edb-postgres-ai/1.3/ai-factory/pipeline/models/supported-models/embeddings/), including `openai-embeddings` and `nim-embeddings`.
- [Completions](https://www.enterprisedb.com/docs/edb-postgres-ai/1.3/ai-factory/pipeline/models/supported-models/completions/), including `openai-completions` and `nim-completions`.
- [Gemini](https://www.enterprisedb.com/docs/edb-postgres-ai/1.3/ai-factory/pipeline/models/supported-models/gemini/)
- [BERT](https://www.enterprisedb.com/docs/edb-postgres-ai/1.3/ai-factory/pipeline/models/supported-models/bert/).
- [CLIP](https://www.enterprisedb.com/docs/edb-postgres-ai/1.3/ai-factory/pipeline/models/supported-models/clip/).
- [NIM\_CLIP](https://www.enterprisedb.com/docs/edb-postgres-ai/1.3/ai-factory/pipeline/models/supported-models/nim_clip/).
- [Llama](https://www.enterprisedb.com/docs/edb-postgres-ai/1.3/ai-factory/pipeline/models/supported-models/llama/).
- [NIM\_RERANKING](https://www.enterprisedb.com/docs/edb-postgres-ai/1.3/ai-factory/pipeline/models/supported-models/nim_reranking/).
- [NIM\_PADDLE\_OCR](https://www.enterprisedb.com/docs/edb-postgres-ai/1.3/ai-factory/pipeline/models/supported-models/nim_paddle_ocr/).

* [Support matrix](https://www.enterprisedb.com/docs/edb-postgres-ai/1.3/ai-factory/pipeline/models/supported-models/support_matrix/): Support matrix for the AI Factory models.
* [T5](https://www.enterprisedb.com/docs/edb-postgres-ai/1.3/ai-factory/pipeline/models/supported-models/t5/): T5 is a text-to-text transformer model that converts input text to output text.
* [BERT](https://www.enterprisedb.com/docs/edb-postgres-ai/1.3/ai-factory/pipeline/models/supported-models/bert/): BERT is a transformer-based model used for natural language processing tasks such as text classification, text generation, and text completion.
* [CLIP](https://www.enterprisedb.com/docs/edb-postgres-ai/1.3/ai-factory/pipeline/models/supported-models/clip/): CLIP (Contrastive Language-Image Pre-training) is a model that learns visual concepts from natural language supervision.
* [Llama](https://www.enterprisedb.com/docs/edb-postgres-ai/1.3/ai-factory/pipeline/models/supported-models/llama/): Llama is a series of large language models developed by Meta.
* [Gemini](https://www.enterprisedb.com/docs/edb-postgres-ai/1.3/ai-factory/pipeline/models/supported-models/gemini/): Google's family of generative models.
* [Completions](https://www.enterprisedb.com/docs/edb-postgres-ai/1.3/ai-factory/pipeline/models/supported-models/completions/): Completions is a text completion model that enables use of any OpenAI API-compatible text-generation model.
* [Embeddings](https://www.enterprisedb.com/docs/edb-postgres-ai/1.3/ai-factory/pipeline/models/supported-models/embeddings/): Embeddings is a text-embedding model that enables use of any OpenAI API-compatible text-embedding model.
* [NIM\_CLIP](https://www.enterprisedb.com/docs/edb-postgres-ai/1.3/ai-factory/pipeline/models/supported-models/nim_clip/): NIM\_CLIP (Contrastive Language-Image Pre-training) is a model that learns visual concepts from natural language supervision on NVIDIA NIM.
* [NIM OCR](https://www.enterprisedb.com/docs/edb-postgres-ai/1.3/ai-factory/pipeline/models/supported-models/nim_paddle_ocr/): NIM OCR (Optical Character Recognition) is a model that extracts text from images on NVIDIA NIM.
* [Reranking](https://www.enterprisedb.com/docs/edb-postgres-ai/1.3/ai-factory/pipeline/models/supported-models/nim_reranking/): Reranking is a method in text search that sorts results by relevance to make them more accurate.
