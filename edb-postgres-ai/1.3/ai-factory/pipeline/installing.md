# Installing AI Accelerator Pipelines

Pipelines is delivered as a set of extensions. Depending on how you're deploying Pipelines, these extensions can be installed by your deployment platform provider or already installed. Contact your deployment platform provider for details. If you deploy your own Postgres server, you need to install the extentions manually.

- [Manually installing pipelines packages](https://www.enterprisedb.com/docs/edb-postgres-ai/1.3/ai-factory/pipeline/installing/packages/)

Once the packages are installed, you can [complete the installation](https://www.enterprisedb.com/docs/edb-postgres-ai/1.3/ai-factory/pipeline/installing/complete/) by activating the extensions in Postgres.

If you have an existing installation and want to upgrade to a new version, see [upgrading Pipelines](https://www.enterprisedb.com/docs/edb-postgres-ai/1.3/ai-factory/pipeline/installing/upgrading/).

- [Installing packages](https://www.enterprisedb.com/docs/edb-postgres-ai/1.3/ai-factory/pipeline/installing/packages/): How to install the AI Database (aidb), PGFS, and PGvector extensions from packages.
- [Completing the installation](https://www.enterprisedb.com/docs/edb-postgres-ai/1.3/ai-factory/pipeline/installing/complete/): Completing and verifying the installation of the AI Database and Postgres File System extensions.
- [Upgrading](https://www.enterprisedb.com/docs/edb-postgres-ai/1.3/ai-factory/pipeline/installing/upgrading/): How to upgrade AI Accelerator Pipelines.
- [Permissions Setup](https://www.enterprisedb.com/docs/edb-postgres-ai/1.3/ai-factory/pipeline/installing/permissions/): Permissions Setup in AIDB
