# AI Accelerator Pipelines knowledge bases

Knowledge bases can be used for semantic search or for retrieval augmented generation (RAG).

A configured knowledge base can compute embeddings (vectors) for your input data. Once this is done, the knowledge base offers a number of interfaces to return data based on a query.
