# Assistant Runs

Assistant runs are individual executions of an [Assistant](https://www.enterprisedb.com/docs/edb-postgres-ai/1.3/hybrid-manager/ai-factory/gen-ai/reference/assistants/).

Once you have created an Assistant, you can run it by sending messages. You can then view details for your runs, including sent and received messages and run configurations.
