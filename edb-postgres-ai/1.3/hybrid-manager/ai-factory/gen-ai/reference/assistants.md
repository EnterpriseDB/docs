# What are Assistants?

AI applications don't always need to be complex to get the job done. Sometimes, all you need is a quick way to give an LLM secure access to your data. If you'd like to build a simple chat app that has access to your data sources, create an Assistant.

Assistants are a special type of Gen AI Builder chatbot Agent Structure that can be created easily in less than a minute, without writing or deploying any code. They offer much of the same functionality provided by Agent Structures, through a simple configurable interface.

Assistants can be configured to use Gen AI Builder resources such as [Knowledge Bases](https://www.enterprisedb.com/docs/edb-postgres-ai/1.3/hybrid-manager/ai-factory/gen-ai/reference/knowledge-bases/), [Rulesets](https://www.enterprisedb.com/docs/edb-postgres-ai/1.3/hybrid-manager/ai-factory/gen-ai/reference/rules/), and [Tools](https://www.enterprisedb.com/docs/edb-postgres-ai/1.3/hybrid-manager/ai-factory/gen-ai/reference/tools/). Once your Assistant is created, you can immediately begin chatting with it by sending a message on the following screen.

- [Getting Started with Assistants](https://www.enterprisedb.com/docs/edb-postgres-ai/1.3/hybrid-manager/ai-factory/gen-ai/reference/assistants/getting-started-with-assistants/): How to create an Assistant
- [Assistant Runs](https://www.enterprisedb.com/docs/edb-postgres-ai/1.3/hybrid-manager/ai-factory/gen-ai/reference/assistants/assistant-runs/): Assistant runs are individual executions of an Assistant.
