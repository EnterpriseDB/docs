# Using the HM console to perform data migration

To perform a data migration, you can leverage the data migration features in the Hybrid Manager (HM) console. This reference material explains the options available under the **Migrate** section of the left navigation in a project.

- [Sources](https://www.enterprisedb.com/docs/edb-postgres-ai/1.3/hybrid-manager/using_hybrid_manager/migration/migrate/sources/): view and manage migration database sources that you added with the DMS agent in reader mode.
- [Destinations](https://www.enterprisedb.com/docs/edb-postgres-ai/1.3/hybrid-manager/using_hybrid_manager/migration/migrate/destinations/): view and manage migration database \[destinations] that you added with the DMS agent in writer mode.
- [Migrations](https://www.enterprisedb.com/docs/edb-postgres-ai/1.3/hybrid-manager/using_hybrid_manager/migration/migrate/migrations/): view existing data migrations or start new data migrations from existing sources to existing destinations.
- [Credentials](https://www.enterprisedb.com/docs/edb-postgres-ai/1.3/hybrid-manager/using_hybrid_manager/migration/migrate/credentials/): Obtain project-scoped credentials required to connect sources and destinations with the DMS agent.

* [Sources](https://www.enterprisedb.com/docs/edb-postgres-ai/1.3/hybrid-manager/using_hybrid_manager/migration/migrate/sources/): Learn about creating sources to prepare for database migrations to Hybrid Manager.
* [Destinations](https://www.enterprisedb.com/docs/edb-postgres-ai/1.3/hybrid-manager/using_hybrid_manager/migration/migrate/destinations/): Learn about creating destinations to prepare for database migrations to Hybrid Manager.
* [Migrations](https://www.enterprisedb.com/docs/edb-postgres-ai/1.3/hybrid-manager/using_hybrid_manager/migration/migrate/migrations/): Learn about viewing migration details when performing database migrations in Hybrid Manager.
* [Credentials](https://www.enterprisedb.com/docs/edb-postgres-ai/1.3/hybrid-manager/using_hybrid_manager/migration/migrate/credentials/): Learn about creating credentials to prepare for database migrations to Hybrid Manager.
