# Installing Hybrid Manager

## Installing Hybrid Manager

This section contains everything you need to install and configure Hybrid Manager (HM).

- **[Installation guide](https://www.enterprisedb.com/docs/edb-postgres-ai/latest/hybrid-manager/install/install_guide/)** — The six-phase guide covering architecture planning through post-installation configuration. Start here for new installations.

- **[Container registry and artifact reference](https://www.enterprisedb.com/docs/edb-postgres-ai/latest/hybrid-manager/install/registry_artifact_reference/)** — Reference for the artifacts HM ships, the canonical image list, required registry layout, signing status, and network access requirements.

- **[Configuration](https://www.enterprisedb.com/docs/edb-postgres-ai/latest/hybrid-manager/install/configuration/)** — Detailed SOPs for advanced configuration topics: TLS, IdPs, KMS for TDE, multi-DC, image sync, and more.

- **[Troubleshooting](https://www.enterprisedb.com/docs/edb-postgres-ai/latest/hybrid-manager/install/troubleshooting/)** — Guidance for diagnosing and resolving installation issues.

Use it for security, procurement, and onboarding review before installation.
* [Configuring SOPs](https://www.enterprisedb.com/docs/edb-postgres-ai/latest/hybrid-manager/install/configuration/): Configure necessary and optional features for your Hybrid manager installation.
* [Troubleshooting](https://www.enterprisedb.com/docs/edb-postgres-ai/latest/hybrid-manager/install/troubleshooting/): Use preflight and postflight checks to help you troubleshoot and monitor your HM installation.
