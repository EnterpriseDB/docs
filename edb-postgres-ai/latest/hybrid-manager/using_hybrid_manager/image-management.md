# Asset management

The Asset Management section of the Hybrid Manager (HM) console provides tools for managing the assets that are available for use in your clusters. This includes managing container images and AI models, as well as repositories that contain these assets.

## Managing HM Postgres and model assets

- [Asset library](https://www.enterprisedb.com/docs/edb-postgres-ai/latest/hybrid-manager/using_hybrid_manager/image-management/asset-library/)
  The main page for managing assets in the HM console, where you can view and manage container images and knowledge bases.
- [Container images](https://www.enterprisedb.com/docs/edb-postgres-ai/latest/hybrid-manager/using_hybrid_manager/image-management/container-images/)
  You can explore and manage container images in the asset library by searching, filtering, and viewing image details.
- [Custom operand images](https://www.enterprisedb.com/docs/edb-postgres-ai/latest/hybrid-manager/using_hybrid_manager/image-management/custom-operand-images/)
  Build and register a custom operand image that includes additional PostgreSQL extensions not available in the standard EDB images.
- [Manage repositories](https://www.enterprisedb.com/docs/edb-postgres-ai/latest/hybrid-manager/using_hybrid_manager/image-management/manage-repositories/)
  Control the visibility of repositories and images in the asset library by managing repository registrations and rules.
- [Knowledge bases](https://www.enterprisedb.com/docs/edb-postgres-ai/latest/hybrid-manager/using_hybrid_manager/image-management/knowledge-bases/)
  Manage AI models in the asset library, including creating and managing knowledge bases that contain AI models for use in clusters.

* [Asset library](https://www.enterprisedb.com/docs/edb-postgres-ai/latest/hybrid-manager/using_hybrid_manager/image-management/asset-library/): Learn how to use the asset library to manage assets, container images, and models for Hybrid Manager clusters.
* [Container images](https://www.enterprisedb.com/docs/edb-postgres-ai/latest/hybrid-manager/using_hybrid_manager/image-management/container-images/): Learn how to use container images for Hybrid Manager clusters.
* [Custom operand images](https://www.enterprisedb.com/docs/edb-postgres-ai/latest/hybrid-manager/using_hybrid_manager/image-management/custom-operand-images/): Build and register a custom Hybrid Manager operand image that includes additional PostgreSQL extensions.
* [Manage repositories](https://www.enterprisedb.com/docs/edb-postgres-ai/latest/hybrid-manager/using_hybrid_manager/image-management/manage-repositories/): Learn about managing repositories in the asset library for Hybrid Manager clusters.
* [Knowledge bases](https://www.enterprisedb.com/docs/edb-postgres-ai/latest/hybrid-manager/using_hybrid_manager/image-management/knowledge-bases/): Learn about using knowledge bases to manage collections of AI models for Hybrid Manager clusters.
