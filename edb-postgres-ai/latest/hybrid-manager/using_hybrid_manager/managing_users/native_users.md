# Managing native users for testing

For testing or demo environments, you can use native users to simplify operations.
To manage the lifecycle of native users you can:

- [Change the password of a native user](https://www.enterprisedb.com/docs/edb-postgres-ai/latest/hybrid-manager/using_hybrid_manager/managing_users/native_users/change_pw_native_user/).
- [Create additional native users](https://www.enterprisedb.com/docs/edb-postgres-ai/latest/hybrid-manager/using_hybrid_manager/managing_users/native_users/create_native_user/).

For production deployments, we strongly recommend that you [configure an external IdP](https://www.enterprisedb.com/docs/edb-postgres-ai/latest/hybrid-manager/using_hybrid_manager/idp_management/config_idp_hm/).
After configuring an IdP, you can:

- [Disable native user login](https://www.enterprisedb.com/docs/edb-postgres-ai/latest/hybrid-manager/using_hybrid_manager/managing_users/native_users/disable_native_user/).

* [Changing password](https://www.enterprisedb.com/docs/edb-postgres-ai/latest/hybrid-manager/using_hybrid_manager/managing_users/native_users/change_pw_native_user/): Change the password of native users.
* [Creating native users](https://www.enterprisedb.com/docs/edb-postgres-ai/latest/hybrid-manager/using_hybrid_manager/managing_users/native_users/create_native_user/): Create additional native users.
* [Disabling native users](https://www.enterprisedb.com/docs/edb-postgres-ai/latest/hybrid-manager/using_hybrid_manager/managing_users/native_users/disable_native_user/): After configuring an external IdP, disable native user login.
