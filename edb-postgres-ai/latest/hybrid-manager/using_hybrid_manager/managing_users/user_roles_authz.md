# User roles and authorization

You can assign several user roles to Hybrid Manager (HM) users. See:

- [User role permissions by use case](https://www.enterprisedb.com/docs/edb-postgres-ai/latest/hybrid-manager/using_hybrid_manager/managing_users/user_roles_authz/authz/)
- [User role descriptions](https://www.enterprisedb.com/docs/edb-postgres-ai/latest/hybrid-manager/using_hybrid_manager/managing_users/user_roles_authz/roles/)
- [Role mapping](https://www.enterprisedb.com/docs/edb-postgres-ai/latest/hybrid-manager/using_hybrid_manager/managing_users/user_roles_authz/role_mapping/)

* [User roles](https://www.enterprisedb.com/docs/edb-postgres-ai/latest/hybrid-manager/using_hybrid_manager/managing_users/user_roles_authz/roles/): Descriptions of the user roles supported by Hybrid Manager.
* [User role permissions](https://www.enterprisedb.com/docs/edb-postgres-ai/latest/hybrid-manager/using_hybrid_manager/managing_users/user_roles_authz/authz/): See what the predefined Hybrid Manager user roles are authorized to access.
* [Role mapping](https://www.enterprisedb.com/docs/edb-postgres-ai/latest/hybrid-manager/using_hybrid_manager/managing_users/user_roles_authz/role_mapping/): Configure rules to automatically assign roles to users based on their identity provider groups.
