# Using a key store

You can use the key store in an external key management system to manage the data encryption key. The tested and supported key stores are:

- [Amazon AWS Key Management Service (KMS)](https://www.enterprisedb.com/docs/edb-postgres-ai/platforms-and-tools/security/tde/secure_key/key_store/aws/)
- [Microsoft Azure Key Vault](https://www.enterprisedb.com/docs/edb-postgres-ai/platforms-and-tools/security/tde/secure_key/key_store/azure/)
- [Entrust KeyControl](https://www.enterprisedb.com/docs/edb-postgres-ai/platforms-and-tools/security/tde/secure_key/key_store/entrust/)
- [Fortanix Data Security Manager](https://www.enterprisedb.com/docs/edb-postgres-ai/platforms-and-tools/security/tde/secure_key/key_store/fortanix/)
- [Google Cloud - Cloud Key Management Service](https://www.enterprisedb.com/docs/edb-postgres-ai/platforms-and-tools/security/tde/secure_key/key_store/google_cloud/)
- [HashiCorp Vault (KMIP Secrets Engine and Transit Secrets Engine)](https://www.enterprisedb.com/docs/edb-postgres-ai/platforms-and-tools/security/tde/secure_key/key_store/hashicorp/)
- [Thales CipherTrust Manager](https://www.enterprisedb.com/docs/edb-postgres-ai/platforms-and-tools/security/tde/secure_key/key_store/thales/)

* [Using AWS KMS](https://www.enterprisedb.com/docs/edb-postgres-ai/platforms-and-tools/security/tde/secure_key/key_store/aws/): Learn how to secure your encryption key with an AWS KMS key.
* [Using Azure Key Vault](https://www.enterprisedb.com/docs/edb-postgres-ai/platforms-and-tools/security/tde/secure_key/key_store/azure/): Learn how to secure your encryption key with an Azure Key Vault key.
* [Using Entrust KeyControl](https://www.enterprisedb.com/docs/edb-postgres-ai/platforms-and-tools/security/tde/secure_key/key_store/entrust/): Learn how to secure your encryption key with an Entrust KeyControl key.
* [Using Fortanix DSM](https://www.enterprisedb.com/docs/edb-postgres-ai/platforms-and-tools/security/tde/secure_key/key_store/fortanix/): Learn how to secure your encryption key with a Fortanix Data Security Manager key.
* [Using Google Cloud KMS](https://www.enterprisedb.com/docs/edb-postgres-ai/platforms-and-tools/security/tde/secure_key/key_store/google_cloud/): Learn how to secure your encryption key with a Google Cloud KMS key.
* [Using HashiCorp Vault](https://www.enterprisedb.com/docs/edb-postgres-ai/platforms-and-tools/security/tde/secure_key/key_store/hashicorp/): Learn how to secure your encryption key with a HashiCorp Vault key.
* [Using Thales CipherTrust](https://www.enterprisedb.com/docs/edb-postgres-ai/platforms-and-tools/security/tde/secure_key/key_store/thales/): Learn how to secure your encryption key with a Thales CipherTrust Manager key.
