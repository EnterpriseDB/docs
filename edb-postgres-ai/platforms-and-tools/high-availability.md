# High Availability

- [Failover Manager](https://www.enterprisedb.com/docs/efm/latest/): Failover Manager documentation and release notes. PostgreSQL replication and failover manager for achieving high availability.
- [EDB Postgres Distributed (PGD)](https://www.enterprisedb.com/docs/pgd/latest/): EDB Postgres Distributed (PGD) provides multi-master replication and data distribution with advanced conflict management, data-loss protection, and throughput up to 5X faster than native logical replication.
- [EDB Slony Guide](https://www.enterprisedb.com/docs/slony/latest/): EDB Slony documentation and release notes.
- [Patroni](https://www.enterprisedb.com/docs/supported-open-source/patroni/): Introduction to Patroni, a template to create your own high-availability solution
- [pglogical 2](https://www.enterprisedb.com/docs/supported-open-source/pglogical2/): The pglogical 2 extension provides logical streaming replication for PostgreSQL,
- [Replication Manager (repmgr)](https://www.enterprisedb.com/docs/supported-open-source/repmgr/): Replication Manager (repmgr) is among the most popular open-source tools for managing replication and failover of PostgreSQL clusters. It relies on PostgreSQL’s streaming replication and hot standby capabilities allowing DBAs to simplify the process of setting up and managing clusters having high availability as well as read scalability requirements. repmgr is distributed under GNU GPL 3 and maintained by EDB.
