# Settings

You can configure project-specific settings like notifications, security, and alerts. Use the **Settings** menu to access these settings.

- Select **Profile** to change your project's name at any time. Project names must be unique in a Hybrid Manager (HM) instance.

- Select [**Notifications**](https://www.enterprisedb.com/docs/edb-postgres-ai/1.4/hybrid-manager/using_hybrid_manager/projects/settings/notifications/) to configure how the project’s notifications are sent.

- Select **Security** to add externally managed keys for transparent data encryption (TDE) to a project. You can use these keys later during cluster creation to add data encryption. See [Enabling KMS for TDE](https://www.enterprisedb.com/docs/edb-postgres-ai/1.4/hybrid-manager/install/configuration/kms_for_tde/) for KMS-specific instructions.

- Select [**Alerts**](https://www.enterprisedb.com/docs/edb-postgres-ai/1.4/hybrid-manager/using_hybrid_manager/projects/settings/alerts/) to see the alert settings of the project and control how and when alerts are sent.

* [Notifications](https://www.enterprisedb.com/docs/edb-postgres-ai/1.4/hybrid-manager/using_hybrid_manager/projects/settings/notifications/): Learn how to customize the types of notifications and channels, such as email, webhook, and pager duty, with Hybrid Manager.
* [Alerting](https://www.enterprisedb.com/docs/edb-postgres-ai/1.4/hybrid-manager/using_hybrid_manager/projects/settings/alerts/): Learn about alerts for proactive notification about critical events with Hybrid Manager.
