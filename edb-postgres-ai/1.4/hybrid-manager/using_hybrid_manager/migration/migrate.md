# Using the HM Console to perform data migration

To perform a data migration, you can leverage the data migration features that are provided by the HM Console. This section provides reference material to explain the options available under the **Migrate** section of the left navigation in a project.

- [Applications](https://www.enterprisedb.com/docs/edb-postgres-ai/1.4/hybrid-manager/using_hybrid_manager/migration/application_assessment/): create application records and assess the SQL compatibility of the applications that use your databases as part of an Oracle migration.
- [Databases](https://www.enterprisedb.com/docs/edb-postgres-ai/1.4/hybrid-manager/using_hybrid_manager/migration/migrate/databases/): view the migration assessment and status of the databases you registered for this project, and drill into a database's schemas, assessment results, and migration activity.
- [Sources](https://www.enterprisedb.com/docs/edb-postgres-ai/1.4/hybrid-manager/using_hybrid_manager/migration/migrate/sources/): view and manage migration database sources that you have added with the DMS Agent in reader mode.
- [Destinations](https://www.enterprisedb.com/docs/edb-postgres-ai/1.4/hybrid-manager/using_hybrid_manager/migration/migrate/destinations/): view and manage migration database \[destinations] that you have added with the DMS Agent in writer mode.
- [Migrations](https://www.enterprisedb.com/docs/edb-postgres-ai/1.4/hybrid-manager/using_hybrid_manager/migration/migrate/migrations/): view existing data migrations or start new data migrations from existing sources to existing destinations.
- [Credentials](https://www.enterprisedb.com/docs/edb-postgres-ai/1.4/hybrid-manager/using_hybrid_manager/migration/migrate/credentials/): Obtain project-scoped credentials required to connect sources and destinations with the DMS Agent.

* [Databases](https://www.enterprisedb.com/docs/edb-postgres-ai/1.4/hybrid-manager/using_hybrid_manager/migration/migrate/databases/): View the migration assessment and status of databases registered for migration in this project in Hybrid Manager.
* [Sources](https://www.enterprisedb.com/docs/edb-postgres-ai/1.4/hybrid-manager/using_hybrid_manager/migration/migrate/sources/): Learn about creating sources to prepare for database migrations to Hybrid Manager.
* [Destinations](https://www.enterprisedb.com/docs/edb-postgres-ai/1.4/hybrid-manager/using_hybrid_manager/migration/migrate/destinations/): Learn about creating destinations to prepare for database migrations to Hybrid Manager.
* [Migrations](https://www.enterprisedb.com/docs/edb-postgres-ai/1.4/hybrid-manager/using_hybrid_manager/migration/migrate/migrations/): Learn about viewing migration details when performing database migrations to Hybrid Manager.
* [Credentials](https://www.enterprisedb.com/docs/edb-postgres-ai/1.4/hybrid-manager/using_hybrid_manager/migration/migrate/credentials/): Learn about creating migration credentials to prepare for database migrations to Hybrid Manager.
