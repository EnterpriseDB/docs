# Installing EDB Data Migration Service agent on Linux

> **Note**
>
> Install and configure EDB DMS Agent with Hybrid Manager versions 1.3 and later. For Hybrid Manager 1.2 and earlier versions, use EDB DMS Reader and EDB DMS Writer.

Select a link to access the applicable installation instructions. If you already have the agent installed and need to upgrade it, see [Upgrading the DMS agent](https://www.enterprisedb.com/docs/edb-postgres-ai/1.4/hybrid-manager/using_hybrid_manager/migration/upgrading_agent/) instead.
