# Databases

The **Databases** page lists the external databases registered for migration in this project, along with a migration assessment you can use for planning. It shows the same information as the **Migrations** tab of the **Estate** page, scoped to the current project.

- [Migrations table](https://www.enterprisedb.com/docs/edb-postgres-ai/1.4/hybrid-manager/using_hybrid_manager/migration/migrations/#migrations-table): See the full list of columns and how to filter, sort, and customize the table.
- [Viewing migration assessment details](https://www.enterprisedb.com/docs/edb-postgres-ai/1.4/hybrid-manager/using_hybrid_manager/migration/migrations/migration_database_details_view/): Select a database to check its migration status, review schemas and assessment results, and start or manage its migration.
- [Migration assessment support](https://www.enterprisedb.com/docs/edb-postgres-ai/1.4/hybrid-manager/using_hybrid_manager/migration/migrations/compatibility/): See which databases can be assessed for migration.
- [Assessing multiple databases at once](https://www.enterprisedb.com/docs/edb-postgres-ai/1.4/hybrid-manager/using_hybrid_manager/migration/migrations/assessing_multiple_databases/): Enroll many databases for migration assessment in a single step.
