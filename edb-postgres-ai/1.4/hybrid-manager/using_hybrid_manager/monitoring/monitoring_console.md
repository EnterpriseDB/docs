# Monitoring with the Hybrid Manager console

You can access a comprehensive set of database metrics using the Hybrid Manager (HM) console, with availability varying by metric and cluster type.

- [Support scope](https://www.enterprisedb.com/docs/edb-postgres-ai/1.4/hybrid-manager/using_hybrid_manager/monitoring/monitoring_console/support_scope/) — Learn about the type of metrics that are supported for your clusters.

- [Metrics latency](https://www.enterprisedb.com/docs/edb-postgres-ai/1.4/hybrid-manager/using_hybrid_manager/monitoring/monitoring_console/metrics_latency/) — Learn about how often metrics are updated.

- [Event markers](https://www.enterprisedb.com/docs/edb-postgres-ai/1.4/hybrid-manager/using_hybrid_manager/monitoring/monitoring_console/event_markers/) — Learn about Event markers and how they provide additional information on the data monitored in your clusters.

* [Metrics support](https://www.enterprisedb.com/docs/edb-postgres-ai/1.4/hybrid-manager/using_hybrid_manager/monitoring/monitoring_console/support_scope/): Understand the support scope for database metrics with the Hybrid Manager console.
* [Metrics latency](https://www.enterprisedb.com/docs/edb-postgres-ai/1.4/hybrid-manager/using_hybrid_manager/monitoring/monitoring_console/metrics_latency/): Understand monitoring latency for database metrics with the Hybrid Manager console.
* [Event markers](https://www.enterprisedb.com/docs/edb-postgres-ai/1.4/hybrid-manager/using_hybrid_manager/monitoring/monitoring_console/event_markers/): Learn how event markers display activity on monitoring charts and let you set time range boundaries.
