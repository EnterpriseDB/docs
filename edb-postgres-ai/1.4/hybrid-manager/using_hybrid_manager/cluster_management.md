# Working with clusters

You can use Hybrid Manager (HM) to create and manage database clusters. The databases can be based on any of the following Postgres types:

- EDB Postgres Advanced Server

- EDB Postgres Extended Server (PGE)

- PostgreSQL

Cluster management includes creating new clusters, controlling access, monitoring cluster performance, and managing lifecycle operations such as editing, restoring, or deleting clusters. You can also create reusable templates to simplify future cluster creation.

## What can you do?

- [Create a cluster](https://www.enterprisedb.com/docs/edb-postgres-ai/1.4/hybrid-manager/using_hybrid_manager/cluster_management/create-clusters/)

  Learn how to create a new database cluster from a predefined template or configure one from scratch.

- [Manage a cluster](https://www.enterprisedb.com/docs/edb-postgres-ai/1.4/hybrid-manager/using_hybrid_manager/cluster_management/manage-clusters/)

  Perform key management tasks such as modifying configuration, restoring backups, deleting clusters, and creating templates.

- [Manage database access](https://www.enterprisedb.com/docs/edb-postgres-ai/1.4/hybrid-manager/using_hybrid_manager/cluster_management/managing_db_access/)

  Set up users, roles, and permissions to control who can access and connect to your clusters.

- [View clusters](https://www.enterprisedb.com/docs/edb-postgres-ai/1.4/hybrid-manager/using_hybrid_manager/cluster_management/view_clusters/)

  Monitor and review the status, configuration, and activity of all your database clusters.

- [Automate cluster operations](https://www.enterprisedb.com/docs/edb-postgres-ai/1.4/hybrid-manager/using_hybrid_manager/cluster_management/hm_automations/)

  Configure rule-based automated operations, such as auto scaling and maintenance windows, that run on a schedule and react to conditions.

* [Creating a cluster](https://www.enterprisedb.com/docs/edb-postgres-ai/1.4/hybrid-manager/using_hybrid_manager/cluster_management/create-clusters/): Create and configure a new database cluster from a template or custom settings.
* [Cluster management tasks](https://www.enterprisedb.com/docs/edb-postgres-ai/1.4/hybrid-manager/using_hybrid_manager/cluster_management/manage-clusters/): Manage and monitor existing clusters by editing configuration, restoring or deleting clusters, upgrading versions, or analyzing performance via Kubernetes resources.
* [Viewing clusters](https://www.enterprisedb.com/docs/edb-postgres-ai/1.4/hybrid-manager/using_hybrid_manager/cluster_management/view_clusters/): View detailed information about a selected cluster, including configuration, health, monitoring, diagnostics, backups, and tags.
* [Managing database access](https://www.enterprisedb.com/docs/edb-postgres-ai/1.4/hybrid-manager/using_hybrid_manager/cluster_management/managing_db_access/): Configure LDAP authentication for your database cluster using the Hybrid Manager API.
* [Automating operations](https://www.enterprisedb.com/docs/edb-postgres-ai/1.4/hybrid-manager/using_hybrid_manager/cluster_management/hm_automations/): Learn about automated cluster operations, a framework for automating routine database operations directly from Hybrid Manager.
