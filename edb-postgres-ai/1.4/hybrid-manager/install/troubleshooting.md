# Troubleshooting Hybrid Manager installations

The Hybrid Manager (HM) installation comes with preflight and postflight checks that you can use to validate your installation, as well as monitor running deployments. These tools also provide detailed information to help you troubleshoot any failed checks.

- [Preflight checks](https://www.enterprisedb.com/docs/edb-postgres-ai/1.4/hybrid-manager/install/troubleshooting/preflight_checks/): Understand how the operator validates secret requirements during installation and how to troubleshoot failures.
- [Postflight checks](https://www.enterprisedb.com/docs/edb-postgres-ai/1.4/hybrid-manager/install/troubleshooting/postflight_checks/): Monitor the health of your Hybrid Manager deployment with automated postflight checks.
- [Registry and artifact errors](https://www.enterprisedb.com/docs/edb-postgres-ai/1.4/hybrid-manager/install/troubleshooting/registry_errors/): Decode error messages you may encounter while mirroring or pulling Hybrid Manager container images and artifacts, and what actually causes each one.
