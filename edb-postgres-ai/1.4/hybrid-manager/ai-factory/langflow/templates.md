# Agent Studio templates

Agent Studio in Hybrid Manager ships with pre-built flow templates for common workflows. Templates give you a working starting point — open one from the template gallery, configure a few inputs, and run it in the Playground.

To access templates, open Agent Studio from **Launchpad** in the HM console, select **New Flow**, and then select **All Templates**.

| Template                                                                                                                                             | What it does                                                                                                                        |
| ---------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| [Simple Migration Agent](https://www.enterprisedb.com/docs/edb-postgres-ai/1.4/hybrid-manager/ai-factory/langflow/templates/simple-migration-agent/) | Automates database migration into Hybrid Manager: creates a destination cluster, migrates the schema, and kicks off data migration. |

- [Simple Migration Agent](https://www.enterprisedb.com/docs/edb-postgres-ai/1.4/hybrid-manager/ai-factory/langflow/templates/simple-migration-agent/): Use the Simple Migration Agent template in Agent Studio to automate database migration into Hybrid Manager.
