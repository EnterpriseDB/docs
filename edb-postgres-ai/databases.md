# EDB Postgres AI databases

## Postgres options

Building on decades of Postgres expertise, the EDB Postgres® AI databases are the core of the EDB Postgres AI platform.

- [Enterprise Postgres (Oracle Compatible)](https://www.enterprisedb.com/docs/epas/latest/) - Also known as EDB Postgres Advanced Server can take on Oracle workloads.
- [Enterprise Postgres](https://www.enterprisedb.com/docs/pge/latest/) - Also known as EDB Postgres Extended Server is designed for large-scale, mission-critical enterprise workloads.

All of them are built on the same Postgres core, so you can use the same tools and skills across all of them.

- [PostgreSQL](https://www.enterprisedb.com/docs/supported-open-source/postgresql/) is the world's most advanced open source database, and the foundation for all EDB Postgres databases.

And for distributed high-availability and fault tolerance for mission-critical workloads, you can use Enterprise Postgres (Oracle Compatible) and Enterprise Postgres in combination with EDB Postgres Distributed:

- [EDB Postgres Distributed](https://www.enterprisedb.com/docs/pgd/latest/)

- [Enterprise Postgres (EDB Postgres Extended Server)](https://www.enterprisedb.com/docs/pge/latest/): Enterprise Postgres, also known as EDB Postgres Extended Server, is a Postgres database server distribution built on open-source, community PostgreSQL. It's fully compatible with PostgreSQL at the SQL and system catalog level: Enterprise Postgres tracks the same catalog format as community PostgreSQL for each major version, so if you have applications written and tested to work with PostgreSQL, they will behave the same with Enterprise Postgres. We support and fix any functionality or behavior differences between community PostgreSQL and Enterprise Postgres.
- [EDB Postgres Distributed (PGD)](https://www.enterprisedb.com/docs/pgd/latest/): EDB Postgres Distributed (PGD) provides multi-master replication and data distribution with advanced conflict management, data-loss protection, and throughput up to 5X faster than native logical replication.
