# EDB Postgres for Kubernetes 1.19.0 release notes

Released: 14 Feb 2023

This release of EDB Postgres for Kubernetes includes the following:

| Type           | Description                                                                                                                                                                                                                                                                            |
| -------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Upstream merge | Merged with community CloudNativePG 1.19.0. See the community [Release Notes](https://cloudnative-pg.io/docs/devel/release_notes/old/v1.19/).                                                                                                                                          |
| Feature        | Support for [Transparent Data Encryption (TDE)](https://www.enterprisedb.com/docs/edb-postgres-ai/platforms-and-tools/security/tde/) with EDB Postgres Advanced Server 15. TDE encrypts, transparently to the user, any user data stored in the database system.                       |
| Feature        | New external backup adaptor to provide a generic way to integrate EDB Postgres for Kubernetes in a third-party tool for backups. See [External Backup Adapter](https://www.enterprisedb.com/docs/postgres_for_kubernetes/latest/addons/#external-backup-adapter) for more information. |
