# Migrating a database

<div id="mp_migrating_database" class="registered_link"></div>

To migrate a database, you must complete the following steps:

1. Perform a [schema extraction](https://www.enterprisedb.com/docs/migration_portal/latest/04_mp_migrating_database/01_mp_schema_extraction/).
2. Perform a [schema assessment](https://www.enterprisedb.com/docs/migration_portal/latest/04_mp_migrating_database/mp_schema_assessment/).
3. Perform a [schema migration](https://www.enterprisedb.com/docs/migration_portal/latest/04_mp_migrating_database/03_mp_schema_migration/#mp_schema_migration).
4. Perform a [data migration](https://www.enterprisedb.com/docs/migration_portal/latest/04_mp_migrating_database/04_mp_data_migration/#mp_data_migration).

- [Schema extraction](https://www.enterprisedb.com/docs/migration_portal/latest/04_mp_migrating_database/01_mp_schema_extraction/): Schema extraction methods
- [Schema assessment](https://www.enterprisedb.com/docs/migration_portal/latest/04_mp_migrating_database/mp_schema_assessment/): You can assess an Oracle database schema for compatibility with EDB Postgres Advanced Server. You can also generate a report about the assessment.
- [Schema migration](https://www.enterprisedb.com/docs/migration_portal/latest/04_mp_migrating_database/03_mp_schema_migration/): After resolving errors in your schemas, you can migrate the schemas to an EDB Postgres Advanced Server database.
- [Data migration](https://www.enterprisedb.com/docs/migration_portal/latest/04_mp_migrating_database/04_mp_data_migration/): After performing the schema migration, migrate the data.
