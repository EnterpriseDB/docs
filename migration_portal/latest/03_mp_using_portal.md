# Using Migration Portal

<div id="mp_using_portal" class="registered_link"></div>

Migration Portal allows you to easily migrate your database schema from Oracle to EDB Postgres Advanced Server. You can upload schemas for assessment and get immediate feedback and suggestions. The portal allows you to download assessed DDLs for all objects and create your EDB Postgres database on premises or in the cloud.

![The assessment and migration process](https://media.githubusercontent.com/media/EnterpriseDB/docs/180a1761cbd57e7d4de5f955718bf0bc144bc1b7/product_docs/docs/migration_portal/5/images/mp_using_portal_updated.png)

> **Note**
>
> Migration Portal currently doesn't have team collaboration features. We recommend collaborative meetings, screen sharing, and using the downloadable assessment report to share results.

To access the Migration Portal, open a web browser and go to [EnterpriseDB Website](https://migration.enterprisedb.com/). Log in using your credentials. See [Migration Portal quick start](https://www.enterprisedb.com/docs/migration_portal/latest/03_mp_using_portal/03_mp_quick_start/) for an overview of using Migration Portal to migrate Oracle schemas.
