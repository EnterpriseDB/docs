# Postgres Analytics Accelerator (PGAA)

Postgres Analytics Accelerator (PGAA) is a high-performance extension that enables Postgres to query large-scale data stored in open table formats like Delta Lake and Apache Iceberg. By offloading heavy analytical queries to a vectorized execution engine, PGAA bridges the gap between operational databases and data lakes.

### Get started

- [Compatibility](https://www.enterprisedb.com/docs/pgaa/1.3/overview/compatibility/): Check supported PostgreSQL versions, operating systems, and other requirements.

- [Architecture](https://www.enterprisedb.com/docs/pgaa/1.3/overview/architecture/): Understand the core architecture and how the vectorized engine works.

- [Core concepts](https://www.enterprisedb.com/docs/pgaa/1.3/overview/concepts/): Understand the fundamental principles of vectorized execution, data lake integration, and DirectScan.

- [Quickstart guide](https://www.enterprisedb.com/docs/pgaa/1.3/overview/quick_start/): Install PGAA, create a storage location and read table from our sample benchmark datasets.

### Using PGAA

- [Installation](https://www.enterprisedb.com/docs/pgaa/1.3/installing/): Step-by-step instructions for installing the extension and enabling the Seafowl background worker.

- [Read from object storage](https://www.enterprisedb.com/docs/pgaa/1.3/read_no_catalog/): Connect directly to S3, GCS, or Azure Blob Storage to query Delta or Iceberg files using a PGFS storage location.

- [Read using Iceberg catalogs](https://www.enterprisedb.com/docs/pgaa/1.3/catalog/): Integrate with external Iceberg REST catalogs to manage table metadata.

- [Write to object storage using CTAS](https://www.enterprisedb.com/docs/pgaa/1.3/ctas/): Use `CREATE TABLE AS SELECT` (CTAS) to export Postgres data into optimized lakehouse formats in your object store.

### Reference

- [Configuration parameters](https://www.enterprisedb.com/docs/pgaa/1.3/reference/configuration_parameters/): The behavior of the PGAA extension is governed by Grand Unified Configuration (GUC) variables.
