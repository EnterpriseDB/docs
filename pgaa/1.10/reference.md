# Reference

The reference section provides detailed technical specifications for the Postgres Analytics Accelerator (PGAA). Use these resources to fine-tune your configuration, understand supported data types, and manage your analytical tables.

For information on the PGFS functions for managing storage location, see the [Agent Factory PGFS documentation](https://www.enterprisedb.com/docs/pg_extensions/pgfs/).

- [Configuration parameters](https://www.enterprisedb.com/docs/pgaa/1.10/reference/configuration_parameters/): The behavior of the PGAA extension is governed by Grand Unified Configuration (GUC) variables. These parameters allow you to switch executors, enable performance optimizations, and manage security credentials.

- [Functions](https://www.enterprisedb.com/docs/pgaa/1.10/reference/functions/): PGAA introduces a suite of SQL functions for administrative tasks, such as mapping new tables, monitoring storage health, and launching maintenance background jobs.

- [Table options](https://www.enterprisedb.com/docs/pgaa/1.10/reference/table_options/): When mapping or creating analytical tables, specific options allow you to define how data is read from or written to your object store.

- [Data types](https://www.enterprisedb.com/docs/pgaa/1.10/reference/data_types/): PGAA maps native Postgres data types to optimized columnar formats in the data lake.

- [Datasets](https://www.enterprisedb.com/docs/pgaa/1.10/reference/datasets/): Access pre-configured schemas and data loading instructions for analytical datasets to baseline your performance.

* [Configuration parameters](https://www.enterprisedb.com/docs/pgaa/1.10/reference/configuration_parameters/): Reference for the configuration parameters provided by the PGAA extension.
* [Functions](https://www.enterprisedb.com/docs/pgaa/1.10/reference/functions/): Reference for the functions provided by the PGAA extension.
* [Table options](https://www.enterprisedb.com/docs/pgaa/1.10/reference/table_options/): Reference for the table options provided by the PGAA extension.
* [Data types and definitions](https://www.enterprisedb.com/docs/pgaa/1.10/reference/data_types/): Supported Postgres types and internal PGAA state definitions.
* [Benchmark datasets](https://www.enterprisedb.com/docs/pgaa/1.10/reference/datasets/): Benchmark datasets available for PGAA.
